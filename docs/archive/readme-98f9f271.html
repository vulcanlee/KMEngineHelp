這個目錄是什麼

本目錄收納已完成、已被取代或已過期的文件，保留供回溯當時的決策脈絡與實作歷程。

重要：這裡的內容一律不代表現行需求或系統現況。查現況請到 docs/prd/（產品需求）、docs/architecture/（技術設計）、docs/guides/（操作教學）、docs/operations/（維運）。每份歸檔文件開頭都有「已歸檔」標頭，註明歸檔原因與該改看哪一份。

之所以保留而不刪除，是因為這些文件記錄了當初為什麼那樣決定——刪掉會失去設計歷史；但留在原目錄又會讓人誤以為是現行規劃。
