知識來源管理與資料清洗：功能、價值與行銷

說明「知識來源加工」與其「清洗」按鈕的實際運作、要解決的痛點與商業價值，並提供行銷標語與價值放大策略，作為對內溝通與對外行銷的單一參考

背景參考：延伸 01-計畫範圍與遠景 與 02-商業價值與行銷策略 的痛點與 ROI 框架；應用情境見 09-企業應用情境型錄；功能與技術規格見 知識來源管理 PRD 與 資料清洗與品質保證 PRD。本文以「給人看的價值語言」整合上述內容，技術描述以現行程式碼為準。

一、「清洗」按鈕到底做了哪些事？

頁面：/knowledge-sources（知識來源加工）。每一筆「知識來源」可底下掛多個「成員」（跨三條匯入管線的素材），按下「清洗」即啟動一條背景式、可重試、可取消、有品質關卡的自動化處理線。

技術鏈路：KnowledgeSourceService.TriggerCleaningAsync → ICleaningQueue（佇列）→ CleaningBackgroundService（背景服務）→ CleaningProcessor（處理器）→ CleaningEnhancer（LLM 強化）。

實際步驟：

  1. 排入佇列：按「清洗」→ 跳出確認（「將彙整此來源的成員內容並產出清洗後文件，確定嗎？」）→ 通過權限與「至少一個成員」檢查後，狀態轉 等待中，清空進度與錯誤訊息，排入清洗佇列。
  2. 取出處理：背景服務取出後，狀態轉 處理中（進度 10%）。
  3. 彙整成員內容：依排序串接該來源底下所有成員的內容，跨四種素材型別（1.0.25 起）——
  4. 影音轉錄（逐字稿）
  5. 文件轉文字（Markdown）
  6. 圖片辨識（解讀文字）
  7. 會議紀錄（AI 會議紀錄，非逐字稿；1.0.25）
  8. 僅納入「已完成且有內容」的成員；未完成或空內容自動略過。
  9. 繁體化：簡體→繁體（OpenCC 台灣用語），僅轉正文、保留原標題避免術語誤代換。
  10. LLM 強化（進度 60%，CleaningEnhancer，五個步驟依序）：
  11. 去重：移除重複段落與明顯雜訊（可降級：失敗則保留原文並記警告）。
  12. 遮罩：將個資與機密（身分證號、電話、Email、地址、金融帳號、密碼、金鑰等）以【已遮罩】取代。安全關鍵、不可降級——遮罩失敗即整筆清洗失敗，避免外洩。
  13. 分類：建議 1–5 個主題分類標籤。
  14. 摘要：約 100–200 字繁中重點摘要，並另列「關鍵實體」（人/組織/產品/主題）。
  15. 信心自評：LLM 對本次清洗整體正確與完整度給 0–1 的分數。
  16. 上述提示詞皆可由「AI 提示詞」覆寫（鍵：清洗-去重/遮罩/分類/摘要/信心），未設定則用內建預設。
  17. 產出乾淨文件：組裝單一 Markdown（標題／摘要／建議分類／備註／清洗後正文），存成 {年}/{guid}.md，寫回 CleanedContentRelativePath、CleanedAt、ConfidenceScore。
  18. 信心門檻路由（SystemSettings.Cleaning.ConfidenceThreshold，預設 0.70）：
  19. 信心 ≥ 門檻 → 已清洗（自動通過）。
  20. 信心 < 門檻、或信心為空（評估失敗）→ 待審核（送人工把關）。
  21. 未設定 LLM → 直接 已清洗（純彙整＋繁體化）。
  22. 進度 100%。

周邊操作（同列按鈕，依狀態出現）：取消清洗、重試清洗（失敗/已取消可重跑）、檢視清洗結果、以及人工關卡 核准／退回（需 角色_知識審核 或管理員）。清單在有 等待中／處理中 紀錄時每 5 秒自動輪詢，即時更新進度與信心。

一句話：「清洗」＝把一個知識來源底下散落的多源素材，一鍵彙整、繁體化、去重、去敏、分類、摘要，並自評可信度後產出一份乾淨的知識文件，再由門檻＋人工決定能不能直接採用。

二、「知識來源加工」這個作業在做什麼？

它是「匯入 → 清洗/蒸餾 → 知識庫」閉環中承上啟下的彙整與品質作業：

  • 聚合：把分散在三條匯入管線的零散素材（會議錄音、文件、影片、圖片、工單…）綁成一個有意義的「知識來源」單位（可命名、加描述、分類、團隊權控、管理成員與排序）。
  • 清洗：一鍵把雜亂多源內容變成乾淨、結構化、去敏、可檢索的知識文件。
  • 治理：用狀態機（草稿／等待中／處理中／已清洗／待審核／失敗／已取消／已退回）＋信心分數＋人工審核關卡，確保「進到知識庫的，是可信的內容」。

三、目的、要解決的問題、為何知識管理需要它

它解決的痛點

痛點現況的苦本功能如何解
素材散落多源錄音、文件、影片、圖片各自為政，找不齊、對不上聚合成單一知識來源，一次處理
格式雜亂、繁簡混用直接用不了，要人工重排自動串接＋繁體化（台灣用語）
含個資/機密不敢外用、合規風險高自動遮罩，遮罩失敗即擋下
重複冗餘同一段講三遍，雜訊多自動去重去雜訊
找不到、用不上沒有分類與摘要，無法檢索自動分類（1–5 標籤）＋重點摘要＋關鍵實體
不知道整理結果可不可信人工整理品質不一、無從判斷信心自評＋門檻＋人工審核，品質可量化、可治理
人工整理耗時一份報告整理半天到一天背景自動化，分鐘級產出

為什麼知識管理「需要」這一層

知識管理最大的失敗不是「沒有資料」，而是「資料進來了卻不能用、不敢用、找不到、不可信」。本功能把「原始素材」轉換成「可信任的知識資產」：去敏讓它敢用、分類摘要讓它找得到、信心分數＋人工審核讓它可被信賴、狀態可視讓它可被管理。沒有這層，知識庫只是另一個雜亂的檔案夾。

四、行銷標語（擇優挑選，標★為推薦首選）

  1. ★「一鍵，把雜亂素材變成可信知識。」 —— 打中：聚合＋清洗＋可信任的整體價值。
  2. ★「會去敏、會分類、會自評信心的知識清洗線。」 —— 打中：合規＋可檢索＋可信賴的差異化。
  3. 「讓每一份會議與文件，自動長成組織的記憶。」 —— 打中：知識資產化、組織記憶的願景。
  4. 「不只是整理資料，是替知識把關。」 —— 打中：品質治理、人工審核關卡。
  5. 「個資自動遮罩，知識才敢拿出來用。」 —— 打中：合規與外用安全的恐懼解除。
  6. 「分鐘級，完成你一整天的知識整理。」 —— 打中：效率與工時節省。
  7. 「給你的不是一堆檔案，是一份結論。」 —— 打中：去蕪存菁、摘要即結論。
  8. 「每一筆清洗，都附一張可信度分數。」 —— 打中：可量化信任、決策依據。

五、以「心理登月」手法放大整個系統的價值

「心理登月」＝先把產品的意義層級從工具拉高到願景（Moonshot），再用心理機制讓使用者渴望擁有、害怕失去、樂於投入。以下每點都對應目前已有功能或可強化的具體動作，讓行銷主張站得住、也指引產品方向。

  1. 願景錨定（升維定位）：不要賣「資料清洗工具」，要賣「企業知識資產化引擎／組織記憶」。對外話術從「幫你整理檔案」改為「把組織每天產生的對話與文件，自動沉澱成可信、可檢索、可複用的知識資產」。——呼應 09 型錄的「基底平台＋能力包」定位。
  2. 損失趨避（把不做的代價可視化）：強調「未清洗＝個資外洩風險＋知識持續流失」。動作：在清單/儀表板上呈現「未清洗筆數、待審核筆數、潛在外洩風險項目」，讓「不處理」變成看得見的損失。
  3. 稟賦效應與進度感（讓資產在眼前增值）：信心分數、進度條、狀態徽章已具雛形。動作：把「已清洗筆數、平均信心、累計節省工時」做成成長曲線，讓使用者感覺「我的知識資產正在升值」，越投入越捨不得離開。
  4. 身分認同（給使用者一個更高的角色）：把使用者塑造成「知識治理者」而非「資料整理員」；核准/退回 的人工關卡＝專業話語權與責任感。動作：審核介面強調「由你把關，才進入組織知識庫」。
  5. 社會證明與里程碑（用數字建立信任與動力）：動作：累計清洗份數、合規覆蓋率（已遮罩比例）、團隊排行榜、里程碑徽章；對外提案附「平均每份節省 X 小時、遮罩召回率 ≥ Y%」（可由清洗品質評測集 CleaningEvaluator 量化）。
  6. 降低啟動門檻（一鍵到結論）：強化「一鍵清洗、分鐘級拿到結論」的即時回饋，縮短「投入 → 收穫」的心理距離。動作：清洗完成即推播摘要與信心分數，讓價值「立刻被看見」。

可直接排入路線圖的增值動作

  • 信心分數儀表板：把 ConfidenceScore 與門檻路由做成可視化看板（自動通過率/送審率）。
  • 清洗前後 Diff：呈現「去重了什麼、遮罩了什麼」，把黑箱變透明，強化信任與稟賦效應。
  • ROI 量化看板：累計節省工時、合規覆蓋率、知識複用次數——對應 02 商業價值框架。
  • 能力包蒸餾延伸：在已清洗知識上一鍵蒸餾 SOP／問答／考題等能力包（呼應 09 型錄），把「清洗」升級為「衍生子應用的起點」，是價值最大的登月方向。

小結：清洗按鈕讓「多源雜亂素材」變成「可信知識文件」；知識來源管理是讓知識「敢用、找得到、可信賴、可管理」的關鍵一層。對外，請以「組織記憶／知識資產化引擎」的願景定位，搭配可量化的信任與 ROI 數字，把工具賣成不可或缺的基礎設施。
