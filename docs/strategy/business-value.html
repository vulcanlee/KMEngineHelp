一、商業價值總綱

知識庫的核心價值是知識資產化：把原本散落、難找、難整理、依附在人身上的資訊，變成可搜尋、可管理、可再利用、可稽核的資產。價值沿兩條路線發生：

  • 內部自用（開發人員自身）：開發人員自己使用這些功能管理自身知識，同時作為產品 dogfooding——天天用、最快驗證價值與發現問題。
  • 對外商品化：以「可私有部署、企業級權控」為差異化，銷售給其他企業與通路。

二、內部自用價值與 ROI 框架

「內部自用」指開發人員自己使用這些功能：把自身蒐集的資料與知識資產化，當成日常查找與工作的工具，並藉此 dogfooding 驗證產品。下列指標既衡量開發者自身的使用價值，也正是日後對外銷售時要對客戶講的同一套 ROI 故事（實際基準值需於使用前量測）。

1. 提升效率

  • 指標：員工平均「找一份資料/答案」的時間、會議後整理工時、新人上手所需天數。
  • 價值假設：問答助理把「翻找＋詢問」替換為「自然語言提問＋帶出處答案」，縮短查找時間。
  • 量化方式：節省時數 × 人力成本/小時 × 月查詢次數。

2. 降低人力成本

  • 指標：逐字稿/會議管理/文件摘要/分類標註的人工工時。
  • 價值假設：清洗階段（自動摘要、分類標籤、去重）把重複性整理工作自動化。
  • 量化方式：自動化前後工時差 × 人力成本。

3. 加速知識傳承

  • 指標：交接完整度、關鍵知識「只在某人腦中」的比例、人員異動造成的重工成本。
  • 價值假設：知識留存於系統而非個人，降低人員異動造成的知識斷層。

4. 提升決策品質

  • 指標：決策所需背景資料的取得速度與完整度。
  • 價值假設：可追溯、帶出處的知識讓決策有據可依。

建議導入時先選 1–2 個高頻情境（如會議知識留存、SOP 查詢），量測基準值，作為內部 ROI 的證據與對外案例的素材。

三、對外商品化策略

首要楔子假設（office-hours 2026/06/08，待驗證）：最尖銳的進場痛點假設為知識傳承（關鍵老手流失、新人接不起來）。在拿到行為證據前，這是「首要待驗證假設」而非定論；通用知識庫定位與此並陳。驗證計畫與成功門檻見 05 §〇。

市場證據（deep-research 2026/06/08，單一來源未交叉驗證）：傳承痛是真且有預算——退休潮規模大、C-suite 高度擔憂、多數組織未系統性捕捉（來源：APQC、tektome 等）。但已有產品在做：KNOWRON（語音/影片捕捉專家知識→可問答）、Dozuki CreatorPro AI（捕捉 SME/江湖知識）。⇒ 楔子被驗證為真，但非藍海；對這些（多偏製造/前線 SOP 垂直）的差異要打「通用＋真地端＋既有影音匯入優勢」。

1. 目標市場與客群

  • 主力：有大量非結構化資訊、且重視資料自主/合規的中型企業與組織。
  • 客群輪廓：知識管理需求高、會議多、SOP/客服文件多、專業知識依附資深人員的單位。
  • 通路：透過企業 AI 導入、知識管理、流程數位化的顧問與系統整合夥伴銷售。

2. 核心痛點（切入點）

  • 資訊分散，知識難以累積。
  • 會議多但後續追蹤不完整。
  • 人工整理成本高、品質不穩定。
  • 關鍵知識依附在人身上，人員異動即斷層。
  • 既有雲端 AI 方案有「資料外流疑慮」，受限產業不敢用。

3. 競品概覽與差異化

關鍵洞察：主流大廠助理（Copilot/NotebookLM/ChatGPT Ent.）幾乎都是純雲端；Glean 是少數可自架者，但是「自架於客戶的雲」而非真・地端/離線。

差異化賣點（依研究校正）：

  1. 真・地端/離線部署（含地端 LLM）——資料完全不出企業環境，面向最受限產業；此點明確強於 Glean 的「自架於客戶雲」。
  2. 企業級權控——延續既有團隊層權控，檢索層即過濾（越權不外洩）（Glean 亦強，須以其他點拉開差距）。
  3. 敏感資訊遮罩 ＋ 存取稽核——合規友善。
  4. 完整閉環＋知識頁審核——匯入→清洗→蒸餾→知識庫→應用一站式，產出「精煉知識」而非只給一個聊天框；這是相對純檢索/助理型競品的結構性差異。

4. 定價模型方向（待細化）

  • 地端/私有部署：授權年費 ＋ 導入服務 ＋ 維運/更新訂閱。
  • 雲端訂閱：依使用者數或知識量分級。
  • 加值：客製連接器、應用模組（SOP/客服/專案助理）、顧問導入。

定價需依目標客群付費意願與成本結構細化，列為待釐清項（見 05 待釐清問題）。

5. GTM 與行銷作法

  • 燈塔案例：先用內部自用成果（量化 ROI）作為第一個對外案例。
  • 情境式行銷：以具體痛點情境（會議知識留存、SOP 查詢、客服問答）切入，而非賣技術名詞。
  • 可體驗：提供旗艦問答助理的 demo 流程，讓客戶「看到答案帶出處」。
  • 夥伴賦能：提供通路夥伴銷售簡報、痛點話術、ROI 試算與導入指南。
  • 資安為賣點：強調地端部署、權控、遮罩、稽核，主打受限產業。

四、以旗艦應用為主軸的價值故事

旗艦一：AI 智慧問答／企業知識助理

  • 故事：「過去問同事、翻檔案要半天；現在問助理，30 秒得到帶出處的答案。」
  • 賣點：通用、好展示、ROI 易量化（查找時間）。
  • 適合：作為對外銷售的樣板案例與 demo 主軸。

旗艦二：AI Agent 自動化工作流

  • 故事：「不只回答問題，還能依知識庫自動完成多步驟工作（彙整、追蹤、產出）。」
  • 賣點：價值最高、想像空間大。
  • 定位：長期願景，近期先做雛形與可行性驗證，作為願景簡報的「未來想像」。

五、兩份商業簡報

本計畫產出兩份對應不同對象的簡報（Markdown ＋ PPTX ＋ HTML 三格式，置於 docs/marketing/）：

  1. 決策投資版——給公司高層/決策投資，強調問題與機會、願景、閉環、投資報酬、路線圖、資源與風險。
  2. 對外銷售版——給潛在客戶，強調痛點、解決方案、旗艦應用 demo 故事、地端/雲端彈性、權控與資安、效益與下一步。
