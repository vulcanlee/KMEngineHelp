客戶用的簡報 Steve Jobs prompt

我需一份關於這個知識庫完整應用系統的簡報，分析這個專案與 docs 下的文件進行理解整個系統的目的與想法，對象是面對客戶，採用蘋果 客戶用的簡報 Steve Jobs 的手法與理念 雖然有些功能尚未實作出來，但我希望能夠讓客戶知道這是一個已經完成的系統，並且對客戶論述這個產品的價值，確實可以幫助他們解決工作或者日常的重點，簡報內容至少需要超過 25 頁以上，產出的檔案要有 .md & pptx(可以編輯) & html 格式的簡報檔案，並且附上一份如何使用與進行報告的指引與說明，目的在於讓客戶聽完這個產品介紹後，會有印象並且有意願下單或者接續往後的業務推動。

對於這樣的想法，有甚麼是我沒有想到或者需要我補充的內容，請反覆與我確認，又或者我該怎麼產生一個更適合的提示詞來文成這項工作，所有這些文件要寫到 docs 目錄下
