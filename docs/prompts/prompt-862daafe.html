黃金評測用法 prompt

使用 superpowers 技能

在這個 黃金評測中，建立一筆新的黃金評測紀錄，這裡需要輸入許多欄位內容，這些內容是要做甚麼用途，舉個許多例子，可以用於在不同的欄位內，對於 黃金評測 這個作業的功能是要做甚麼事情，會做哪些事情，其目的在哪裡，想要解決甚麼時間，為什麼知識管理需要這樣的功能，他解決了甚麼痛點，若要給予一句行銷話語，列出大家一聽就會想要擁有這個功能的一句話，列出至少五種來選擇，並且依據心理登月的營銷手法，說明對於這個功能或者對於匯入的資料到產生出真正清洗完成知識過程，該怎麼做來增加對於整個系統的價值，這裡是否是客戶真正需要的，算是絕大多數企業客戶的痛點嗎?這樣特色有很大的價值與意義嗎?

所以，對於知識清洗、清洗設定檔和黃金評測這三者之間，有沒有設麼關係，在操作與使用上，有沒有甚麼要注意的地方，我也需要一份文件，從客戶匯入、清洗到完成知識的過程該如何才能做到，最好有1~2個有幫助的例子來增加理解

順便解釋一下，現在的系統有已經設計到蒸鎦或者預計要做到這樣功能嗎?
