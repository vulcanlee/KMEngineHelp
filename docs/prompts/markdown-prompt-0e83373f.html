文件檔案轉換 Markdown 內容 prompt

使用 superpowers 技能

我要新建立一個頁面，可以提供使用者上傳檔案，透過 MarkItDown 工具 https://github.com/microsoft/markitdown ，在該網頁中有說明支援那些檔案格式(如 office, pdf 等等)，可以將其轉換成 Markdown 格式的文字內容，這是一個 CRUD 的頁面，設計規格參考 ProjectPage 頁面的設計方式。這可能需要加入其他的設定，如sidebar 功能表與Menu.json和角色裡的權限控制設計

其中需要透過背景工作，透過安裝在本機上 MarkItDown 工具執行檔案，進行文字內容的抽取而得到其文字內容，但在 UI 介面可以看到轉換進度與狀態，得知是否轉換完成或者失敗。

對於轉換出來的文字內容，採用以檔案的方式來儲存在檔案系統內，所要儲存的目錄可以在 appsettings.json 內來指定，在此目錄下，以上傳時間的年度切割為不同年度目錄，檔案將會儲存在指定的目錄下。

請依照這樣的需求產生一個 prd 檔案，並且記錄在 docs 目錄下，在 docs 目錄下，若沒有符合的子目錄，建立一個子目錄，將這個檔案儲存在那裏，對於文字內容，需要採用繁體中文 UTF-8 方式編碼，不可以有亂碼，若有不確定或者不理解我的需求，需要反覆對我提問，直到弄清楚我的目的
