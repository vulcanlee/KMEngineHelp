加入 分類與團隊選單

使用 superpowers 技能

現在已經有了分類與團隊清單建立的功能，現在需要把這兩個項目，加入到已經存在的頁面中 對於 專案項目、工作項目、會議紀錄、音訊轉錄、文件萃取 紀錄中，需要加入 分類 這個欄位，這個欄位類似一個 Tag 標籤這樣的功能，使用者可以定義這些紀錄屬於哪個 分類 項目，其屬性為字串，不需要做關聯，而且可以為空值，或者為多個 分類，使用類似 ant design 提供的類似 auto completion UI，使用者可以透過下拉選單來選取，也可以輸入關鍵字，並且自動出現符合的分類項目清單來選擇，加入之後，可以看到這筆紀錄有哪些 分類 項目歸屬在這個紀錄內，也可以對某個 分類 做移除，就像一般對待 Tag 標籤這樣的UI依樣，可以看到每個標籤右上方有個 x 圖示，點選後，就會移除該標籤。一旦儲存之後，就會儲存到原先記錄內。另外，對於瀏覽所有紀錄的時候，除了原有的排序、搜尋機制一樣要正常運作之外，還要加入可以選擇一個或者多個 分類 項目來進行過濾紀錄的功能。

對於 團隊 這個欄位也如同分類一樣，需要加入到上述的五個頁面 專案項目、工作項目、會議紀錄、音訊轉錄、文件萃取 記錄內，條件也要符合上述定義。

對於使用者角色紀錄上，要加入一個預設 團隊 欄位，該欄位可以設定一個或者多個 團隊 值，一旦使用者進入到 專案項目、工作項目、會議紀錄、音訊轉錄、文件萃取 頁面來瀏覽紀錄的時候，就僅能夠瀏覽該登入使用者授權看到的角色內定義的 團隊 值的紀錄。對於該使用者為 管理員 屬性，則不會受到這樣限制，管理員使用者可以看到所有 團隊 的紀錄。

這樣的設計是要提供使用者可以快速找到或者瀏覽特定的 分類 紀錄，並且限定該使用者僅能夠看到授權團隊可以看到的紀錄，不在該團隊內的紀錄，要被控制不能讓非授權的使用者看到，畢竟這些資料是有些敏感度的。

這次的變動範圍有些廣，並且要做到權控的功能，因此，設計上必須要能夠良好的測試或者驗證方法，確保這些需求可以正常做出來

請依照這樣的需求產生相關說明文件，並且記錄在 docs 目錄下，在 docs 目錄下，若沒有符合的子目錄，建立一個子目錄，將這個檔案儲存在那裏，所有文字需要採用繁體中文 UTF-8 編碼，不能有亂碼，若有不清楚我的意圖，需要反覆向我提問，直到確定這是我想要做的事情。
