團隊清單 prompt

使用 superpowers 技能

我要新建立一個頁面，能夠建立團隊清單，可以用於建立其他紀錄的時候，可以做為資料指定可以讓特定或者所有團隊可以使用這些紀錄之用，這是一個 CRUD 的頁面，設計規格參考 ProjectPage 頁面的設計方式。這可能需要加入其他的設定，如sidebar 功能表與Menu.json和角色裡的權限控制設計

預設瀏覽的時候，採用最近更新時間的排列，最近更新的紀錄，排在最前面

所輸入的團隊名稱文字，不論在新增或者修改的時候，必須要能夠為唯一值

這個頁面在 Side bar 功能表中，要位於 資料定義 的子功能表區域內

請依照這樣的需求產生一個 prd 檔案，並且記錄在 docs 目錄下，在 docs 目錄下，若沒有符合的子目錄，建立一個子目錄，將這個檔案儲存在那裏，所有文字需要採用繁體中文 UTF-8 編碼，不能有亂碼，若有不清楚我的意圖，需要反覆向我提問，直到確定這是我想要做的事情。
