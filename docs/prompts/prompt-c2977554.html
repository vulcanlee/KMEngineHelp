圖片轉文字服務 prompt

使用 superpowers 技能

我要新建立一個頁面，可以提供使用者上傳圖片檔案，這是一個 CRUD 的頁面，設計規格參考 ProjectPage 頁面的設計方式。這可能需要加入其他的設定，如sidebar 功能表與Menu.json和角色裡的權限控制設計，其位於 sidebar 的專案管理子功能表內

當這個圖片上傳完成之後，可以透過 OpenAI 的 LLM 來進行解讀這個圖片，再將其轉換成為文字，這裡會使用 appsettings.json 內的 OpenAISettings GenerationModel 所定義的模型來解讀文字，當要進行描述這個圖片的文字解讀的時候，會出現一個對話窗，在這裡可以選擇提示詞清單內的定義好的提示詞，告訴模型如何來解讀文字，轉換出來的文字，採用以檔案的方式來儲存在檔案系統內，所要儲存的目錄可以在 appsettings.json 內來指定，在此目錄下，以上傳時間的年度切割為不同年度目錄，檔案將會儲存在指定的目錄下。

請依照這樣的需求產生一個 prd 檔案，並且記錄在 docs 目錄下，在 docs 目錄下，若沒有符合的子目錄，建立一個子目錄，將這個檔案儲存在那裏
