使用手冊製作說明 prompt

使用 superpowers 技能

我需要一份這個系統的安裝、基礎設定、如何使用的教學手冊 對於要安裝這個系統，將會提供一個壓縮檔案，這個檔案有這裡底下的檔案內容 C:\Vulcan\Github\KnowledgeExtraction.AI\src\KnowledgeExtraction\KnowledgeExtraction.Web\bin\Release\net10.0\publish

這裡將會說明在本機電腦上啟動這個系統的做法 取得此壓縮檔案，進行解壓縮到某個目錄下 透過執行底下的命令，並且指定該 web 所要綁定的 port (這裡需要有文件說明來做這樣的參數使用方式) KnowledgeExtraction.Web.exe --urls "http://0.0.0.0:5080;https://0.0.0.0:5443"

接著，開啟瀏覽器，輸入這裡指定的網址，就會進入到這個系統 然後寫出如何使用這個系統，從登入(說明第一次登入的預設帳號密碼)，建立其他帳號、角色、設定其他的引用紀錄，如團隊或者分類等等，一旦基本準備工作完成後，此時，就要說明如何進行匯入 > 檢視 > 清洗 > 評量的過程，或者是這裡沒有提到，但是屬於這個系統的功能，並且是使用者必須要知道的內容，都需要寫到這份使用者操作指引文件中

這個文件的目的在於，使用者看完這份文件之後，可以下載程式，進行第三方工具安裝與檢測確認，啟動與使用這個系統，並且有相關 FAQ 問題排除指引，並且學會這個系統的操作，全部都寫在這一份文件內。若有不清楚或者疑問的地方 ，需要反覆與我確認，直到理解我真正的需求
