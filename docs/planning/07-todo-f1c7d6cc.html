第四階段：品質保證（✅ 完成 v0.2.68；QA-2/3/4 + 門檻鎖定）

  • ☑QA-2（v0.2.62）：LLM 自評信心分數 + 自動門檻（高信心自動已清洗、低信心轉待審核）。KnowledgeSource.ConfidenceScore、狀態「待審核」、Cleaning.ConfidenceThreshold（預設 0.7）；信心自評失敗/無法解析保守轉待審核；待審核可檢視結果與重新清洗。
  • ☑QA-3（v0.2.65）：人工審核關卡（待審核 → 核准→已清洗／退回→已退回；記錄 ReviewedBy/ReviewedAt）。新增專屬「知識審核」動作權限；服務層強制權限＋團隊權控。校正（編輯清洗內容）未做，留後續。
  • ☑QA-4（v0.2.66）：清洗品質評測集（應用內「清洗品質評測」頁，角色_黃金評測 權限）。GoldenSample 樣本 CRUD ＋一鍵載入合成種子；CleaningEvaluator 純函式量化遮罩漏判（recall）、分類 P/R/F1、摘要關鍵實體涵蓋率；門檻掃描（0.5~0.9）＋建議門檻（校準僅供參考，套用改 appsettings）。摘要採啟發式涵蓋率（未用 LLM 評審）。
  • ☑於 strategy/05-待釐清問題 §五 補登並鎖定可接受門檻數值（v0.2.68）：信心 0.70（強制）、校準目標精準 0.90、遮罩召回率 ≥0.98、必留詞 100%、分類 F1 ≥0.70、摘要涵蓋率 ≥0.60；量測 vs 硬閘與回歸用法載明。
  • ☑驗收：低信心來源確實進審核流程（QA-2，CleaningProcessor 已實作並有單元測試）；清洗品質評測集可量化準確率並作回歸（QA-4，門檻已鎖定為回歸基準）。端到端真實樣本品質驗證留第五階段 PoC。
