旗艦簡報・講者指南與使用說明

教你如何使用這套簡報、如何報告、如何應對客戶提問

  • 文件用途：教你如何使用這套簡報、如何報告、如何應對客戶提問
  • 搭配檔案：KnowledgeExtraction-AI-旗艦簡報.md / .html / .pptx
  • 對應系統版本：1.0.14（2026/07/18）
  • 場合定位：首次接觸客戶、15–20 分鐘
  • 編碼：UTF-8（繁體中文，含 BOM）

〇、最重要的一條原則：誠實、可驗證

這套系統的匯入 → 清洗 → 蒸餾 → 知識庫 → AI 問答四階段閉環皆已上線、可現場 demo： 文件／音訊／影片／圖片萃取、佇列化與重試、去重/遮罩/分類/摘要清洗、知識頁審核成互連 Wiki 頁（含版本化與知識百科）、向量＋關鍵字混合檢索、帶出處且權控的問答助理、檢索品質評測、MCP 對外 AI Agent 整合（5 工具、雙認證）、經營統計報表與 24 項系統健康監控——都是現貨。 仍在規劃的是「AI Agent 自動化多步驟工作流」與「授權/計費保護機制」，這些是後續項目，不要宣稱為現貨。

報告時請守住一個框架——「完整閉環已可用、可當場驗證，Agent 工作流為下一步願景」：

  • 自信地描述完整願景與閉環，並可現場展示匯入→清洗→問答的真實流程（見 Q&A 第 1 題）。
  • 唯獨 AI Agent 自動化工作流要誠實說明「規劃中」，不要宣稱現在就能自動跑多步驟流程。
  • 有任何未上線細節（如結構化 PDF 專屬處理），據實說明為後續增強。

能當場驗證，最有說服力。誠實，反而讓你顯得專業、可被信賴。

二、報告前的準備

  1. 填好聯絡方式：把簡報最後一頁的 {{聯絡方式}} 換成你的窗口與聯絡資訊。
  2. 準備一個端到端 demo：挑一段會議錄音或一份 PDF，現場示範「上傳 → 逐字稿／Markdown → 清洗遮罩 → 蒸餾知識頁 → 進知識庫 → 對它提問拿到帶出處答案」。整條閉環都真的能 demo。
  3. 想好試點情境：依客戶產業，預先想一個最有感的高頻情境（會議留存／新人交接／SOP）。
  4. 測試放映：開 html 全螢幕跑一遍，確認字級、顏色、翻頁正常。

四、逐頁講稿（口語版）

以下是建議講詞，照著講或改成你的口吻皆可。（停） 表示刻意停頓。

第 1 頁・開場 「我先問一個問題——你公司每天，是不是都在『重複付錢』？（停）付錢請人，去找同一份資料、問同一個人、等同一個答案。」

第 2 頁・1.8 小時 「有個數字：員工平均每天花 1.8 小時找資料、問人、等回覆。一年算下來，等於 22 個工作天，就這樣蒸發。這是業界估算，但我相信你心裡有數。」

第 3 頁・品牌 「我們做的這套系統，叫 KnowledgeExtraction.AI。它做一件事——把你公司的資訊，變成找得到、用得上的知識。」

第 4 頁・你是否遇到 「你看看這幾個狀況，有沒有很熟悉？（逐條輕點，不要每條都念完）」

第 5 頁・每天在花錢 「這些不是『不方便』而已，它每天都在花你的錢：時間、重工、決策變慢、知識流失、還有合規風險。只是從來沒被算進帳。」

第 6 頁・最貴的一件事 「但最貴的是這個——你公司最重要的知識，只在某些人腦袋裡。（停）他在，一切順暢；他一走，從零開始。」

第 7 頁・承諾 「我們要做的，是把這 1.8 小時，變成一句話、30 秒。問一句，得到帶出處的答案。而且——資料留在公司、權限可控、全程可稽核。」

第 8 頁・閉環 「怎麼做到的？一條龍：資料匯入、清洗、蒸餾、進知識庫、最後變成應用。每一段我快速說明。」

第 9–14 頁・能力 「匯入——這部分現在就能用：文件、音訊、影片、圖片，丟進來就自動變文字。（可在此切去 demo）清洗，把雜訊去掉、敏感資訊遮起來。蒸餾，不是搬原文，是把『真知識』萃取出來。進到知識庫，問什麼都找得到，而且帶出處、只給你看得到的內容。最後是旗艦應用——AI 知識助理，30 秒給你帶出處的答案。」

第 15 頁・能力總覽（關鍵頁，務必誠實） 「我要很坦白地告訴你我們在哪裡：匯入、清洗、蒸餾、知識庫、帶出處的問答助理——現在就是現貨，今天就能當場示範。唯一還在規劃的是『AI Agent 自動化工作流』，那是我們的下一步。所以你看到的不是空談，是可以馬上被你驗證的完整閉環。」

第 16–19 頁・差異化 「你可以選地端或雲端——受限產業就地端，資料不出公司。資安不是我們事後補的，是第一天就內建：權控、遮罩、稽核。跟市面上的方案比，我們最大的不同是『真・地端』加『完整閉環』。它不只是一個聊天框。」

第 20–23 頁・情境（挑一個深講） 「舉個例子（停）——假設一家中型企業每週開幾十場會……」

第 24–28 頁・導入 「導入沒有想像中難。我們立基在成熟平台上，分階段做，先挑一個高頻情境試點，量測效益再擴大。整個試點到上線大概 8 到 12 週。」

第 29 頁・收尾 「所以下一步很簡單：選一個情境、小範圍試、看數字。（停）讓知識，成為你的競爭力。我們找個時間，安排一次需求對談跟展示，好嗎？」

五、Q&A 應對（最關鍵）

Q1：現在可以 demo 問答助理嗎？／可以馬上看到知識庫嗎？

「可以，現在就能。你給我一段會議錄音或一份 PDF，我當場示範完整流程——自動轉逐字稿／結構化、清洗遮罩、蒸餾成知識頁、進知識庫，然後我直接對它提問，讓你看到帶出處、只回你有權限內容的答案。整條閉環都是現貨。」

Q2：那 AI Agent 自動化工作流呢？什麼時候能用？

「基礎已經有了——我們已上線 MCP 對外整合，Claude／Codex 等外部 AI Agent 現在就能透過 5 個知識工具、沿用同一套權控與稽核安全查我們的知識庫。再往上的『多步驟自動化編排』（Agent 自己串起一連串任務）是規劃中的下一步。目前閉環（匯入→清洗→知識庫→問答）與對外整合皆已上線可用；完整自動化工作流會在後續迭代交付，導入時可一起排進路線圖。」

Q3：跟 ChatGPT／Copilot 有什麼不一樣？

「三個關鍵差別：第一，資料可留在公司（地端私有部署），不必上雲。第二，權限控管延續團隊層、於檢索層即過濾，越權內容不會被看到。第三，我們是完整閉環——從匯入、清洗到帶出處的問答，不是只給你一個聊天框。」

Q4：我們的資料安全嗎？會不會外流？

「可以選擇地端／私有部署，資料完全不出你的環境。系統內建敏感資訊遮罩與存取稽核——誰、何時、問了什麼、看了哪些來源，全程留痕。」

Q5：要多少錢？多久能上線？

「我會依你的試點規模與部署模式報價。時間上，試點到上線中型規模約 8–12 週。建議先用一個高頻情境做試點，用最小成本驗證效益，再決定擴大。」

Q6：那個 1.8 小時、ROI 數字哪來的？

「那是業界估算，用來示意量級。實際效益我們會在你的試點情境裡真實量測——例如查找時間、整理工時，用你的數字說話。」

Q7：我們資料量很大／格式很雜，吃得下嗎？

「現在就支援 PDF／Word／PPT／Excel、音訊、影片、圖片，並用背景佇列批次處理、自動重試。中型規模（數萬文件、數百使用者）是我們設定的目標範圍；更大規模我們在導入評估時一起確認。」

六、反對意見處理

客戶心裡的話你的回應方向
「聽起來還沒完全做好」強調完整閉環（匯入→清洗→知識庫→問答）已上線、可當場示範；僅 Agent 自動化工作流為規劃中，風險在試點裡被控制
「我們已經有 SharePoint／雲端硬碟」那是存放，我們做的是找得到、用得上、帶出處、可問答——是知識，不是檔案櫃
「怕導入很痛」立基成熟平台、單一情境試點、8–12 週、每兩週驗收，風險小、可回頭
「主管會擔心資安」地端私有部署＋遮罩＋稽核，第一天就內建，正是為合規而生
「先看看再說」提議最小成本試點：選一個情境、給一批資料，先量測，數字說話

七、收尾促單話術

  • 二擇一收束：「我們下一步，是先安排一次 30 分鐘的需求對談，還是直接抓一個情境做小型試點？」
  • 降低門檻：「試點不必大，挑一個你最有感的情境就好，先用最小成本看到效益。」
  • 製造行動：「你方便給我一個窗口跟一批試點資料嗎？我這邊就能幫你估時程跟範圍。」

目標不是當場成交，而是拿到下一個明確動作：一場對談、一個窗口、一批試點資料。
