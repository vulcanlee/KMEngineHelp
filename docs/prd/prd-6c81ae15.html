上游清洗整體設計見 資料清洗與品質保證 PRD；操作教學見 清洗品質評測使用指南。

一、目標與範圍

清洗品質評測是資料清洗品質的回歸測試頁。使用者建立人工標註樣本，系統用目前清洗提示詞與 LLM 跑一次清洗增強，再以確定性指標比對標準答案，量化遮罩、保留詞、分類與摘要品質。

本 PRD 範圍包含 /golden-samples 的樣本 CRUD、載入種子、評測此筆、評測全部、彙總儀表板與明細 JSON。非範圍包含直接修改系統清洗門檻、套用特定清洗規則設定、評測真實知識來源清單。

二、使用者與入口

項目說明
路由/golden-samples
選單知識庫 → 清洗品質評測
權限MagicObjectHelper.角色_黃金評測
主要使用者QA、知識管理者、導入顧問、開發者

清洗品質評測評的是「黃金樣本自己的 InputText」，完全不讀「知識來源加工」的紀錄，也不改任何真實清洗結果。

三、畫面與欄位

樣本欄位：

欄位說明
Title樣本標題
InputText要餵入清洗增強器的原始文字
ExpectedMaskedTerms應被遮罩的詞，每行一項
MustKeepTerms應保留的詞，每行一項
ExpectedCategories預期分類，每行一項
ExpectedSummaryEntities摘要應涵蓋的關鍵實體，每行一項
HumanPass人工認定該樣本清洗是否應通過

清單顯示最近評測時間、最近信心、遮罩 Recall、分類 F1、摘要涵蓋率與操作按鈕。儀表板顯示已評測數、平均指標、建議門檻與目前門檻。

四、內部系統運作

核心流程為 GoldenSampleView → GoldenSampleService → CleaningEnhancer → CleaningEvaluator。

  1. 使用者新增或編輯樣本，清單欄位以 TagStringHelper.ToStored 儲存為分隔字串。
  2. 按「評測此筆」時，GoldenSampleService.EvaluateOneAsync(id) 讀取該樣本。
  3. 服務呼叫 CleaningEnhancer.EnhanceAsync(adapter.InputText)，使用目前全域清洗提示詞與 LLM 產生清洗結果。
  4. 若 LLM 未設定，CleaningEnhancer 回傳 Skipped，評測失敗並提示未設定 LLM。
  5. 若 LLM 執行成功，CleaningEvaluator.Evaluate(adapter, enh) 以純函式計算指標。
  6. 指標序列化到 LastMetricsJson，並更新 LastConfidence、LastEvaluatedAt、UpdatedAt。
  7. GetAggregateAsync 只彙整 LastMetricsJson != null 的已評測樣本。

五、LLM 與提示詞

  • 清洗品質評測重用清洗增強器，因此會依序使用清洗去重、遮罩、分類、摘要、信心五段提示詞。
  • 提示詞來源為全域解析：DB Prompt 的 清洗-* 鍵、appsettings、程式 fallback。
  • 目前不傳入 CleaningProfile，所以不會套用某一筆知識來源的清洗規則設定。
  • 評測過程會真的呼叫 LLM，費用、延遲與模型行為皆等同一次清洗增強。

六、指標與校準

指標說明
MaskRecall應遮詞是否被遮掉；合規關鍵
MustKeepOk必留詞是否全數保留
ClassifyPrecision / Recall / F1建議分類與人工分類集合比對
SummaryCoverage摘要是否涵蓋人工標註實體
PrecisionVsHuman / RecallVsHuman依 HumanPass 與信心門檻做校準參考

建議門檻只供參考。真正影響清洗流程的是 SystemSettings.Cleaning.ConfidenceThreshold，需由維運者修改設定並重啟後才生效。

七、安全與資料影響

  • 黃金樣本不套團隊權控，屬品質測試資料；應避免放入真實未遮罩個資。
  • 評測只更新樣本的最近評測欄位，不修改知識來源、清洗結果、提示詞或 appsettings。
  • LLM 日誌不得記錄完整樣本文本或完整回應。

八、錯誤與邊界

  • 沒有任何已評測樣本時，彙總報表應顯示 0 或無建議門檻，不可因空集合崩潰。
  • 已有樣本時「載入種子」不應覆蓋現有樣本。
  • LLM 失敗時只回報該筆評測失敗，不刪除既有最近評測結果。

九、驗收與測試

  • 可新增、編輯、刪除、搜尋與分頁黃金樣本。
  • 種子只能在空清單載入。
  • 評測此筆會更新 LastMetricsJson、LastConfidence 與 LastEvaluatedAt。
  • 無已評測樣本時頁面不崩潰。
  • 指標計算由 CleaningEvaluatorTests 覆蓋。

十一、0.3.34 現況校正

  • 清洗品質評測只讀每筆樣本自己的原始輸入與標準答案，不讀知識來源、不改正式清洗結果。
  • 指標包含遮罩召回、分類 Precision／Recall／F1、摘要涵蓋率、最近信心與門檻掃描；無已評測樣本時建議門檻為空，不可對空序列取最大／最小值。
  • 建議門檻只供校準；正式清洗門檻仍為 SystemSettings.Cleaning.ConfidenceThreshold，與 RAG Reject／LowConfidence 門檻不同。
