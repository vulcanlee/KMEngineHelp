一、目標與範圍

檢索品質評測是知識庫檢索品質與權控合規的回歸測試頁。使用者建立問句樣本與期望命中來源，系統以模擬身分對整個已索引知識庫執行混合檢索，再計算 Precision@k、Recall@k、NDCG@k、MRR、出處正確率、越權洩漏與延遲。

本 PRD 範圍包含 /rag-evaluation 的樣本 CRUD、載入範本、評測此筆、評測全部、彙總儀表板與明細 JSON。非範圍包含 LLM 生成答案評分、改變實際問答結果、重建索引。

二、使用者與入口

項目說明
路由/rag-evaluation
選單知識庫 → 檢索品質評測
權限MagicObjectHelper.角色_RAG評測
主要使用者QA、知識管理者、導入顧問、開發者

檢索品質評測評的是「使用者建立的問句樣本」，檢索打的是「整個已索引知識庫」。未經清洗、蒸餾與索引的來源不會被命中。

三、畫面與欄位

欄位說明
Title樣本名稱
Query送入混合檢索的問句
ExpectedSourceTitles期望命中的知識來源標題，每行一項
ExpectedAnchors期望命中的錨點，每行一項，可空
EvalTeams評測時模擬使用者團隊，每行一項
EvalIsAdmin是否模擬管理員

儀表板顯示已評測數、平均 Precision/Recall/NDCG/MRR、平均出處正確率、越權洩漏總數與平均延遲。越權洩漏只要大於 0 即為資安紅線。

四、內部系統運作

核心流程為 RagEvaluationView → RagEvaluationService → IRetrievalService → RagEvaluator。

  1. 使用者新增樣本，標註問句、期望來源、錨點與模擬身分。
  2. RagEvaluationService.EvaluateOneAsync(id) 讀取樣本，組成 RecordAccessScope(entity.EvalIsAdmin, EvalTeams)。
  3. 呼叫 retrievalService.RetrieveAsync(entity.Query, new RetrievalQuery(scope), ct) 對整庫混合檢索。
  4. RetrievalService 先產生 query embedding；若嵌入未設定或向量路徑失敗，退化為關鍵字檢索。
  5. 服務載入命中 chunk 對應的 KnowledgeSource.Title，組成 RagEvalHit。
  6. 每個命中再用 TagStringHelper.IsTeamAccessible 二次判斷是否越權，作為回歸守門。
  7. RagEvaluator.Evaluate 以純函式計算指標。
  8. 指標序列化到 LastMetricsJson，並更新 LastEvaluatedAt、LastLatencyMs、UpdatedAt。

五、LLM / Embedding / RAG 細節

  • 本功能不呼叫 chat LLM 生成答案，因此評測結果是確定性的檢索指標。
  • 若 embedding 已設定，會使用 IEmbeddingClient 產生 query 向量，並透過 IVectorStore.SearchAsync 取候選。
  • 關鍵字路徑以 query 切詞後對 VectorEmbedding.ChunkText 做 OR 查詢。
  • 向量與關鍵字分數由 SystemSettings.Retrieval 的權重融合，最後依 TopK 與 MinScore 篩選。

六、權控與資料影響

  • 評測可用樣本內的 EvalTeams / EvalIsAdmin 模擬不同身分，不使用目前登入者的團隊作為檢索 scope。
  • 檢索層依模擬 scope 套團隊權控；非管理員只可命中公開或團隊交集 chunk。
  • 評測只更新樣本的最近指標欄位，不改變向量索引、不影響實際 AI 知識問答、不修改來源資料。

七、錯誤與邊界

  • 沒有已評測樣本時，彙總報表應顯示 0，不可崩潰。
  • 期望來源標題若與知識來源標題不一致，Recall 會偏低；這是標註問題，不由系統自動修正。
  • 未設定嵌入時仍可評測，但結果代表關鍵字退化品質，不代表正式語意檢索品質。

八、驗收與測試

  • 可新增、編輯、刪除、搜尋與分頁 檢索品質評測樣本。
  • 評測此筆會更新 LastMetricsJson、LastLatencyMs 與 LastEvaluatedAt。
  • 模擬受限團隊時，越權洩漏應為 0。
  • 管理員樣本可命中所有有關來源。
  • RagEvaluatorTests 覆蓋 P/R/NDCG/MRR/出處/越權指標。

十、0.3.34 現況校正

  • 評測為純檢索，不呼叫 LLM 生成；針對全部已索引內容套模擬團隊／管理員權限。
  • 支援 ExpectedSourceTitles、ExpectedAnchors、P@k、R@k、NDCG、MRR、延遲與越權洩漏；來源標題用於重建索引後穩定比對。
  • 支援查詢期參數基線快照，記錄 TopK、CandidateTopK、權重、MinScore、Reject 與 LowConfidence，便於回歸比較。
  • 越權洩漏必須為 0；任何非 0 都是安全失敗，不以平均分數抵銷。
