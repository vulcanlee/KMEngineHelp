產品需求（PRD）

知識百科與 Wiki 導覽 PRD

  • 文件版本：1.0
  • 文件狀態：已實作
  • 現行系統版本：1.0.62
  • 首次實作版本：0.3.13
  • 最後核對日期：2026/07/25

一、產品目標與範圍

提供一般讀者以百科方式閱讀已完成的 Wiki 概念頁，不必進入管理者用的蒸餾審核頁，也不必先會使用 RAG 問答。入口為 /knowledge-wiki，涵蓋概念索引、搜尋與篩選、WikiLink 導覽、版本閱讀、複製、PDF 匯出及團隊權控。

本能力只呈現已完成的 Wiki 頁，不負責產生、審核或重建內容；這些流程由《知識頁審核 PRD》及《嵌入索引與混合檢索 PRD》負責。

二、使用者與入口

  • 一般讀者：閱讀自己有權存取的公開或團隊概念。
  • 知識維護者／審核者：核對已發布成果與概念連結。
  • 入口：左側「知識庫 → 知識百科」，路由 /knowledge-wiki。

三、現行功能需求

3.1 概念索引

  • 左欄列出已完成概念，以分類分組；未分類項目仍須可見。
  • 支援依概念標題搜尋、分類多選及團隊多選篩選。
  • 沒有已完成頁面時顯示空狀態；有資料但篩選無結果時顯示不同提示。

3.2 閱讀與導覽

  • 右欄呈現標題、版本資訊、渲染後 Markdown 與操作列。
  • 內文 [[概念標題]] 可導向相符概念；找不到或無權存取時不得洩漏概念內容。
  • 未選概念時提示從左側選取；深連結或內部導覽失敗時維持安全空狀態。

3.3 版本與匯出

  • 顯示可讀版本歷史，標示版本、狀態及日期；預設呈現現行已完成版本。
  • 支援複製原始 Markdown 與將目前概念下載為 PDF。
  • PDF 與複製內容必須與畫面上已授權版本一致。

四、權限與安全

  • 非管理員只可讀取 Teams 空白（公開）或與角色預設團隊有交集的概念；管理員不受限制。
  • 查詢、單筆讀取、WikiLink 導覽及 PDF 下載都必須套用相同團隊權控，不能只在左欄隱藏。
  • Markdown 以禁用原始 HTML 的安全渲染器呈現，避免儲存型 XSS。
  • 分類／團隊採精確標籤比對，不得以子字串造成誤命中。

五、資料與依賴

  • 主要資料：WikiPage／WikiPageAdapterModel、內容檔案、來源繼承的分類與團隊。
  • 上游：知識來源已清洗並完成蒸餾／審核。
  • 下游：讀者可從概念理解知識；RAG 索引是否可檢索由索引管線另行管理。
  • 主要程式：KnowledgeWikiPage.razor、Components/Views/KnowledgeWiki/**、Wiki 讀取服務與 PDF 產生服務。

六、錯誤與邊界

  • 無內容、無篩選結果、找不到概念與無存取權必須有可理解但不洩漏資訊的訊息。
  • 內容檔案遺失時不得顯示空白成功頁；應留下錯誤日誌並提示管理員檢查一致性。
  • PDF 失敗不影響閱讀；顯示失敗訊息並允許重試。

七、驗收條件

  1. 有權使用者能搜尋、篩選、閱讀並沿 [[概念]] 導覽。
  2. 無權使用者不能從清單、深連結、WikiLink 或 PDF 取得受限內容。
  3. 版本列能切換可讀版本，預設版本與現行狀態一致。
  4. 複製及 PDF 內容與目前授權頁面一致。
  5. 空狀態、篩選無結果及檔案遺失各有明確行為。

八、規劃中需求

  • 尚未實作：跨概念關係圖、收藏／訂閱、概念差異比較及發布通知。
  • 以上不得視為 0.3.34 現行能力。
