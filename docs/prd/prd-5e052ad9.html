一、目標與範圍

提供安全且可維運的帳號入口：本地帳號密碼登入、驗證碼、記住我、Google OAuth 登入、待審核頁、登出、強制改密碼，以及 Google 使用者設定 API 密碼以取得 JWT。

本 PRD 範圍包含 /Auths/Login、/Auths/Logout、/Auths/Pending、/Auths/Google/Login、/Auths/Google/Callback、/ChangePassword、/Profile。非範圍包含自助註冊、忘記密碼信件、MFA、refresh token 撤銷。

二、使用者與入口

流程路由使用者
本地登入/Auths/Login所有使用者
Google 登入/Auths/Google/LoginGoogle OAuth 啟用時
待審核/Auths/Pending新建且未啟用 Google 使用者
登出/Auths/Logout已登入使用者
強制改密碼/ChangePassword使用預設密碼的本地使用者
設定 API 密碼/Profile已登入使用者，特別是 Google 帳號

三、畫面與操作

  • 登入頁：帳號、密碼、驗證碼、記住我、Google 登入按鈕（設定完整時顯示）。
  • Pending 頁：提示 Google 驗證已完成，但需管理員啟用帳號。
  • ChangePassword：輸入目前密碼、新密碼、確認新密碼。
  • Profile：設定本地 API 密碼；若已有本地密碼需輸入目前密碼，Google 帳號首次設定可免舊密碼。
  • Layout 使用者選單：變更密碼、設定 API 密碼、登出。

四、內部系統運作

本地登入流程：

  1. Login.razor 驗證帳號、密碼與驗證碼。
  2. MyUserServiceLogin.LoginAsync 查詢使用者並驗證 salt + SHA 密碼。
  3. 成功後建立 Cookie claims，使用 MagicObjectHelper.CookieScheme。
  4. AuthenticationStateHelper.Check 在後續頁面載入使用者、角色與預設團隊。
  5. 若密碼仍為 MagicObjectHelper.NeedChangePassword，導向 /ChangePassword。

Google OAuth 流程：

  1. 登入頁顯示 Google 按鈕的條件為 GoogleOAuthSettings.IsConfigured。
  2. /Auths/Google/Login 觸發 Google challenge。
  3. Google 回 /signin-google，再進 /Auths/Google/Callback。
  4. ExternalLoginService 先以 GoogleId 比對，再以 email 連結，否則建立停用本地帳號。
  5. 停用帳號導向 /Auths/Pending；啟用帳號建立 Cookie 登入。

密碼流程：

  1. /ChangePassword 供已登入且需改密碼者更新本地密碼。
  2. /Profile 呼叫 MyUserService.SetOwnApiPasswordAsync，讓 Google 帳號可用 email + API 密碼呼叫 JWT login。

五、LLM / RAG 互動

帳號流程不呼叫 LLM、不使用 embedding。它會決定所有 AI 功能的身分、角色權限與團隊 scope，是後續清洗、問答、檢索品質評測權控的基礎。

六、權限與安全

  • Cookie 登入、API JWT 與 MCP 專用 X-API-Key（McpApiKey，1.0.5 起）是三條不同 authentication scheme；MCP 端點 /mcp 以 McpAccess policy 接受三者任一。MCP 金鑰（McpAccessKey）由管理員於 /mcp-api-keys 管理，其 UserId 對映既有帳號決定團隊 scope。
  • 密碼只存 hash 與 salt，不存明碼。
  • Google OAuth 用戶端密鑰必須透過安全設定來源提供。
  • Google 自動建帳預設停用，需管理員審核。
  • support 預設開發帳號禁止透過 Profile/ChangePassword 一般流程任意變更。
  • 日誌不得記錄密碼、token、OAuth secret。

七、錯誤與邊界

  • 驗證碼錯誤時不得嘗試登入。
  • Google 回呼缺 email 或 subject 時登入失敗並導回登入頁。
  • 使用者停用、角色缺失、權限 JSON 壞掉時，應導出或拒絕。
  • /Profile 新密碼與確認密碼不一致時拒絕儲存。

八、驗收與測試

  • 本地帳號可用正確帳密登入，錯誤帳密不可登入。
  • Google OAuth 未設定時登入頁不顯示 Google 按鈕。
  • Google 新帳號預設導向 Pending，管理員啟用後可登入。
  • 預設密碼使用者登入後被導向 ChangePassword。
  • Profile 可設定 API 密碼，供 /api/Auth/login 使用。

十、0.3.34 現況校正

  • 本地登入包含驗證碼與「記住我」；Google 新帳號導向 /Auths/Pending，待管理員啟用。
  • 強制改密碼、個人資料及 Google 使用者設定 API 密碼分屬 /ChangePassword、/Profile 與 API 認證流程。
  • Cookie／JWT／API 密碼用途不同；任何 PRD、畫面或日誌不得把明文密碼、存取 token 或 refresh token 當一般欄位顯示。
