產品需求（PRD）

檢索診斷與查詢期調校 PRD

  • 文件版本：1.0
  • 文件狀態：已實作
  • 現行系統版本：1.0.62
  • 首次實作版本：0.3.3–0.3.6
  • 最後核對日期：2026/07/25

一、產品目標與範圍

讓管理員在 /rag-diagnostics 用實際問答稽核資料與索引狀態判斷「為何查不到、為何信心低、門檻是否合理」，並在不重啟系統下安全調校查詢期參數。此能力不修改來源內容、不執行 LLM 生成，也不取代 檢索品質評測回歸集。

二、使用者與入口

  • 僅管理員可見及操作。
  • 入口：系統管理 → 檢索診斷與調校，路由 /rag-diagnostics。
  • 典型時機：查無依據增加、低信心增加、引用不相關、內容明明存在卻查不到。

三、現行功能需求

3.1 門檻觀察與調整

  • 顯示目前生效與建議的 RejectThreshold、LowConfidenceThreshold。
  • 合法關係為 0 ≤ RejectThreshold ≤ LowConfidenceThreshold ≤ 1。
  • 支援手動套用、套用建議及回復設定預設；套用後下一則問答熱生效。
  • 顯示是否有執行期覆蓋，避免管理員誤認已永久寫回 appsettings.json。

3.2 查詢期參數

  • 顯示並可調整 TopK、CandidateTopK、VectorWeight、KeywordWeight、MinScore 等查詢參數。
  • 權重與數值必須通過服務端驗證；不合法組合不可生效。
  • 調整只影響後續查詢，不回寫既有問答或評測結果。

3.3 分析與模擬

  • topScore 分佈呈現實際檢索分數區間。
  • 門檻效果模擬以既有稽核資料估算查無依據、低信心及正常回答比例，不改動正式設定。
  • 樣本不足時明確標示建議不可靠，不以少量資料自動套用。

3.4 索引健康、自檢與試檢索

  • 顯示已清洗／已索引來源、片段數、Cleaned／Wiki chunk、最後索引時間與紅黃綠狀態。
  • 自檢列出嵌入未設定、空索引、過時來源及樣本不足等症狀。
  • 試檢索接受查詢與權限範圍，顯示命中來源、片段、向量／關鍵字／融合分；不呼叫 LLM。
  • 顯示近期問答稽核紀錄，供管理員連結症狀與實際案例。

四、權限、安全與資料影響

  • 頁面僅管理員可見；服務端仍須驗證管理員，不可只依選單隱藏。
  • 試檢索必須依指定或目前權限範圍套團隊過濾，不能成為越權內容預覽器。
  • 熱套用會影響所有後續問答，必須記錄操作者、時間、舊值與新值。
  • 頁面不得顯示 API Key、完整秘密或不必要的敏感原文。

五、錯誤與恢復

  • 不合法門檻或參數顯示明確訊息且不更新目前值。
  • 診斷資料不足時保持頁面可用，以提示取代錯誤結論。
  • 嵌入端點不可用時試檢索可顯示關鍵字退化或失敗原因。
  • 回復預設只移除執行期覆蓋；永久設定仍以 appsettings.json 為來源。

六、驗收條件

  1. 非管理員無法進頁或呼叫調校服務。
  2. 門檻與查詢參數合法值能熱生效，不合法值保持原設定。
  3. 模擬不改正式設定，套用與回復能從頁面狀態辨識。
  4. 索引健康、自檢及試檢索可定位空索引、過時來源及低分命中。
  5. 試檢索不呼叫 LLM，且越權片段命中為 0。
