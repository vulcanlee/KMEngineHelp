產品需求（PRD）

嵌入索引與混合檢索 PRD

  • 文件版本：1.0
  • 文件狀態：已實作
  • 現行系統版本：1.0.62
  • 首次實作版本：0.2.123–0.2.126
  • 最後核對日期：2026/07/25

一、產品目標與範圍

將已清洗長文與已完成 Wiki 概念切成可追溯片段，產生向量並寫入向量儲存，再以語意向量與關鍵字融合檢索，提供 AI 知識問答、檢索品質評測及診斷試檢索一致的證據來源。

本 PRD 負責「建立索引及取回證據」；不負責 LLM 生成答案，也不負責 PDF 專屬結構感知解析。

二、使用者與入口

  • 知識維護者：在知識來源清單觀察索引狀態、單筆建立／重建索引。
  • 管理員：執行全量重建、查看索引健康與查詢期參數。
  • 消費端：/knowledge-base-chat、/rag-evaluation、/rag-diagnostics。

三、索引需求

3.1 輸入與切塊

  • 索引來源包含清洗後長文及該來源已完成 Wiki 頁；每個 chunk 保留來源、頁面、分類、團隊、版本與可追溯錨點。
  • 切塊參數由設定提供；內容或版本變更後必須能判定索引過時。
  • 蒸餾完成後自動觸發索引；維護者亦可對單筆來源補建或重建。

3.2 嵌入與儲存

  • 支援雲端或地端嵌入端點；向量維度必須與目前模型及資料庫欄位相容。
  • 嵌入端點未設定時，語意檢索停用並明確警告；關鍵字檢索仍可退化運作。
  • 寫入採增量差異：移除已不存在片段、加入新增或變更片段，未變內容避免重算。

3.3 狀態與背景處理

  • 狀態：待索引 → 等待中 → 處理中 → 已索引／失敗／已取消。
  • 佇列在記憶體；啟動時重新排入等待中／處理中工作。
  • 失敗保留錯誤訊息並允許重試；取消必須透過共用取消註冊表中止。
  • 管理員可全量重建；操作前需確認模型、參數、時間與 Token／嵌入成本。

四、檢索需求

  • Query Rewrite 可將對話問題改寫為檢索查詢；失敗時保留原查詢降級。
  • 先取 CandidateTopK 候選，再以向量分數與關鍵字分數依 VectorWeight／KeywordWeight 融合。
  • 兩路候選集皆須先排序再截斷：向量路徑依 cosine，關鍵字路徑依命中詞數（1.0.16 起）。無序截斷會使高相關片段無法進入融合階段。
  • TopK 控制最終片段數，MinScore 排除低於最低分的片段。
  • 支援限定一或多個知識來源與分類；限制條件與團隊權控須同時生效。
  • RejectThreshold 與 LowConfidenceThreshold 判定證據不足／低信心／正常回答，且需符合 0 ≤ Reject ≤ LowConfidence ≤ 1。

五、權限與安全

  • 每次查詢都以 IRecordAccessScopeProvider 取得管理員狀態與允許團隊，在資料層先過濾後才計分。
  • 非管理員只可命中公開或團隊交集片段；管理員不受限。
  • 來源／分類限制不得繞過團隊權控；檢索品質評測的模擬團隊使用同一規則。
  • 查詢及日誌不得記錄 API Key、Token 或完整敏感本文。

六、資料與介面

  • 主要資料：VectorEmbedding、chunk metadata、KnowledgeSource 索引狀態與時間。
  • 主要服務：EmbeddingIndexProcessor、EmbeddingIndexQueue、IRetrievalService 及向量儲存實作。
  • 主要設定：SystemSettings.Retrieval 下的 TopK、CandidateTopK、權重、MinScore、RejectThreshold、LowConfidenceThreshold，以及嵌入提供者設定。

七、錯誤與恢復

  • 嵌入不可用：標示索引失敗或語意退化，不得假裝完整語意檢索正常。
  • 個別片段失敗：整筆來源保留可診斷錯誤；修正端點／內容後單筆重試。
  • 全量重建屬高成本管理操作；不得作為一般單筆失敗的第一處置。
  • 內容檔案遺失或版本過時交由一致性巡檢顯示，避免查詢引用舊內容。

八、驗收條件

  1. 已清洗／蒸餾來源可完成索引並產生 Cleaned 與 Wiki 片段統計。
  2. 語意與關鍵字混合檢索能命中代表性查詢；關鍵字退化模式有明確警告。
  3. 來源／分類限制正確縮小結果，且不能繞過團隊權控。
  4. 非管理員越權命中數為 0。
  5. 取消、失敗重試、重啟回復與單筆／全量重建符合狀態規則。
  6. 內容改版後舊索引被標記過時，重建後只引用現行版本。

九、規劃中需求

  • 尚未實作：專用 re-ranker、可插拔向量資料庫叢集、跨租戶索引隔離與自動容量分片。
  • PDF 條款／表格／圖表感知切塊仍屬 PDF 型 RAG 處理 PRD 的規劃中能力。
