Sidebar 收合子選單 Hover 修正

摘要

修正側邊欄收合模式下，游標從主選單圖示移動到右側彈出子選單時，子選單容易提前收合、無法彈出，或點擊子項後不再收合的問題。最新修正保留自訂 collapsed flyout，並避免 flyout 子項焦點讓選單持續開啟。系統版本 0.2.52 → 0.2.53。

變更內容

  • 展開側邊欄時維持 AntDesign MenuMode.Inline 與既有 SelectedKeys / OpenKeys 行為。
  • 收合側邊欄時使用自訂 collapsed menu，頂層只顯示固定尺寸圖示。
  • 有子項的頂層選單在 hover 時顯示右側 flyout，並以透明 bridge 維持游標移動期間的 hover 狀態。
  • 移除 flyout 顯示條件中的 :focus-within，避免點擊子功能表項目後焦點留在 link 上造成 flyout 黏住不收合。
  • 保留既有選單資料、權限結構、路由與資料權控邏輯。

驗證

  • dotnet build src/KnowledgeExtraction/KnowledgeExtraction.Web/KnowledgeExtraction.Web.csproj --no-restore
  • dotnet test src/KnowledgeExtraction/KnowledgeExtraction.Tests/KnowledgeExtraction.Tests.csproj --no-restore
  • 啟動站台後於 /prompts 收合側邊欄，驗證頂層圖示置中、右側 flyout 可彈出、游標移入 flyout 時不提前收合，且點擊子項導頁後 flyout 不會黏住。
  • pwsh -File scripts/Test-DocsEncoding.ps1
