工具列圖示規範化：全站動作鈕統一使用 CrudActionButton（0.2.135）

  • 日期：2026-06-27
  • 版本：0.2.134 → 0.2.135
  • 類型：UI 改善 / 開發規範

症狀

各列表頁「操作欄」動作鈕早已統一為共用元件 CrudActionButton（outlined classic Material Icons）， 但工具列的「新增 / 重新整理 / 搜尋 / 清空搜尋」按鈕仍是有邊框的自訂按鈕內嵌 emoji （➕ 🔄 🔍 ❌），與操作欄外觀不一致，全站圖示風格分歧。

調整內容

  • 將所有列表頁（約 17 個 View）工具列的 emoji 按鈕改用 CrudActionButton，與操作欄同元件、同尺寸、同 hover 行為。

另把「管理成員」對話窗內的搜尋鈕（KnowledgeSourceView、SkillView）一併改為 CrudActionButton。

  • 圖示語意對應（皆為 classic Material Icons）：新增 add、重新整理 refresh、搜尋 search、清空搜尋 close。
  • CrudActionButton 本身已內建 Tooltip，轉換時連同外層 Tooltip 一併移除；保留各按鈕原本的事件流程不變。
  • 移除因改用 CrudActionButton 而孤立的 *-view-icon-button scoped CSS 規則。
  • Skills/SkillView 的下載連結維持以文字標籤 md / zip 區分檔案格式（非 emoji、非圖示），記為「允許的文字標籤例外」。

測試強化

  • CrudActionIconTests.AllowedCrudActionIcons 補上 refresh、close。
  • 新增 CrudActionIconTests.Views_DoNotUseLegacyToolbarEmojiIcons：掃描 Views 下所有 .razor，

禁止再出現工具列 emoji（➕ 🔄 🔍 ❌），避免日後回退。

  • 全測試 367 筆通過。

文件

  • docs/architecture/開發慣例與限制速查.md §1.7：把「CRUD 操作欄圖示」擴充為全站動作鈕圖示規範，

明確工具列與對話窗小搜尋鈕也須使用 CrudActionButton，全站不得以 emoji 當圖示。

  • docs/guides/建立一個新 CRUD 操作網頁說明.md：工具列與「圖示一致性」小節補上工具列圖示對應表與範例。

備註

本次僅調整 UI 圖示與文件，未動資料模型、權限、路由，不需 migration、不需權限三處同步。 新增頁面的工具列／操作欄動作鈕，請一律使用 CrudActionButton + classic Material Icons， 並把新圖示名稱加入 CrudActionIconTests.AllowedCrudActionIcons。
