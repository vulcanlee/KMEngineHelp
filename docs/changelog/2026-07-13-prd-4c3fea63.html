新增「知識庫統計報表」PRD 與開發代辦清單（規劃中）

  • 日期：2026-07-13
  • 版本：不升版（純文件・規劃中，實作預計 0.3.37）
  • 類型：文件（規劃）

需求

需要在側邊功能表新增「統計報表」子選單，提供可自訂時間區間的各式統計分析報表：Token 用量統計、使用者 token 用量排名、使用者回饋（喜歡/不喜歡）統計等。本次先產出規劃文件（PRD＋代辦清單），與使用者反覆確認需求與範圍後再進入實作。

變更（文件）

  • 新增 知識庫統計報表 PRD：定義 5 份管理員專用彙總報表（Token 用量分析、使用者回饋分析、問答量與使用行為、檢索品質分析、內容/來源清點），各支援日期區間、（可行範圍內的）團隊/分類過濾與「下載 PDF 報表」。狀態標為「規劃中」。
  • 新增 統計報表開發代辦清單：分六階段可勾選項目。
  • 更新 PRD 主控台「規劃中產品藍圖」新增一列。
  • 更新 文件總索引 prd 與 planning 兩處。

確認過的關鍵決策

  • 存取層級：管理員專用（選單 adminOnly、頁面 CheckIsAdmin()，不進權限樹）。
  • 視覺化：沿用 Dashboard 的 CSS 卡片＋長條，不引入圖表庫。
  • 保留現有 /token-usage、/chat-logs 明細頁，另建彙總報表。
  • 內容清點以素材級（三張上游表）計數；影音/音訊合併為一類。
  • 團隊過濾全報表提供；Token/回饋/問答三報表以新增 LlmTokenUsage/LlmChatLog 的 Teams 快照欄位支援（需雙 migration，僅升版後新資料有值）。分類過濾僅內容清點提供。
  • PDF 匯出沿用既有 QuestPDF＋Noto Sans TC 管線（零新相依）。

已知限制（載於 PRD）

  • 無費用/成本欄位，Token 報表僅呈現原始 token 數。
  • Token/回饋/問答的團隊維度僅對升版後新紀錄有值。
  • 分類過濾僅內容清點；影音/音訊無法從資料模型分離。

後續

實作時依代辦清單推進，完成後將 PRD 狀態改「已實作」、移入主控台矩陣、補實作版 changelog 並升版至 0.3.37。
