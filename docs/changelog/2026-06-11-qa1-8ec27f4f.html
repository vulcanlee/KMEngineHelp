清洗管線（QA-1 端到端最小可用）（0.2.60）

  • 日期：2026-06-11
  • 版本：0.2.59 → 0.2.60
  • 對應路線圖：資料清洗開發代辦清單 第三階段、設計 strategy/08

摘要

知識來源（KnowledgeSource）現可被「清洗」：把其底下成員（跨音訊轉錄／文件萃取／圖片清單三管線）的 已萃取文字彙整 → OpenCC 轉繁體 → 產出清洗後 Markdown，狀態與進度可追蹤，可取消、重試、檢視結果。 本階段為 QA-1（先把端到端跑通），純程式步驟，尚未接 LLM 的去重／遮罩／分類／摘要。

內容

  • 資料模型：KnowledgeSource 新增 Status（草稿／等待中／處理中／已清洗／失敗／已取消，預設「草稿」）、

ProgressPercentage、ErrorMessage、CleanedContentRelativePath、CleanedAt。雙 provider migration AddKnowledgeSourceCleaning（既有資料 Status 回填「草稿」）。

  • 清洗管線（比照既有三管線骨架）：ICleaningQueue／CleaningQueue（Channel<int>，Singleton）、

CleaningBackgroundService（出列、建 scope、IPipelineCancellationRegistry 取消、重啟把「等待中／處理中」重新入列）、 CleaningProcessor（彙整成員文字＋OpenCC 繁體＋產出 {yyyy}/{guid}.md 於 CleanedSourcePath， PipelineRetryHelper 自動重試）。成員只取「已完成」者，未完成略過；全無可用成員則標記失敗。 OpenCC 只套用於成員內文，標題保留原文（避免 文件→檔案 之類用詞替換改動標題）。

  • 服務動作：KnowledgeSourceService 新增 TriggerCleaningAsync／CancelCleaningAsync／

RetryCleaningAsync／GetCleanedContentAsync，全程套團隊權控；觸發需至少一名成員。

  • 設定：ExternalFileSystem.CleanedSourcePath（appsettings 與 Program.cs 目錄準備）。
  • UI：知識來源清單新增「狀態」「進度」欄與 清洗／取消／重試／檢視結果 操作、清洗結果 Modal、5 秒輪詢。
  • 測試：新增 CleaningProcessorTests（彙整＋轉繁體、略過未完成成員、全無可用→失敗）與服務層

觸發測試；全測試 176 筆綠燈。
