修正知識來源清單工具列版面（分類/團隊/搜尋位置）（0.2.64）

  • 日期：2026-06-11
  • 版本：0.2.63 → 0.2.64
  • 類型：Bug 修正

症狀

「知識來源管理清單」頁的工具列，分類過濾、團隊過濾、搜尋關鍵字、搜尋鈕呈垂直堆疊， 與其他清單頁（如「文件萃取」）的單列、左側新增/重整、右側過濾與搜尋版面不一致。

根本原因

工具列版面用的 .project-view-toolbar／-left／-right／-search-input／-icon-button 是 Blazor scoped CSS，各清單 View 於自身 .razor.css 各帶一份（DocumentExtraction、 ImageRecognition、MediaTranscription、ProjectView 皆有）。scoped CSS 不跨元件套用。 新建的 KnowledgeSourceView.razor.css 只放了成員管理用的 .ks-* 樣式，漏掉 .project-view-*， 導致工具列類別無樣式、退回 block 預設而垂直堆疊。

修正

  • KnowledgeSourceView.razor.css：補上 .project-view-toolbar（flex、space-between）、

-left/-right（flex、gap）、-search-input（width:260px）、-icon-button，與其他清單頁一致。

備註

此為各 View scoped CSS 重複的既有模式；新建清單頁時，記得連同 .project-view-* 工具列樣式一併帶入 .razor.css。
