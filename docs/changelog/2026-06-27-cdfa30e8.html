環境檢測腳本補強：.NET 10 執行時 / PowerShell 7.x / npm（0.2.136）

  • 日期：2026-06-27
  • 版本：0.2.135 → 0.2.136
  • 類型：維運 / 環境檢測改善

背景

新機器若缺少必要執行時期軟體，系統會無法執行。原檢測腳本 scripts/Test-ExternalTools.ps1 只檢查外部工具（ffmpeg／yt-dlp／markitdown 與抖音鏈），未檢測本系統最關鍵的 .NET 10 執行時， 也沒有檢查 PowerShell 版本與 npm。

調整內容

scripts/Test-ExternalTools.ps1 新增「平台前置需求」檢測：

  • .NET 10 ASP.NET Core Runtime（阻斷型）：以 dotnet --list-runtimes 比對是否存在

Microsoft.AspNetCore.App 10.x。缺少（或未裝 dotnet）→ 顯示 FAILED、提示 「系統將無法執行」與安裝指令（winget install Microsoft.DotNet.AspNetCore.10），並納入結束碼（缺少→1）。

  • PowerShell 版本（警告型）：檢查 $PSVersionTable.PSVersion，低於 7 → 警告並提示

winget install --id Microsoft.PowerShell -e；不影響結束碼（程式本身不需 PowerShell）。

  • npm（警告型，抖音鏈）：於抖音區塊新增 npm --version 檢測。

同步更新腳本檔頭 .SYNOPSIS／.DESCRIPTION 與結束碼／摘要訊息（阻斷條件＝ .NET 10 ＋核心工具）。

文件

  • docs/operations/全新機器部署SOP.md §1：補 PowerShell 7+ 選配建議與「一鍵檢測」提示。
  • README.md 快速開始：補 PowerShell 7.x 建議與檢測腳本提示。
  • docs/operations/外部工具安裝與路徑設定.md：更新 Test-ExternalTools.ps1 說明，標明已涵蓋 .NET 10／PowerShell／npm。
  • docs/guides/使用者安裝與操作手冊.md §1：補「一鍵確認 .NET 10／PowerShell／外部工具」說明。

驗證

  • 本機執行 pwsh -File scripts/Test-ExternalTools.ps1：摘要新增「.NET 執行時 / PowerShell / npm」三列，

本機（.NET 10.0.9、PowerShell 7.6.3、npm 11.x）皆 OK，結束碼 0。

  • 缺 .NET 10 時 .NET 列顯示 FAILED＋安裝提示且結束碼為 1；PowerShell < 7 僅警告、結束碼不變。

備註

本次僅調整檢測腳本與文件，未動程式碼、資料模型、權限、路由，不需 migration、不需權限三處同步。 安裝腳本 Install-ExternalTools.ps1 維持原行為（不自動安裝 .NET，由使用者依提示安裝）。
