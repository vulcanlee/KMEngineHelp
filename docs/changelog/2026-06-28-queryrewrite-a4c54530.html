知識庫問答 Query Rewrite（0.2.142）

  • 日期：2026/06/28
  • 版本：0.2.141 → 0.2.142

摘要

知識庫問答新增條件式上下文補全 Query Rewrite：在多輪對話中，若使用者以「它」、「剛剛那個」、「怎麼處理」等短問句或代詞延續前文，系統會先用最近對話補成可獨立檢索的查詢，再交給既有混合檢索。回答仍保留使用者原始問題，避免改寫影響回答語氣或意圖。

變更內容

  • 新增 KnowledgeBaseQueryRewriteService，回傳原始查詢、有效查詢、是否改寫與原因。
  • KnowledgeBaseChatService.RetrieveAsync 可接收 history，檢索用改寫後 query；團隊權控仍完全由 IRetrievalService 套用。
  • 新增 SystemSettings.Retrieval.QueryRewrite 設定：
  • Enabled
  • Mode
  • MinQueryChars
  • MaxHistoryMessages
  • FallbackToOriginalOnError
  • 新增 Query Rewrite 專用 LLM 設定，預設使用較小模型 gpt-5.4-mini：
  • OpenAISettings.QueryRewriteModel
  • OpenAISettings.QueryRewriteTimeoutSeconds
  • OpenAISettings.LocalQueryRewriteModel
  • 新增提示詞槽位 知識庫-查詢改寫 / LlmPrompts.KnowledgeBaseQueryRewrite，沿用四層提示詞解析。
  • 後續不在本版實作的 HyDE、多查詢展開、rerank、query drift guard、adjacent chunk expansion 已加入優化待辦清單。
  • SystemVersion 升至 0.2.142 (2026/06/28)。

注意事項

Query Rewrite 只改變送進檢索層的查詢文字，不新增任何資料權限；越權內容仍不可進候選、context 或出處。若改寫模型失敗或逾時，預設會回退原始查詢，避免中斷問答流程。
