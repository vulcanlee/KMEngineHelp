知識來源管理清單（KnowledgeSource）（0.2.59）

  • 日期：2026-06-11
  • 版本：0.2.58 → 0.2.59
  • 對應 PRD：知識來源管理 PRD
  • 對應計畫：實作計畫

摘要

新增「資料清洗」階段的第一個入口頁面：知識來源管理清單。知識來源（KnowledgeSource） 把零散的匯入素材（音訊轉錄／文件萃取／圖片清單）聚合成有主題、有歸屬、可後續清洗的容器。

內容

  • 新側邊選單：新增父選單「清洗與蒸餾」，其下子頁「知識來源管理清單」（路由 /knowledge-sources）。
  • 資料模型：新增 KnowledgeSource（本體：標題／描述／分類／團隊／建立·更新時間）與

KnowledgeSourceItem（成員：以 ItemType + ItemId 軟參照三管線素材，SortOrder 排序， 對來源為 Cascade Delete，(KnowledgeSourceId, ItemType, ItemId) 唯一）。雙 provider migration AddKnowledgeSource（SQLite 與 SQL Server 各一）。

  • CRUD ＋ 成員聚合：KnowledgeSourceService 提供來源 CRUD、加入／移除／上下排序成員、

以及挑選「已完成」素材的查詢；全程套團隊權控（IRecordAccessScopeProvider ＋ TagStringHelper）。 清單預設依更新時間由新到舊；成員增刪／重排會更新 UpdatedAt。刪除來源僅移除成員關聯， 素材原紀錄保留。

  • 權限：MagicObjectHelper 新增 角色_清洗與蒸餾、角色_知識來源管理清單；

RolePermissionService 以位置索引新增對應權限群組；Menu.json 同步。既有角色需於 「角色管理」重新勾選才看得到。

  • UI：Blazor Server + Ant Design 頁面（清單、新增／編輯 Modal、成員管理 Modal），不含檔案上傳。
  • 測試：新增 KnowledgeSourceServiceTests（排序、團隊權控、成員去重與排序、級聯刪除保留素材、

可選素材過濾、成員移動）共 6 筆；全測試套件 170 筆綠燈。
