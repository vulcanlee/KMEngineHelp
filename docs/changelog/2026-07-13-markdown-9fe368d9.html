AI 聊天紀錄「聊天全文」對話窗改用 Markdown 預覽（0.3.40）

  • 日期：2026-07-13
  • 版本：0.3.39 → 0.3.40
  • 類型：調整 / UI

調整內容

  • 「AI 聊天紀錄」頁（管理員可見）的「查看全文」對話窗，原本以 <pre> 純文字顯示整份聊天內容，導致 #、##、###、- 等 Markdown 語法以字面呈現、閱讀性差。
  • 改為沿用既有共用元件 Components/Commons/MarkdownRenderer.cs（Markdig，DisableHtml() 防 MarkupString XSS），以 <div class="markdown-preview">@((MarkupString)MarkdownRenderer.ToHtml(contentText))</div> 渲染，與知識庫問答、知識來源對話、Wiki、內容編修等處一致。
  • 保留原本 max-height:60vh; overflow:auto 高度上限與捲動限制，避免長內容撐爆對話窗。

備註

  • 內容來源（LlmChatLog.RelativePath 指向的實體 .md 檔）與載入邏輯（ChatLogService.ReadContentAsync、ChatLogsView 的 contentText）皆維持不動；本次僅改前端顯示方式。
  • .markdown-preview 全專案未定義對應 CSS 規則，標題／清單依瀏覽器預設樣式呈現。
