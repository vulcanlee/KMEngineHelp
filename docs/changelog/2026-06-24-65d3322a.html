知識蒸餾（階段二）（0.2.117）

  • 日期：2026/06/24
  • 版本：0.2.116 → 0.2.117
  • 對應 PRD：知識蒸餾；路線圖：strategy/04 §階段二

摘要

實作五階段知識庫願景的階段二「知識蒸餾」：把已清洗的知識來源，用 LLM 蒸餾成多個精煉、可推理的 Wiki 實體頁（一概念一頁、以 [[wiki-links]] 互連、繼承來源 Teams/Categories 標籤）。完全沿用既有清洗管線模式（佇列＋背景服務＋處理器＋增強器＋四層提示詞＋雙 migration＋三處權限同步＋團隊權控）。

設計重點

  • 一來源多頁：一個知識來源蒸餾為多筆 WikiPage，彼此以 [[標題]] 互連。
  • 完整品質關卡：每頁記 LLM 自評信心；信心 ≥ 門檻（SystemSettings.Distillation.ConfidenceThreshold，預設 0.70）→「已完成」，否則「待審核」，由具 蒸餾審核 權限者核准/退回。
  • 蒸餾在清洗之後：輸入為已遮罩內容，故不再重做遮罩。
  • 重蒸餾＝取代：對同一來源重新蒸餾會先刪除其既有 Wiki 頁（含實體檔）再重建。
  • 內容只存檔案：Wiki 頁 Markdown 落於 ExternalFileSystem.WikiOutputPath 下 {年}/{guid}.md，DB 僅存相對路徑。
  • LLM 輸出解析：要求回 JSON 陣列（title/content/links/confidence）；解析失敗時降級為單頁並轉「待審核」，不整筆失敗。

變更內容

  • 資料模型：新增 WikiPage 實體；KnowledgeSource 新增 DistillationStatus/DistillationProgressPercentage/DistillationErrorMessage/DistilledAt；雙資料庫 migration AddKnowledgeDistillation。
  • 管線：IDistillationQueue/DistillationQueue、DistillationProcessor、DistillationEnhancer、DistillationBackgroundService；PipelineNames.Distillation。
  • 提示詞：新增 蒸餾-生成（LlmPromptKeys.DistillationGenerate）四層解析與程式 fallback。
  • 服務：新增 WikiPageService（查詢/檢視/編修/核准/退回/刪除＋觸發/取消/重試蒸餾，皆套團隊權控）。
  • UI：知識來源頁新增「蒸餾／取消蒸餾／重試蒸餾」操作與「蒸餾」狀態欄；新增「知識蒸餾」頁（/knowledge-distillation）。
  • 權限：新增 知識蒸餾（頁面）與 蒸餾審核（動作）兩權限，三處同步（MagicObjectHelper、RolePermissionService、Menu.json）。
  • 設定：appsettings.json 新增 ExternalFileSystem.WikiOutputPath 與 Distillation.ConfidenceThreshold、LlmPrompts.DistillationGenerate。
  • 測試：新增 DistillationEnhancerTests（JSON 多頁/圍欄/降級/信心正規化）。
  • 修正：download 圖示補列入 CRUD 圖示允許清單（修復既有測試缺口）。
