知識蒸餾頁版面修正與產生指引（0.2.118）

  • 日期：2026/06/24
  • 版本：0.2.117 → 0.2.118
  • 對應 PRD：知識蒸餾

摘要

修正知識蒸餾頁（/knowledge-distillation）的工具列版面與「知識來源管理清單」一致，並補上「Wiki 頁如何產生」的頁面指引。

變更內容

  • 工具列版面：新增 WikiPageView.razor.css（Blazor scoped CSS 不跨元件，各 View 須自帶一份），比照知識來源頁的 project-view-* 規則，使「重新整理／分類過濾／團隊過濾／搜尋」呈水平版面（左＝重新整理、右＝過濾＋搜尋），不再垂直堆疊。
  • 產生指引：知識蒸餾頁工具列下方新增淡色提示，說明 Wiki 頁由「知識來源管理清單」對已清洗來源按「蒸餾」🧪 觸發產生（此頁刻意無手動「新增」按鈕）。
  • 「蒸餾」狀態顯示：知識來源清單的「蒸餾」欄，當 DistillationStatus 為空字串（本功能 migration 前既有資料的回填值）時改顯示「待蒸餾」，不再空白。純 UI fallback，不更動資料。
