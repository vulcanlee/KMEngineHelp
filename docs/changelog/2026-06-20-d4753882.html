變更紀錄

音訊轉錄表單「來源類型」區塊移至最上方（0.2.100）

  • 日期：2026-06-20
  • 版本：0.2.99 → 0.2.100
  • 類型：使用體驗調整（UI 版面）

變更

新增音訊轉錄記錄時，將「來源類型／轉錄語言／影片網址或音訊影片檔案」整段移到表單最上方（標題之前）。使用者可先選定來源、貼上影片連結並自動帶入標題，再往下填標題、描述、分類、團隊，操作流程更順暢。

  • Components/Views/MediaTranscriptions/MediaTranscriptionView.razor：新增模式（isNewRecordMode）下的來源類型區塊上移至 AntDesign.Form 開頭。
  • 編輯模式欄位順序不變（仍為標題在前）。
  • appsettings.json SystemVersion 0.2.99 → 0.2.100。

影響範圍

  • 純 Razor 版面調整，無資料模型、權限或行為變更，無需 migration。
  • 來源類型（影片連結／上傳檔案）與轉錄語言的功能與行為不變；其說明見 日誌與設定檔說明（描述的是選項與行為，與欄位位置無關，仍正確）。
  • 其餘記錄表單（專案、工作、會議、文件萃取、圖片）不受影響。

驗證

  1. dotnet build 通過。
  2. 新增音訊轉錄記錄：表單最上方即為來源類型／轉錄語言／影片網址或檔案；貼上影片連結可自動帶入標題；編輯既有記錄時欄位順序維持原樣。
