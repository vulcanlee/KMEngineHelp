變更紀錄

MCP Server 實作：四知識工具＋JWT/API Key 雙認證＋分級日誌與稽核（1.0.1 → 1.0.6）

  • 日期：2026-07-16
  • 版本：1.0.1 → 1.0.6
  • 類型：新功能（在 KnowledgeExtraction.Web 內嵌 MCP Server，對外 AI Agent 可查詢知識庫）

需求

讓外部 AI Agent（Claude、Codex、Cursor、VS Code 等支援 MCP 的工具）能以標準協定安全查詢企業知識庫，全面沿用既有團隊權控，並具分級日誌與稽核。設計與使用說明見 MCP Server 整合設計與使用指南、MCP 服務使用說明書。

變更（分階段）

Phase 0：骨架（1.0.2）

  • 加套件 ModelContextProtocol.AspNetCore 1.4.1（HTTP／Streamable HTTP transport）。
  • ServiceCollectionExtensions.AddApplicationServices() 註冊 AddMcpServer().WithHttpTransport().WithToolsFromAssembly()。
  • Program.cs 掛 app.MapMcp("/mcp")（後於 Phase 3 改用具名 policy）。
  • 新增 Web/Mcp/KnowledgePingTool.cs（knowledge_ping 連通診斷）。

Phase 1：knowledge_ask（1.0.3）

  • 新增 Web/Mcp/KnowledgeAskTool.cs：包 KnowledgeBaseChatService.RetrieveAsync，強型別回傳（context/信心/最高分/出處）、多輪 history 對映、三點式分級日誌。稽核由 RetrieveAsync 自動寫入 KnowledgeBaseQueryAudit（不呼叫 LLM）。

Phase 2：search／list／get（1.0.4）

  • KnowledgeSearchTool（IRetrievalService 混合檢索）、KnowledgeListSourcesTool（GetAsync(DataRequest) 分頁、只回 Id/Title/Categories/Teams/Status）、KnowledgeGetDocumentTool（GetCleanedContentAsync 取全文）。
  • 三工具全部複用已內建團隊權控的既有服務、註冊免動（assembly 掃描）。
  • knowledge_get_document 對「不存在／未清洗／無權」統一回 unavailable（不洩漏來源存在性）。

Phase 3：認證 JWT + API Key（1.0.5）

  • 新增 Models/Systems/McpSettings.cs（設定型金鑰 Mcp:ApiKeys＝Key/UserId/Name）與 Web/Auth/McpApiKeyAuthenticationHandler.cs（讀 X-API-Key、定時比對、發帶 ClaimTypes.Sid 身分，RecordAccessScopeProvider 沿用不變）。
  • Program.cs：註冊 McpApiKey scheme；AddAuthorization 加具名 policy McpAccess（Bearer + Cookie + McpApiKey）；MapMcp 改用 McpAccess（修正 Phase 0 預設 Cookie scheme 導致 JWT 不被認證）。
  • 修正：JwtTokenService 補 ClaimTypes.Sid，使 JWT 非管理員也能解析所屬團隊（原先只見公開，屬欠授權；獨立 commit）。

Phase 4：日誌身分補足（1.0.6）

  • 新增 Web/Mcp/McpToolLog.cs；4 工具注入 IHttpContextAccessor，日誌情境帶 user=（已認證身分），補足請求層 UseHttpRequestLogging 在認證前擷取造成的 user=anonymous 缺口。

Phase 5：文件收尾（純文件，不升版）

  • 設計文件／使用說明書狀態改「已實作」，對齊 unavailable 錯誤碼、X-API-Key 標頭、McpAccess policy、knowledge_ping 工具。
  • 新增本 changelog；更新 docs/README.md 索引。

已知限制

  • 稽核身分：MCP 走 HTTP，KnowledgeBaseQueryAudit 的 account/name 為空（currentUserService 為 Blazor 專用）；IsAdmin/Teams 正確，呼叫者 account 由工具日誌 user= 補足。來源以日誌 op=McpAsk/… 區分（未加 Channel 欄位）。
  • API Key：第一版為設定型（撤銷＝移除設定、reloadOnChange）；DB 型金鑰（簽發/撤銷/稽核表）與稽核來源通道欄位列為日後增強（屆時需 Entity + 雙資料庫 migration）。
  • 未變更 Entity → 本次無雙資料庫 migration。

驗證

  1. dotnet test 557 通過（含權控不變量、四工具、認證、LoggingConventionTests）。
  2. scripts/Test-DocsEncoding.ps1 全綠（docs/*.md UTF-8 含 BOM）。
  3. 待人工於本機以真實 MCP client（如 Claude Code CLI、Codex）連 /mcp 走查四工具，並以管理員 vs 非管理員比對權控差異。
