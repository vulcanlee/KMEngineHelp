2026-06-09 圖片清單（圖片上傳與 LLM 視覺解讀）（0.2.45）

摘要

新增「圖片清單」頁面（路由 /image-recognition，位於側邊選單「專案管理」子選單），提供圖片上傳的 CRUD 管理；上傳後可選取提示詞清單中的提示詞，請 OpenAI 視覺模型（OpenAISettings.GenerationModel）解讀圖片並轉成文字。解讀文字以檔案儲存於可設定目錄並依上傳年度切分。系統版本 0.2.44 → 0.2.45。

異動內容

  • 設定：ExternalFileSystem 新增 ImageUploadPath（上傳圖片）與 ImageRecognitionTextPath（解讀文字輸出，依上傳年度切分）；Program.cs 啟動建立兩目錄；視覺解讀沿用 OpenAISettings.GenerationModel／ApiKey／BaseUrl。
  • 資料模型：新增 ImageRecognition 實體與 DbSet、雙 provider migration AddImageRecognition（含 ImageRelativePath、RecognitionTextRelativePath、RecognizedAt、Categories、Teams 等）；ImageRecognitionAdapterModel（含 HasRecognitionText）、DTO 與 AutoMapper（Categories/Teams 以 TagStringHelper 雙向）。
  • 格式驗證：ImageFormatValidator（.jpg/.jpeg/.png/.webp/.gif）。
  • 服務：ImageRecognitionService（CRUD、年度切分存圖、團隊權控、GetImageAsync/GetRecognitionTextAsync、刪除時清實體檔）；ImageRecognitionGenerationService（背景安全：呼叫視覺模型→寫年度切分解讀文字檔→更新路徑，只保留最新一筆）。
  • 視覺用戶端：OpenAIChatCompletionClient 新增 CompleteWithImageAsync 與靜態 BuildImageRequestBody（chat/completions，content 為 text + image_url(base64 data URL) 陣列）。
  • API：ImageRecognitionController 提供 GET {id}/image（內嵌串出原圖）與 GET {id}/text（下載解讀文字），團隊權控於 service。
  • UI：ImageRecognitionPage + ImageRecognitionView：上傳/編輯 Modal、操作區「檢視原圖／解讀圖片／檢視解讀文字／修改／刪除」、解讀對話窗（選提示詞→可編輯文字盒）、背景解讀（獨立 DI scope，完成自動刷新）、結果 Modal（唯讀＋複製到剪貼簿，IJSRuntime）。
  • DI：AddScoped<ImageRecognitionService>、AddScoped<ImageRecognitionGenerationService>；HttpClient 重用既有 OpenAIChatCompletionClient。
  • 權限三處同步：MagicObjectHelper 新增 角色_圖片清單；RolePermissionService 於「專案管理」群組末端加入；Menu.json 新增子項 id 26。
  • 測試：新增 ImageFormatValidatorTests 與 OpenAIChatCompletionClientTests.BuildImageRequestBody。

範圍外（未來延伸）

  • 列表縮圖預覽、多圖批次解讀、解讀歷史保留與比較、將解讀文字一鍵建立為其他紀錄、提示詞變數樣板、大圖壓縮。
