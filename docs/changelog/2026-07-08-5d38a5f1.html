/rag-diagnostics 新增「近期問答稽核紀錄」逐筆分頁表格（0.3.4→0.3.5）

  • 日期：2026-07-08
  • 版本：0.3.4 → 0.3.5
  • 類型：新增功能（RAG 診斷 EVAL-4 增補）

需求

EVAL-2 的 KnowledgeBaseQueryAudit 原本只被 /rag-diagnostics 以彙整形式消費（分佈/門檻）。本次在同頁補上逐筆稽核紀錄表格，供操作面 drill-down（例如篩出近期「查無依據／低信心」的問答看趨勢）。

變更

商業層

  • RagDiagnosticsModels：新增 POCO KnowledgeBaseQueryAuditRow（與 EF 實體解耦；僅中繼資料）。
  • RagDiagnosticsService.GetAuditRecordsAsync(page, pageSize, confidenceFilter)：AsNoTracking + 可依 Confidence 篩選 + OrderByDescending(CreatedAt).ThenByDescending(Id)（最新在前，CreatedAt 已有索引）+ 分頁。

UI 層

  • RagDiagnosticsView 於效果模擬表之後新增「近期問答稽核紀錄」區：信心篩選下拉（全部／查無依據／信心不足／正常）+ AntDesign 遠端分頁 Table（欄位：時間、信心、topScore、命中數、已改寫、問句長度、團隊、命中明細）+ 隱私註記。沿用頁面既有 CheckIsAdmin 守門與選單 adminOnly。

測試

  • RagDiagnosticsTests 新增 2：GetAuditRecordsAsync 分頁＋最新在前；依信心篩選。相關 8 個測試全綠。

隱私（不變量維持）

表格只顯示中繼資料（長度與分數），不含問句本文、context 或 chunk 文字——延續 EVAL-2 隱私邊界；頁面下方明示。若未來要看「使用者實際問了什麼」，需另做「儲存問句文字」的設計（隱私/保存期限決策，接近 EVAL-8）。

影響範圍

  • 進度：EVAL-4 由「分佈/門檻」再增「逐筆稽核表」；索引健康、症狀自檢、試檢索仍待補。
  • 無資料表／欄位／migration（複用 KnowledgeBaseQueryAudit）；無新權限。
  • appsettings.json SystemVersion 0.3.4 → 0.3.5。
  • 同步更新 docs/operations/RAG問題診斷手冊.md、docs/guides/RAG補強修正測試指南.md、docs/planning/12-...。

驗證

  1. dotnet test --filter RagDiagnosticsTests 綠燈（8 通過）；dotnet build 成功。
  2. 手動（管理員）：問數題 → /rag-diagnostics「近期問答稽核紀錄」見逐筆列、可翻頁、依信心篩選、無問句本文；非管理員被擋。
  3. scripts/Test-DocsEncoding.ps1 全綠。
