統計報表第三～五階段：5 個報表頁＋PDF 匯出＋側邊「統計報表」選單（0.3.38→0.3.39）

  • 日期：2026-07-13
  • 版本：0.3.38 → 0.3.39
  • 類型：新功能（統計報表功能完成，可操作）

需求

把統計報表第二階段的 4 個聚合服務接到畫面：5 個管理員專用報表頁（日期區間＋團隊/分類過濾＋PDF 下載）與側邊「統計報表」子選單。至此功能完整可用。

變更

PDF 與共用元件

  • 新增 Models/Reports/ReportDocumentModel.cs（PDF 文件模型）。
  • 新增 Web/Components/Commons/ReportPdfExporter.cs：QuestPDF 原生 Table 渲染、字型 Noto Sans TC（繁中不亂碼，沿用 Program.cs 既有註冊，零新相依）；ReportPdfButton.razor 經 DotNetStreamReference + keChat.downloadFileFromStream 下載。
  • 新增 Views/Reports/Shared/：ReportStatCards/ReportBarList/ReportRankList/ReportTrend/ReportViewHelper/ReportStatCard；全域 report-* 樣式加到 wwwroot/app.css（因 Dashboard 樣式為 scoped 不可重用）。

報表頁（管理員專用）

  • 5 個頁殼 Pages/Reports/ ＋ 5 個 View Views/Reports/（比照 TokenUsageView）：/reports/token-usage-report、/reports/feedback、/reports/qa-activity、/reports/retrieval-quality、/reports/content-inventory。每頁：進頁 CheckIsAdmin()、日期區間（預設近 30 天）、團隊多選（全部報表）＋分類多選（內容清點）、CSS 卡片＋長條、下載 PDF 報表。

選單與權限（三處同步＋位置對齊校正）

  • Datas/Menu.json：於「資料定義」與「登出」之間新增「統計報表」adminOnly 分組（id 7，子 71–75），圖示皆用允許清單內 classic Material Icons。
  • 位置索引校正：SidebarMenuService.ApplyPermissionStructure 以位置索引對應選單與 RolePermissionService 群組；因 角色_登出 = "登出 "（含尾空白）≠ 選單名，若只加選單不加權限樹，登出會退化。故新增 MagicObjectHelper.角色_統計報表 常數，並在 RolePermissionService.GetRoleListPermissionAllName() 相同索引插入 [角色_統計報表] 佔位，保「登出」對齊（同「系統管理」adminOnly 群組慣例）。
  • MenuIconTests.AllowedParentIcons 加入 analytics（首頁已用，classic 可顯示）。

版本與文件

  • appsettings.json SystemVersion 0.3.38 → 0.3.39。
  • PRD 狀態改「已實作」、首次實作版本 0.3.39、修正「不進權限樹」為「adminOnly 群組仍於權限樹佔位以保位置對齊」；docs/prd/README.md 由「規劃中藍圖」移入「已實作覆蓋矩陣」。

已知限制（沿續前階段）

  • 團隊維度僅升版後帶快照的新 Token/聊天紀錄有值；無費用欄位；分類過濾僅內容清點；影音/音訊合併。

驗證

  1. dotnet build 0 錯誤；dotnet test 540 通過（含 MenuIconTests 驗新選單/圖示）。
  2. scripts/Test-DocsEncoding.ps1 全綠。
  3. 待人工於瀏覽器：管理員逐頁查詢、PDF 下載、過濾；非管理員被擋且登出仍顯示。
