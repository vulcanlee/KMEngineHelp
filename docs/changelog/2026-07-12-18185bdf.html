知識庫問答：查詢期加入「團隊」篩選並強化分類/團隊下拉（0.3.35→0.3.36）

  • 日期：2026-07-12
  • 版本：0.3.35 → 0.3.36
  • 類型：新增功能（多團隊精準問答；無 migration）

需求

跨庫問答（/knowledge-base-chat）已於 0.3.22 支援「限定知識來源／分類」查詢期篩選，但團隊只用於自動權控，尚無讓使用者主動「只問某團隊內容」的下拉。本次補上限定團隊多選，並依需求強化分類/團隊下拉的可存取範圍與版面。

變更

檢索層（向量＋關鍵字兩路徑皆套，疊加在團隊權控之上）

  • RetrievalQuery（IRetrievalService.cs）、VectorQuery（IVectorStore.cs）新增可選 IReadOnlyList<string>? Teams（預設 null＝不限）。
  • RetrievalService.SearchKeywordAsync（關鍵字路徑）與 DualDbVectorStore.SearchAsync（向量路徑）在既有 team 權控／SourceLayer／ApplyEffective／SourceIds／Categories 之後加入：Teams → 重用 TagStringHelper.BuildContainsAnyPredicate<VectorEmbedding>(x => x.Teams, ...)（精確成員、空集合回 _ => true）。SearchVectorAsync 建 VectorQuery 時帶入 Teams。
  • KnowledgeBaseChatService.RetrieveAsync 簽章新增 teams（相容預設）並帶入 RetrievalQuery。

下拉資料來源（限可存取範圍）

  • KnowledgeBaseChatService 新增 GetFilterTeamsAsync()（管理員＝所有啟用團隊 TeamService.GetAllEnabledNamesAsync()；非管理員＝角色團隊 RecordAccessScope.Teams）與 GetFilterCategoriesAsync()（對可存取、現行版 VectorEmbedding 取 distinct 分類；非管理員先套 BuildTeamAccessPredicate）。注入 TeamService。

UI 層

  • KnowledgeBaseChatView：設定面板第二列在「限定知識來源」「限定分類」之後新增「限定團隊」多選 AntDesign Select（三者並排、樣式一致）。
  • 分類下拉改由 GetFilterCategoriesAsync() 供給（原本 CategoryService.GetAllEnabledNamesAsync() 全部啟用分類），團隊下拉由 GetFilterTeamsAsync() 供給；兩者預設留空＝全部。SendAsync 帶入所選團隊，LogTurnAsync 的 ScopeNote 納入團隊。移除因此不再使用的 CategoryService 注入。

測試

  • RetrievalFilterTests：Fx.AddVectorAsync 擴充可帶 teams；新增 SearchAsync_TeamsFilter_ReturnsOnlyMatching 與 SearchAsync_NonAdmin_TeamsFilterNarrowsWithinVisible_CannotWiden（權控先行、篩選無法擴權）。
  • 全測試 522 通過、0 失敗。

範圍決策（誠實記錄）

  • 團隊權控永遠先套用，本篩選只在可見集合內再縮小、無法擴權；團隊下拉本身也只列可存取團隊。
  • 兩條檢索路徑都套（避免關鍵字路徑漏濾）。
  • 查詢期參數、無 schema 變更 → 無 migration（VectorEmbedding.Teams 欄位已存在）。
  • 分類下拉改為「可存取知識中實際用到的分類」（distinct over 現行版可存取向量），避免列出選了也無結果的分類。

已知既有限制（本次不修）

  • VectorEmbedding.Teams/.Categories 為索引當下自來源/Wiki 頁複製之去正規化副本；增量重建以文字 ContentHash 為鍵，故「只改團隊/分類、未改內文」不會觸發重嵌入，chunk 標籤可能過時。此限制同時影響既有團隊權控與本次團隊篩選。

影響範圍

  • docs/guides/AI知識問答使用指南.md（設定面板段）。
  • docs/guides/新手完整操作指南.md（§19.8、§20 篩選段與速查表）。
  • docs/guides/完整操作手冊.md（§十一 控制項）。
  • docs/architecture/知識庫RAG設計與執行.md（查詢期範圍篩選段）。
  • docs/prd/知識庫問答-prd.md（畫面與操作—設定面板）。
  • appsettings.json SystemVersion 0.3.35 → 0.3.36。

驗證

  1. dotnet build（KnowledgeExtraction.slnx）成功；dotnet test 綠（522 通過，含新 RetrievalFilterTests）。
  2. 手動：/knowledge-base-chat 展開設定 → 分類／團隊／知識來源三篩選器並排；分類下拉只列可存取知識中用到的分類、團隊下拉只列可存取團隊；不選＝跨可見庫；選團隊→答案與出處只來自該團隊內容；分類＋團隊併用取交集。
  3. 非管理員：選任何團隊都不外洩無權限內容（團隊權控先行）。
  4. scripts/Test-DocsEncoding.ps1 全綠。
