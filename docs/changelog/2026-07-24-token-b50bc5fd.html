Token 用量頁：使用者下拉篩選＋四維度統計＋PDF 報表下載（1.0.45→1.0.46）

  • 日期：2026-07-24
  • 版本：1.0.45 → 1.0.46
  • 類型：新功能（純查詢／唯讀，無資料模型變更）

需求

管理員的「Token 用量」查閱頁（/token-usage）已能逐筆列出每次 OpenAI 呼叫用量並顯示「篩選範圍合計」，但仍缺三項：

  1. 「帳號或姓名」只能純文字輸入，無法從既有使用者清單挑選，也無法單獨篩出「（系統/背景）」。
  2. 無法把查詢結果輸出成 PDF 報表下載（明細＋統計都要）。
  3. 除了合計列外，缺少分組統計（依使用者／作業／模型／型別），且統計要同時顯示在畫面與 PDF。

變更

後端（TokenUsageQueryService）

  • TokenUsageQueryFilter 新增 SystemOnly：為真時只取「帳號與姓名皆空」的系統/背景紀錄（與 UserKeyword 互斥）。
  • 新增 GetUserOptionsAsync：MyUser 全部啟用帳號 ∪ 用量紀錄中出現過的帳號，以帳號去重、依姓名/帳號排序（不含「（系統/背景）」，該項由畫面固定加最前）。
  • 新增 AggregateAsync：對「與明細相同篩選」做四維度分組彙總——依使用者（含輸入/輸出/快取/推理/合計與次數）、依作業、依模型、依型別（均依合計遞減）；涵蓋全部篩選結果、非僅當頁；沿用報表服務的 GroupBy→Sum 樣式，依序 await（單一 DbContext）。
  • 新增 ExportRowsAsync：與 QueryAsync 相同排序但不分頁，供 PDF 明細取全部篩選結果。

UI（TokenUsageView）

  • 「帳號或姓名」＝ Input（自行輸入模糊比對）＋ Select（EnableSearch 下拉選取，Value＝帳號、Label＝「姓名（帳號）」；最前為「（系統/背景）」專用選項，選取後寫入輸入框）。註：原採 AutoComplete，因 AntDesign 1.6.0 該元件首次渲染掛 ResizeObserver 會 NRE 導致整頁崩潰，改用此組合。
  • 查詢後於「篩選範圍合計」下方新增統計區：AntDesign Tabs 四分頁（依使用者／依作業／依模型／依型別），內為統計表。
  • 篩選列「查詢」旁新增「下載 PDF 報表」按鈕：以 ReportPdfExporter（QuestPDF，繁中字型）產出含「篩選範圍合計＋四維度統計＋全部明細」的 PDF，經既有 keChat.downloadFileFromStream 串流下載。
  • 新增 TokenUsageView.razor.css（統計表樣式，CSS isolation）。

測試

  • 新增 TokenUsageQueryServiceTests（in-memory SQLite）：AggregateAsync 四維度分組與系統/背景歸屬、SystemOnly 篩選、UserKeyword 模糊比對、GetUserOptionsAsync 合併去重排除停用/系統項、ExportRowsAsync 不分頁且排序一致。

影響與相容性

  • 純查詢/唯讀功能，無模型變更、不需 migration。
  • 頁面維持管理員專用；PDF 明細「全部列入」，資料量大時檔案較大、產生較久（屬預期）。

版本

  • appsettings.json SystemVersion：1.0.45 (2026/07/24) → 1.0.46 (2026/07/24)。
