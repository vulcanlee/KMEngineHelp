釐清「評測用哪些紀錄」：黃金評測 vs RAG 評測（0.2.138）

  • 日期：2026-06-27
  • 版本：0.2.137 → 0.2.138
  • 類型：文件 / 可理解性改善

背景

使用者詢問「按『評測』時用哪些紀錄？是不是整份知識來源管理清單？」這是常見誤解。經程式碼確認，兩種評測用的紀錄不同，且都不是「整份知識來源清單」：

  • 黃金評測（GoldenSampleService.EvaluateOneAsync）：評的是黃金樣本自己貼的「輸入文字」＋標準答案，用全域清洗提示詞重跑再比對；完全不讀知識來源管理清單。評測此筆＝該筆；評測全部＝目前頁所有黃金樣本。
  • RAG 評測（RagEvaluationService → RetrievalService.RetrieveAsync → RagEvaluator）：評的是你建立的問句樣本；按評測時把問句送進混合檢索，打整個已索引知識庫（所有向量 chunk），依該樣本模擬的團隊權限過濾——非單一來源、非未索引清單列。純檢索、不經 LLM 生成；結果只寫回樣本指標，不改索引或實際問答／搜尋。

調整內容

  • docs/guides/完整操作手冊.md：§八 黃金評測、§十二 RAG 評測 各補一段「評測用哪些紀錄？」明確說明。
  • docs/guides/實作練習手冊-Hands-on Lab.md：第 8 章、第 12 章 各補一則 📌 評測用哪些紀錄 callout。
  • docs/guides/檢索品質評測使用指南.md（1.0 → 1.1）：§一 補「評測用哪些紀錄？」與「對系統有沒有影響？」，明確化資料來源與唯讀/量測性質。
  • docs/guides/清洗品質評測使用指南.md：§二 運作原理步驟 1 補一句「完全不讀知識來源管理清單」，直擊誤解。
