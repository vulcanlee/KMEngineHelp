發行說明：分類清單（Category）管理功能（0.2.34）

期間：2026/06/05。本輪新增「分類清單」CRUD 管理頁面，供未來建立其他紀錄時做為資料分類之用。設計參考既有「專案管理」(ProjectPage)。版本來源為 appsettings.json 的 SystemVersion。需求與規格見 分類清單 PRD。

重點摘要

  • 新增單一共用的分類清單管理頁面（路由 /categories），提供新增、查詢、編輯、刪除。
  • 分類名稱為唯一值：比對時忽略大小寫並去除頭尾空白，新增與編輯皆生效（編輯時排除自身）。
  • 列表預設依更新時間由新到舊排序，最近更新者排最前。
  • 側邊選單新增「資料定義」主功能表（置於「系統管理」之後、「登出」之前），其下放「分類清單」，並納入角色權限控制。

功能與變更

0.2.34 — 新增分類清單 CRUD

  • 資料模型：新增 Category 實體（Id、Name、Description、IsEnabled、CreatedAt、UpdatedAt）；

BackendDBContext 新增 DbSet<Category>；產生 Sqlite 與 SqlServer 雙 migration（AddCategory）。

  • 後端分層（比照 Project）：CategoryRepository、CategoryService、CategoryController，

以及 CategoryDto／CategoryCreateUpdateDto／CategorySearchRequestDto／CategoryAdapterModel。

  • 名稱唯一性：UI 路徑由 CategoryService.BeforeAddCheckAsync／BeforeUpdateCheckAsync 驗證；

API 路徑由 CategoryRepository.ExistsByNameAsync 驗證，重複時回 409 Conflict。

  • 預設排序：CategoryRepository.GetPagedAsync 與 CategoryService.GetAsync 預設 OrderByDescending(UpdatedAt)。
  • UI（Blazor Server + Ant Design）：CategoryPage（/categories）與 CategoryViewView；

表格欄位為名稱、描述、啟用狀態、更新時間、操作；新增／編輯 Modal 含啟用狀態切換。

  • 選單與權限：Datas/Menu.json 新增「資料定義 > 分類清單」（並調整「登出」id 維持唯一）；

MagicObjectHelper 新增 角色_資料定義／角色_分類清單；RolePermissionService 於系統管理之後、登出之前新增對應權限群組。

  • 接線：AutoMapping 新增 Category 對應；ServiceCollectionExtensions 註冊 CategoryService／CategoryRepository。
  • 測試：新增 CategoryServiceTests，涵蓋唯一值（忽略大小寫＋去空白、編輯排除自身）與預設排序；全套測試 96 筆通過。
  • 文件：新增 分類清單 PRD；appsettings.json 版本號 0.2.33 → 0.2.34。

使用方式

  1. 既有角色需先到「系統管理 → 角色管理」勾選「資料定義 / 分類清單」權限。
  2. 部署前對資料庫套用 AddCategory migration（Update-Database）。
  3. 進入「資料定義 → 分類清單」即可新增、編輯、刪除分類；名稱重複（含僅大小寫或頭尾空白差異）會被擋下並提示。

未來延伸（Out of Scope）

  • 其他紀錄（專案、會議、轉錄等）引用分類欄位與下拉選單（屆時可依 IsEnabled 僅顯示啟用中的分類）。
  • 分類的批次匯入／匯出、階層（父子）結構。
