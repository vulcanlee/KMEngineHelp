實作「AI Agent 技能產生器」模組（0.2.95）

  • 日期：2026-06-20
  • 版本：0.2.94 → 0.2.95
  • 類型：功能新增

需求

依 AI 技能產生器 PRD（原 prd/AI技能產生器-prd.md，已於 1.0.45 隨功能移除而刪除）實作：操作比照知識來源管理——指定三類已完成素材為成員、套用提示詞（自訂／/prompts／內建 meta-prompt），背景以 LLM 產生可重用 SKILL.md（Claude Code / Codex 技能），可線上預覽/編修並下載（單檔 SKILL.md ＋ zip <slug>/SKILL.md）。

變更（新增模組，鏡像 KnowledgeSource）

  • 資料層：實體 SkillDefinition + SkillSourceItem（軟參照三類素材、唯一索引、cascade）；BackendDBContext 註冊與 OnModelCreating；雙資料庫 migration AddSkillGenerator（Sqlite ＋ SqlServer）。
  • 設定：ExternalFileSystem.SkillOutputPath（C:\temp\KnowledgeExtraction\Skill）＋ Program.cs EnsureDirectoryExists。
  • AdapterModel：SkillDefinitionAdapterModel（狀態常數）、SkillSourceItemAdapterModel；AutoMapper ForMember＋TagStringHelper；選取沿用既有 SelectableSourceItemAdapterModel。
  • 服務 SkillDefinitionService：CRUD＋管理成員（加/移/排序/可選清單，限已完成＋團隊權控）＋TriggerGenerateAsync/CancelGenerateAsync/RetryGenerateAsync＋GetSkillContentAsync/UpdateSkillContentAsync/GetSkillForDownloadAsync。
  • 背景管線：ISkillGenerationQueue/SkillGenerationQueue（Singleton Channel）→ SkillGenerationBackgroundService（HostedService，重啟復原）→ SkillGenerationProcessor（彙整成員→繁體正規化→套提示詞→IChatCompletionClient.CompleteAsync→解析/補齊 frontmatter→落檔）。取消沿用 IPipelineCancellationRegistry（PipelineNames.SkillGeneration）。未設 LLM 金鑰直接失敗（不可降級）。
  • 輔助：SkillContentHelper（slug 轉換、frontmatter 解析/補齊，純函式有單元測試）、SkillPromptDefaults.MetaPrompt（內建技能產生提示詞）。
  • 下載控制器 SkillController：GET {id}/skill（SKILL.md）、GET {id}/zip（<slug>/SKILL.md，System.IO.Compression）。
  • UI：/skills（SkillPage + SkillView）：列表/工具列/過濾/搜尋；列動作 產生（選提示詞對話窗）、取消、重試、檢視/編修、下載 SKILL.md、下載 zip、管理成員、修改、刪除；5 秒輪詢。
  • 選單與權限三處同步：MagicObjectHelper.角色_AI技能產生器、RolePermissionService（清洗與蒸餾群組，插於清洗設定檔之後、知識審核之前以對齊側邊欄位置）、Menu.json（id 34「AI技能產生器」/skills，icon auto_awesome）。

影響範圍

  • 新增實體 → 需 migration（已產生雙套，啟動時 Sqlite 自動套用）。
  • DI 註冊（SkillDefinitionService、Queue Singleton、Processor Scoped）＋ AddHostedService<SkillGenerationBackgroundService>。
  • 測試：新增 SkillContentHelperTests；MenuIconTests/CrudActionIconTests 允許清單補 auto_awesome。
  • appsettings.json SystemVersion 0.2.94 → 0.2.95。

  3. 端到端（需金鑰）：/skills 新增→管理成員加素材→「產生」→完成→預覽/編修→下載 SKILL.md 與 zip。
