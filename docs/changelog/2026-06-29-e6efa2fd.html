專案列表「工作與會議」對話窗 + 共用編輯 Modal 抽取（0.2.152）

  • 日期：2026/06/29
  • 版本：0.2.151 → 0.2.152

摘要

在「專案項目」清單每列新增「工作與會議」按鈕，以對話窗（非路由切換）顯示該專案關聯的工作項目與會議記錄，並能就地新增/修改/刪除。用對話窗是為了避免離開專案清單而遺失頁次與捲動位置。同時把工作/會議的編輯表單抽成共用編輯對話窗元件，原頁面與新對話窗共用同一實作。

變更內容

  • 新增 MyTasEditModal / MeetingEditModal：自包含的編輯對話窗（含 Modal、表單、驗證、附件上傳、呼叫服務存檔），以參數驅動（新增/編輯、鎖定/隱藏專案、子工作繼承），完成後以 OnSaved/OnCancelled 通知宿主。
  • 重構 MyTasViewView / MeetingViewView：移除頁面內嵌的編輯 Modal，改用上述共用元件；工作項目的「管理子工作」仍留在原頁，改驅動同一個編輯元件（沿用隱藏/還原巢狀 Modal 與父工作日期同步）。
  • 新增 ProjectRelatedRecordsModal：Tabs（工作項目/會議記錄）+ 簡單表格 + 每列新增/修改/刪除；依 角色_工作項目/角色_會議項目 權限顯示分頁；新增與修改皆鎖定所屬專案為當前專案。
  • ProjectViewView：ActionColumn 新增「工作與會議」按鈕（具工作或會議權限才顯示）；以疊加對話窗開啟，不導航、不影響清單頁次/捲動。
  • MeetingService.GetAsync：新增 ProjectIdFilters 過濾（仿 MyTasService）。
  • wwwroot/app.css：新增 .project-related-records-modal 寬版 Modal 樣式。
  • SystemVersion 升至 0.2.152 (2026/06/29)。

注意事項

  • 無資料庫/模型變更，沿用既有 MyTask.ProjectId/Meeting.ProjectId 外鍵，無 migration。
  • 團隊權控完全沿用各服務 GetAsync 內既有 BuildTeamAccessPredicate。
  • 共用編輯元件以 _wasVisible 守衛，僅在開啟（hidden→visible）時重建資料，避免重繪清空輸入。
  • 已以 Playwright 實機驗證：對話窗 Tabs 正常、新增工作所屬專案鎖定為當前專案、巢狀編輯取消後還原、關閉後專案清單頁次不變、原工作/會議頁編輯回歸正常。
