發行說明：紀錄分類、團隊標籤與團隊權限控管（0.2.36 – 0.2.37）

期間：2026/06/05。為五種紀錄（專案項目、工作項目、會議紀錄、音訊轉錄、文件萃取）加入「分類」「團隊」標籤欄位與過濾，並以角色預設團隊實作資料可見性權控。需求與規格見 紀錄分類與團隊權控 PRD。版本來源為 appsettings.json 的 SystemVersion。

重點摘要

  • 五種紀錄可標註多個「分類」與「團隊」（標籤式多選、僅能選現有啟用清單、可逐一移除），清單可依分類/團隊過濾，原搜尋/排序/分頁照常並可疊加。
  • 角色可設定「預設團隊」。非管理員瀏覽五種紀錄時，僅能看到無團隊（公開）或與自身角色團隊有交集的紀錄；管理員不受限。
  • 權控於所有存取路徑生效：清單、單筆讀取、編輯、刪除、下載/預覽。團隊名稱採精確比對（不發生「團隊」誤中「團隊2」）。

功能與變更（依版本）

0.2.36 — 階段一：分類/團隊標籤與過濾（不含權控）

  • 共用 TagStringHelper：List<string> ⇄ 分隔字串、Wrap、BuildContainsAnyPredicate（精確成員 OR 述詞，SQLite/SqlServer 皆可）。
  • 五種紀錄 Entity 新增 Categories、Teams 可空字串欄位；雙 provider migration AddCategoryTeamTags。
  • 五 AdapterModel 新增 List<string> Categories/Teams 與顯示用文字屬性；AutoMapping 以 TagStringHelper 雙向轉換。
  • DataRequest 新增 CategoryFilters/TeamFilters；五 Service GetAsync 加入分類/團隊 OR 過濾；新增/更新持久化標籤。
  • Category/TeamService 新增 GetAllEnabledNamesAsync。
  • 五頁 Blazor UI：工具列分類/團隊多選過濾、清單欄位、新增/編輯標籤式多選（AntDesign Select Mode="SelectMode.Multiple"）。

0.2.37 — 階段二：角色預設團隊與團隊權控

  • RoleView 新增 DefaultTeamsJson；雙 provider migration AddRoleDefaultTeams。RoleViewAdapterModel 新增 DefaultTeams，角色管理頁加入「預設團隊」多選。
  • CurrentUser 新增 TeamList；登入流程（AuthenticationStateHelper.Check）載入角色預設團隊。
  • 新增存取範圍解析器 IRecordAccessScopeProvider / RecordAccessScopeProvider：Blazor 取自 CurrentUserService、Web API/下載取自 HttpContext claims 查角色團隊；回傳 (IsAdmin, AllowedTeams)。
  • TagStringHelper 新增 BuildTeamAccessPredicate（公開 OR 團隊交集）與 IsTeamAccessible（單筆判斷）。
  • 五 Service 清單與單筆查詢、下載/預覽（附件、逐字稿、Markdown）套用團隊權控；

Project/MyTask/Meeting 三個 Repository 的清單、單筆、編輯、刪除路徑套用團隊權控（其 Controller 走 Repository）。

  • 測試：TagStringHelperTests、ProjectTagFilterTests、ProjectTeamAccessTests（權控矩陣、精確比對、單筆防繞過），全套 119 測試通過。

使用方式

  1. 部署前套用資料庫 migration（AddCategoryTeamTags、AddRoleDefaultTeams）。
  2. 於「系統管理 → 角色管理」為各角色設定「預設團隊」。
  3. 於五種紀錄新增/編輯時以標籤選取分類與團隊；清單可依分類/團隊過濾。
  4. 非管理員僅能看到無團隊或與自身角色團隊交集的紀錄；管理員看到全部。

已知限制 / 後續強化

  • 非管理員的「團隊」下拉目前仍列出全部啟用團隊（伺服器端可見性已嚴格限制；指定到自身未授權的團隊僅會造成自己看不到該紀錄，非資料外洩）。UI 下拉依使用者團隊限縮列為後續強化項。
