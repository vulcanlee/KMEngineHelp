產品更名：知識萃取器系統 → 智庫引擎（2026-07-04）

背景

本系統原先的產品名稱為「知識萃取器系統」。為建立更清晰、更具品牌識別度的產品定位，正式將產品名稱定名為「智庫引擎」，並在登入頁加入新的產品定位文案：

將企業分散的文件、會議與影音資料，轉化為可搜尋、可問答、可傳承的智慧知識庫。

決策邊界

本次更名只調整使用者可見的產品名稱，刻意收斂範圍以降低風險：

  • 只改產品名：僅替換明確指「知識萃取器系統」的產品名稱字串。
  • 保留動詞／概念用法：如「把知識萃取出來」「知識萃取的核心價值」「知識萃取工具」等描述性用語維持不變。
  • 保留功能名稱：知識庫、知識來源、知識蒸餾、知識庫問答等是功能名稱，不是產品名，維持不變。
  • 技術識別碼全部保留：namespace KnowledgeExtraction.*、專案名／.csproj、資料夾 KnowledgeExtraction.AI、JWT Issuer/Audience、Redis InstanceName、DB 路徑、KnowledgeExtraction.Web.styles.css 資源名等一律不動。變更這些屬大型重構，且會破壞建置、Git 歷史、既有 JWT token 相容性與 DB 路徑。
  • 英文名呈現：文件以「智庫引擎」為主，技術基底英文名 KnowledgeExtraction 在括號或程式碼路徑中保留。

產品名稱的唯一來源

登入頁標題、Splash 啟動畫面、側欄品牌名、關於視窗名稱全部動態繫結至 appsettings.json 的 SystemSettings.SystemInformation.SystemName。因此只要修改設定檔即全域生效，UI 檔（SplashView.razor／NavMenu.razor／MainLayout.razor）不需逐一修改。

驗證

  1. rg "知識萃取器系統" → 除本文件的說明引用外，無殘留產品名。
  2. 於 src/KnowledgeExtraction 執行 dotnet build → 建置成功。
  3. 啟動 Web，開登入頁 /Auths/Login：標題顯示「智庫引擎」、說明文字為新定位文案；Splash、側欄、關於視窗名稱同步。
  4. pwsh scripts/Test-DocsEncoding.ps1 → 所有 docs 維持 UTF-8 含 BOM。
