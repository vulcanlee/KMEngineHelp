慣例調整：引用程式碼一律用符號名

稽核發現長青文件中的 檔案:行號 引用無一存活——程式一改就全部失準，且不會有工具提醒。本批把 architecture／operations／security／features 底下全部行號引用改為符號名（檔名 + 類別／方法名），改完剩餘 0 筆。

同時在 operations/維護規範.md 新增「規範四」，明訂此慣例，並要求不要在文件中複製程式碼的完整清單（DI 清單、常數全文、設定鍵列舉）——複製一份就多一個漂移來源，應指向單一真實來源。本批已據此處理 §3.4 與架構總覽的 DI 清單。
