清洗管線 LLM 步驟（去重/遮罩/分類/摘要）（0.2.61）

  • 日期：2026-06-11
  • 版本：0.2.60 → 0.2.61
  • 對應路線圖：資料清洗開發代辦清單 第三階段、設計 strategy/08

摘要

在清洗管線（QA-1）的「彙整 → OpenCC 繁體」之後，接上 LLM 四個增強步驟： 去重/品質過濾 → 敏感資訊遮罩 → 分類/標籤建議 → 摘要/實體擷取，重用既有 OpenAI client。

內容

  • IChatCompletionClient：自既有 OpenAIChatCompletionClient 抽出純文字完成介面，

讓清洗增強可用假 client 單元測試、不影響其他使用者。

  • CleaningEnhancer（Business/Services/Cleanings/）：封裝四個 LLM 步驟。
  • 提示詞：程式內預設常數；若 Prompt 清單存在同名且啟用者（清洗-去重/清洗-遮罩/清洗-分類/清洗-摘要）則優先覆寫。
  • 失敗策略：敏感資訊遮罩失敗（或回傳空）→ 整筆清洗失敗（不輸出未遮罩內容）；

去重/分類/摘要失敗 → 降級（保留前一步內容、於清洗文件加註記）。

  • 未設定 OpenAISettings.ApiKey → 整段 LLM 略過（降級為彙整+OpenCC，文件註記），離線/開發可用。
  • CleaningProcessor 整合：彙整成員內容 → LLM 增強 → 組最終 Markdown

（# 標題 + ## 摘要 + ## 建議分類 + 註記 + --- + 遮罩後本文）； 建議分類合併進 KnowledgeSource.Categories（不重複），不動 Teams（權控）。

  • 測試：CleaningEnhancerTests（四步轉換、分類解析、遮罩失敗拋例外、去重/分類降級、ApiKey 空略過）、

CleaningProcessorTests 新增 LLM 端到端與遮罩失敗→失敗案例；全測試 183 筆綠燈。

  • 不新增 DB 欄位、無 migration。
