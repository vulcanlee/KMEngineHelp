清洗 QA-4：黃金評測集（0.2.66）

  • 日期：2026-06-12
  • 版本：0.2.65 → 0.2.66
  • 對應路線圖：資料清洗開發代辦清單 第四階段 QA-4、設計 strategy/08

摘要

建立「黃金評測集」應用內頁面：人工標註小樣本，跑清洗管線並比對，量化遮罩漏判、分類準確率、摘要品質， 並以門檻掃描校準信心門檻（QA-2 的 Cleaning.ConfidenceThreshold）。

內容

  • 資料模型：GoldenSample（Title、InputText、ExpectedMaskedTerms/MustKeepTerms/ExpectedCategories/

ExpectedSummaryEntities、HumanPass、最近評測結果 LastEvaluatedAt/LastConfidence/LastMetricsJson）。 雙 provider migration AddGoldenSample。

  • 純評估器 CleaningEvaluator（靜態、可單測、不需 LLM）：
  • 遮罩：列出仍出現在本文的「應遮罩字串」（漏判）、算 MaskRecall、MustKeep 是否保留。
  • 分類：與管線建議分類做集合比對 → Precision/Recall/F1。
  • 摘要：預期關鍵實體在摘要中的涵蓋率（啟發式）。
  • 門檻掃描：0.5~0.9 各門檻的自動清洗率/待審率/對人工 Pass 的精準率與召回率，並建議門檻。
  • 服務 GoldenSampleService：樣本 CRUD、EvaluateOneAsync（重用 CleaningEnhancer 跑真 LLM → 比對 → 存指標）、

GetAggregateAsync（彙整指標＋門檻掃描＋建議/目前門檻）、SeedBuiltInAsync（一鍵載入內建繁中合成樣本）。

  • 頁面/權限：「清洗與蒸餾 > 黃金評測」（路由 /golden-samples，新增頁面權限 角色_黃金評測，

三處同步＋位置索引；圖示 fact_check）。頁面含樣本 CRUD、載入種子、評測（單筆/全部）、指標與門檻儀表板。

  • 測試：CleaningEvaluatorTests（17 筆，指標/門檻純函式）、GoldenSampleServiceTests（5 筆，含假 LLM 端到端）；

全測試 221 筆綠燈。MenuIconTests 允許清單加入 fact_check。

備註

  • 評測需設定 OpenAI ApiKey（重用清洗管線）；未設定則回明確提示、不評測。
  • 校準只建議門檻，套用仍由人改 appsettings（避免自動改動線上行為）。
  • 摘要品質採啟發式關鍵實體涵蓋率；LLM 評審打分留待後續。
  • 資料清洗第四階段（QA-1~QA-4）至此完成；下一步可往知識蒸餾推進。
