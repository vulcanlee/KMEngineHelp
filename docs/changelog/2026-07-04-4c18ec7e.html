產品代表圖示套用紀錄

變更目的

採用 KnowledgeExtractionAI_logo_09_secure-constellation（安全星座）作為「智庫引擎」的產品代表圖示，套用於登入頁、Splash 畫面與網頁 favicon，並適度放大。

圖示資產產生方式

來源圖為 1024×1024、白色不透明底，實際 logo 內容僅約佔 30%×33%（四周大量白邊）。以 Python + PIL 一次性處理：

  1. 依非白內容 bbox 裁切 logo（裁切後約 304×341）。
  2. 置中貼到白色正方形磚，logo 約佔磚面 72%。
  3. 烘焙圓角（半徑約 18%），圓角外為透明（RGBA），使深色背景上呈現乾淨圓角磚而非硬白方塊。
  4. 輸出兩個資產：
  5. wwwroot/images/app-logo.png（512×512，登入頁／Splash 用）
  6. wwwroot/favicon.png（128×128，覆蓋原檔，作為網頁 favicon）

深藍色 logo 需保留淺色（白）底磚，才能在暗黑霓虹翡翠主題上維持清晰；故不去背。
