Graph RAG P3：社群摘要 + 全域問答（1.0.84 → 1.0.85）

  • 日期：2026-07-27
  • 版本：1.0.84 → 1.0.85
  • 類型：新增功能（Graph RAG 第三階段，系列完結）

背景

延續 P1（wiki-link 邊 + 圖檢索融合）、P2（LLM 三元組抽取 + 人工審核 + 接進檢索）。P3 補齊「全域性問答」：把已核可的知識圖譜分群成社群、對每群產生 LLM 摘要，並在 AI 知識問答加「全域」查詢模式，以 map-reduce 社群摘要回答「綜觀全部／整體趨勢／系統性根因」這類 local 檢索答不好的問題（Microsoft GraphRAG 的 global search）。

變更

  1. 資料模型：新增 GraphCommunity（Title/Summary/Teams(成員聯集)/MemberCount），整批重建、不做審核；雙庫 AddGraphCommunity migration。
  2. 社群偵測：CommunityDetector.LabelPropagation（LPA，純函式、決定性、無外部依賴）。
  3. 摘要建置：GraphCommunityBuilder（只用 已完成 三元組建圖 → LPA 分群 → 依成員數上限 50 取大群 → 每群 LLM 產 {title,summary}（OperationGraphCommunity）→ 整批取代）；IGraphCommunityQueue/GraphCommunityBackgroundService/IGraphCommunityBuildState（單例全域工作，不進 PipelineNames）；管理員於審核頁「重建社群摘要」手動觸發。
  4. 全域問答：KnowledgeBaseChatService.GlobalMapAsync（對可存取社群摘要各生重點，map，OperationGraphGlobalChat）+ BuildGlobalMessagesAsync（reduce 系統提示詞 + 防注入包裹）+ 既有 StreamAsync（串流）。提示詞槽位 GraphCommunitySummary/GraphGlobalMap/GraphGlobalReduce（四處同步）。
  5. UI：AI 知識問答設定面板加「查詢模式」切換（一般／全域）；SendAsync 分支——全域→map-reduce、無社群→查無依據、答案末附「參考社群」。知識圖譜審核頁加「重建社群摘要」按鈕與狀態列（建置中／上次建立時間／社群數／錯誤）。
  6. DI/Host：GraphCommunityQueue/BuildState(Singleton)、GraphCommunityBuilder/GraphCommunityService(Scoped)、GraphCommunityBackgroundService(HostedService)。
  7. appsettings.json：SystemVersion 1.0.84 → 1.0.85。

安全與相容（leak=0 紅線，比一般權控更嚴）

  • 社群摘要混合成員知識，故存取判定為 社群 Teams 聯集 ⊆ 使用者團隊（子集，非一般的交集）或社群純公開；管理員全部。由 GraphCommunityService.GetAccessibleSummariesAsync 集中把關（GraphCommunityServiceTests 釘住：非管理員拿不到聯集超出其團隊的社群）。
  • 全域無可用社群 → 程式層回「查無社群依據」不呼叫 reduce。
  • 一般（local）問答、P1/P2、清洗、蒸餾、評測全部不受影響（切「一般」即原行為）。

已知限制（P4 再處理）

  • 節點為 per-來源去重、三元組亦同來源，故社群多半落在單一來源內（未做跨來源實體合併）；但全域 map-reduce 仍涵蓋所有來源的社群，故全域問答仍跨來源，只是社群粒度偏「來源主題」。
  • map-reduce 成本 ＝ (可存取社群數 + 1) 次 LLM，以社群上限（建置 50、查詢 20）控管。

驗證

  • dotnet build 成功；dotnet test 795 全綠（既有 785 + 新增 10：CommunityDetectorTests 3、GraphCommunityBuilderTests 3、GraphCommunityServiceTests 3、全域無社群 1）；守護測試（提示詞槽位/作業別/管線健康檢查）全綠——社群工作刻意不進 PipelineNames 故不影響健康檢查推導。
  • 手動（管理員）：核可若干三元組 → 審核頁「重建社群摘要」→ 狀態走完、GraphCommunity 有列；AI 知識問答切「全域」問整體性問題 → 得跨社群綜合答案並列參考社群；切「一般」為原 local 行為。
  • 非管理員/他隊：全域問答不出現他隊社群內容（leak=0）。
  • scripts/Test-DocsEncoding.ps1 0 失敗。
