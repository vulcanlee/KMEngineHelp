「資料定義」5 頁：放寬區塊垂直間距（1.0.52）

  • 日期：2026-07-25
  • 版本：1.0.51 → 1.0.52
  • 類型：使用體驗修正（版面間距，純 CSS）

問題

延續 1.0.51（儀表板/RAG 診斷段落間距）之後，使用者反映「資料定義」子選單底下的每個頁面同樣過於擁擠、區塊之間垂直間距太小、有壓迫感。此群組（Menu.json id 6）含 5 個清單頁：分類清單 /categories、團隊清單 /teams、提示詞清單 /prompts、清洗設定檔 /cleaning-profiles、專案分類 /work-categories。

這 5 頁都是單純清單頁（版面為「（部分頁有）說明文字 → 工具列 → 表格」），間距只靠說明列 margin-bottom: 8px、工具列 margin-bottom: 12px，表格外層無間距，區塊貼得很近。

變更

只改 5 個 View 的 scoped CSS，加大區塊之間垂直間距；不動 razor、不動全域 app.css。

  • *-view-toolbar { margin-bottom: 12px → 20px }（工具列↔表格，5 頁全部）。
  • *-view-hint { margin-bottom: 8px → 12px }（說明↔工具列，僅 CategoryViewView、WorkCategoryViewView 兩頁有說明列）。

檔案（前綴）：Categories/CategoryViewView.razor.css（category-view-）、WorkCategories/WorkCategoryViewView.razor.css（work-category-view-）、Teams/TeamViewView.razor.css（team-view-）、Prompts/PromptViewView.razor.css（prompt-view-）、CleaningProfiles/CleaningProfileViewView.razor.css（cleaning-profile-view-）。

影響範圍

  • 純版面間距調整，無邏輯、無資料、無 razor/C# 異動，無資料庫 migration。
  • 表格列高不動：查證確認這 5 個表格未指定 Size、走 AntDesign 預設，每列儲存格上下內距已是 16px（本就寬鬆），故不覆寫列高、只放寬區塊間距。
  • appsettings.json SystemVersion 1.0.51 → 1.0.52。

驗證

  1. dotnet build 通過。
  2. 逐一開啟 /categories、/teams、/prompts、/cleaning-profiles、/work-categories：說明列/工具列/表格三段之間有明顯留白、不再擁擠；表格每列高度不變。
