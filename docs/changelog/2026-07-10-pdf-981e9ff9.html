知識庫問答與 AI 對話：AI 回覆可下載為 PDF（0.3.18）

  • 日期：2026-07-10
  • 版本：0.3.17 → 0.3.18
  • 對應 PRD：知識庫問答 PRD、知識來源 AI 對話 PRD

摘要

「知識庫問答」與「知識來源 AI 對話」兩個聊天頁，於每則 AI 回覆既有的「複製」按鈕旁， 新增一個下載 PDF按鈕：把該則生成的 Markdown 內容轉成 PDF 檔並下載（單則匯出）。

內容

  • 單則匯出：按鈕放在每則 AI 回覆下方的動作列，只匯出該則內容（與複製鈕範圍一致）；

串流未完成、尚無內容的回覆不顯示動作列。

  • 繁體中文不亂碼：伺服器端以 QuestPDF 產生 PDF，內嵌 Noto Sans TC（OFL 授權）字型並設為

預設字型；程式碼區塊與特殊字元字型同樣指向繁中字型，確保無亂碼、文字可選取。

  • 一鍵下載：PDF bytes 透過 Blazor DotNetStreamReference 串流回瀏覽器，直接觸發下載，

檔名含時間戳（如 知識庫問答_yyyyMMddHHmmss.pdf、知識來源對話_yyyyMMddHHmmss.pdf）。

實作

  • 新增 Components/Commons/ChatPdfExporter.cs：靜態 Generate(markdown, title)，

以 QuestPDF ＋ QuestPDF.Markdown 將 Markdown 轉為 PDF byte[]（A4、1 吋邊界、頁碼）。

  • Program.cs：啟動時設定 QuestPDF.Settings.License = Community，並以

FontManager.RegisterFont 註冊內嵌字型 Resources/Fonts/NotoSansTC.ttf。

  • KnowledgeExtraction.Web.csproj：新增 QuestPDF、QuestPDF.Markdown 套件

（並將 Markdig 由 1.3.0 提升至 1.3.2 以符合相依）；字型檔設 CopyToOutputDirectory。

  • wwwroot/js/chat.js：window.keChat 新增 downloadFileFromStream(fileName, streamRef)。
  • KnowledgeBaseChatView 與 KnowledgeSourceChatView（各 .razor ＋ .razor.cs）：

動作列新增「下載 PDF」按鈕，並新增 DownloadPdfAsync(content)（沿用既有 IJSRuntime 注入）。

備註

  • 無資料模型變更，不需要資料庫 migration。
  • 聊天訊息為前端暫存、無持久化 Id，故不新增 controller 端點，直接於元件內產生並串流下載。
