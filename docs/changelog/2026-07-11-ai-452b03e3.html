AI 聊天紀錄＋滿意度回饋＋首頁滿意度統計（0.3.28→0.3.29）

  • 日期：2026-07-11
  • 版本：0.3.28 → 0.3.29
  • 類型：新功能

需求

需要保留每一次 AI 聊天「送進大語言模型的提示詞」與「模型回覆」的全文，供事後查閱「哪位使用者問了什麼、AI 怎麼回、答得好不好」。決策：全文存實體檔案、不入資料庫（目錄可由 appsettings.json 指定、每年一子目錄，比照逐字稿/清洗/Wiki 既有架構）；資料庫只留一筆索引（含提問者身分與滿意度）。並讓提問者對每則答案回饋滿意/不滿意，首頁儀表板顯示最近 30 天滿意度。

變更

資料層

  • 新增實體 LlmChatLog（AccessDatas/Models/LlmChatLog.cs）：只存中繼資料（CreatedAt/UserAccount/UserName/IsAdmin/Origin/KnowledgeSourceId/KnowledgeSourceTitle/Confidence/TopScore/WasBlocked/RelativePath/Feedback/FeedbackAt），不存提問與回覆本文。BackendDBContext 加 DbSet 與 CreatedAt 索引。
  • 雙 provider migration AddLlmChatLog（Sqlite 於 AccessDatas；SqlServer 於 AccessDatas.SqlServerMigrations）。

商業層

  • 新增 ChatLogService（Business/Services/DataAccess/）：WriteAsync（全文寫 ExternalFileSystem.ChatLogPath 下 {yyyy}/{guid}.md、UTF8Encoding(false)，DB 寫索引列）、SetFeedbackAsync、QueryAsync（分頁/篩選）、ReadContentAsync（讀檔顯示）。記錄失敗一律 try/catch 隔離、不中斷聊天。
  • DashboardService 加最近 30 天全站滿意/不滿意計數（DashboardViewModel.ChatSatisfaction）。

UI 層

  • 知識庫問答與知識來源 AI 對話兩個 View 於每輪答完（finally）呼叫 ChatLogService.WriteAsync（含「查無依據」未送 LLM 也記一筆），並以訊息實例為鍵記下 logId。
  • 新共用元件 ChatFeedbackBar（👍滿意/👎不滿意，可改可取消）掛在每則答案下方 → SetFeedbackAsync。
  • 新增管理員專用頁 /chat-logs（Components/Pages/ChatLogs + Views/ChatLogs）：CheckIsAdmin() 把關、篩選（使用者/日期/來源/滿意度）、分頁表、「查看全文」Modal。Menu.json 系統管理群組加 id 47（adminOnly，不進權限樹）。
  • 首頁儀表板新增「最近 30 天 AI 回答滿意度」區塊。

設定

  • ExternalFileSystem 新增 ChatLogPath；appsettings.json 加預設值 C:\temp\KnowledgeExtraction\ChatLog。

範圍決策（誠實記錄）

  • 全文刻意保留於檔案（與 SEC-5 稽核 KnowledgeBaseQueryAudit 只存長度/分數不同）；以管理員專用查閱＋可設定目錄控管，屬明確需求。
  • 聊天紀錄無保留/清理策略（每輪一檔、持續成長）；本次不做自動清理，需管理員監控磁碟。
  • 滿意度存 DB（可改可取消、只留最後一次），全文檔案保持不可變、不因回饋而改寫。
  • 儀表板滿意度為全站彙總、不套團隊權控（純數字、不含內容）。

  1. 乾淨建置 0 錯誤；雙 provider migration AddLlmChatLog 產生成功（僅建 LlmChatLog 表＋CreatedAt 索引）。
