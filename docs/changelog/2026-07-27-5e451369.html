變更紀錄

新增「資料表使用狀況」管理頁（1.0.81 → 1.0.82）

  • 日期：2026-07-27
  • 版本：1.0.81 → 1.0.82
  • 類型：新增管理者診斷頁

背景

管理員需要總覽資料庫健康度：每張資料表的筆數、佔用儲存空間、索引數量，用來評估資料成長、找出異常膨脹的表、規劃維運。既有頁面無法滿足（/system-health 只給總檔案大小、DashboardView 只給業務筆數卡片）。新增 /table-usage，定位為管理者診斷工具，比照 /system-health、/data-consistency、/dashboard 放「系統管理 > 系統監控與日誌」、僅管理員可見。

變更

  1. 新增服務 KnowledgeExtraction.Business/Services/DataAccess/TableUsageService.cs（Scoped，注入 BackendDBContext + ILogger）：
  2. 供應商以 Database.ProviderName 字串判斷（避免 Business 層相依 Sqlite 套件）。
  3. 筆數：對每表原生 SELECT COUNT(*)（識別字依供應商加界定符 "name"／[name]）。
  4. 索引數：EF 模型 entityType.GetIndexes().Count()（provider 無關，不含主鍵自動索引）。
  5. 儲存空間：SQLite 以 dbstat 虛擬表估算每表資料頁大小，該 build 不支援時 PerTableSizeSupported=false、各列 SizeBytes=null；總大小＝PRAGMA page_count × page_size（對檔案與 :memory: 皆可靠）。SQL Server 走 sys.dm_db_partition_stats join sys.tables 取每表 reserved 空間、總大小為加總。
  6. 這是專案第一處原生 SQL；SQLite 與 SQL Server 兩分支皆已處理。
  7. 新增模型 KnowledgeExtraction.Models/AdapterModel/TableUsageReportAdapterModel.cs（TableUsageReportAdapterModel + TableUsageRowAdapterModel）。
  8. 新增頁面 KnowledgeExtraction.Web/Components/Pages/TableUsagePage.razor（＋ .razor.css）：@page "/table-usage"，比照 SystemHealthPage 以 Check + CheckIsAdmin() 守衛；AntDesign <Table> 呈現，欄位（資料表／筆數／索引數／儲存空間）可排序，頂部顯示供應商、資料庫總大小、產生時間與重新整理；dbstat 不支援時顯示提示、儲存空間欄顯示 N/A。
  9. DI：ServiceCollectionExtensions.AddApplicationServices 加 services.AddScoped<TableUsageService>();。
  10. 選單：Datas/Menu.json 於「系統監控與日誌」(id 502) 末尾新增 { id:514, name:"資料表使用狀況", icon:"storage", url:"/table-usage", adminOnly:true }。圖示 storage 已在 MenuIconTests.AllowedLeafIcons；因整條路徑皆 adminOnly，依既有豁免規則不動 MagicObjectHelper／RolePermissionService／權限守護測試。
  11. 測試：新增 TableUsageServiceTests（2 條）——涵蓋全部應用表、筆數正確、VectorEmbedding 索引數>0，且不論 dbstat 是否支援皆不拋例外。
  12. appsettings.json：SystemVersion 1.0.81 → 1.0.82。
  13. 文件：本 changelog、索引，docs/architecture/開發慣例與限制速查.md adminOnly 診斷頁清單補 /table-usage。

刻意不變更

  • 只涵蓋 BackendDBContext 的 30 張應用資料表，不列 __EFMigrationsHistory 等系統表。
  • 索引數採 EF 模型宣告數（不含主鍵自動索引），使用者接受此近似。
  • MagicObjectHelper／RolePermissionService／權限守護測試／MenuIconTests：adminOnly 豁免、圖示已允許。

驗證

  • dotnet build 成功；dotnet test 760 全綠（既有 758 + 新增 2）。
  • 手動：管理員於「系統管理 > 系統監控與日誌 > 資料表使用狀況」進入 /table-usage，看到 30 張表的筆數與索引數；SQLite 顯示資料庫總大小，每表大小為估算值或 N/A（視 dbstat 支援）；非管理員看不到選單項、直接開 /table-usage 被拒。
  • scripts/Test-DocsEncoding.ps1 確認文件為 UTF-8 含 BOM。
