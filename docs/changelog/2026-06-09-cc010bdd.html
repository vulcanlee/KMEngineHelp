2026-06-09 提示詞清單功能

摘要

新增「提示詞清單（Prompt）」CRUD 管理頁面（路由 /prompts），位於側邊選單「資料定義」群組，供使用者集中維護可重複使用的 LLM 提示詞。系統版本 0.2.42 → 0.2.43。

異動內容

  • 新增 Prompt 實體與雙 provider migration（AddPrompt，Sqlite 與 SQL Server）。
  • 新增 PromptAdapterModel、PromptDto、PromptCreateUpdateDto、PromptSearchRequestDto。
  • 新增 PromptRepository、PromptService（名稱唯一性：Trim + 忽略大小寫，編輯排除自身；預設依 UpdatedAt 新到舊）。
  • 新增 PromptController（search / get / create / update / delete，名稱重複回 409）。
  • 新增 Blazor 頁面 PromptPage 與檢視元件 PromptViewView（提示詞本文為多行 TextArea，Enter 不自動送出）。
  • 權限三處同步：MagicObjectHelper 新增 角色_提示詞清單；RolePermissionService 於「資料定義」群組末端加入；Menu.json 新增子項 id 43。
  • 提示詞本文 Content 為必填長文字欄位（上限 8000 字）。
  • 新增 PromptServiceTests（CRUD、名稱唯一性、預設排序、Content 持久化）。

範圍外（未來延伸）

  • 將提示詞串接至音訊轉錄／會議紀錄等 LLM 生成流程。
  • 提示詞用途分類、變數樣板、版本控管、匯入匯出。
