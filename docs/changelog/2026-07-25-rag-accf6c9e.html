儀表板與 RAG 診斷頁：放寬區塊/段落垂直間距（1.0.51）

  • 日期：2026-07-25
  • 版本：1.0.50 → 1.0.51
  • 類型：使用體驗修正（版面間距，純 CSS）

問題

使用者反映兩個管理頁面看起來擁擠、段落之間缺乏適當垂直間距：

  • 首頁儀表板（/App）「經營洞察」：1.0.48 已把「管理者專區↔經營洞察」兩大區塊用「直接子區塊 28px + 細分隔線」分開，但「經營洞察」內部的子群組（KPI 卡列 → 三個 Top 榜 → 最受歡迎功能/改善方向訊號）是孫層、拿不到那條規則，彼此擠在一起；h4 標題（Token 用量 Top、最受歡迎的功能）上緣只有 4px，貼著上方內容。
  • RAG 診斷（/rag-diagnostics）：段落間距只靠 .rag-diag-section { margin-top: 20px }、h3 { margin-bottom: 8px }，偏小且無分隔線，整頁擁擠。

變更

僅改兩個 scoped CSS 檔，不動 razor 結構、不動全域 app.css。

  • Components/Views/RagDiagnostics/RagDiagnosticsView.razor.css：
  • .rag-diag-section margin-top 20 → 24px。
  • 新增 .rag-diag-section:not(:first-of-type)：margin-top/padding-top: 28px + border-top: 1px solid #f0f0f0（第一段緊接統計卡片列，只留白不畫線；其後每段各有淡色細分隔線分段，比照儀表板大區塊慣例）。
  • .rag-diag-section h3 margin-bottom 8 → 12px。
  • Components/Views/Dashboard/DashboardView.razor.css：
  • .dashboard-insights h4 margin 4px 0 8px → 0 0 10px（標題不再貼著上方內容）。
  • 新增 .dashboard-insights .dashboard-columns { margin-top: 24px }：讓經營洞察內部三組欄群（三個 Top 榜、最受歡迎功能/改善方向訊號）與上方內容分開。大區塊已有分隔線，內部僅用留白、不重複加線。

影響範圍

  • 純版面間距調整，無邏輯、無資料、無 razor/C# 異動，無資料庫 migration。
  • 管理者專區↔經營洞察大區塊分隔線（1.0.48）維持不變。
  • appsettings.json SystemVersion 1.0.50 → 1.0.51。

驗證

  1. dotnet build 通過。
  2. /App：經營洞察三組欄群之間有明顯留白、h4 標題不再貼上方；大區塊分隔線不變。
  3. /rag-diagnostics：各段落之間留白加大且有淡色細分隔線分段，整頁不再擁擠。
