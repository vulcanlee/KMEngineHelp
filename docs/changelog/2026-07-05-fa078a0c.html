版本

  • appsettings.json：SystemSettings.SystemInformation.SystemVersion 由 0.2.159 (2026/07/04) 遞增為 0.2.160 (2026/07/05)。

背景

策略、行銷與簡報文件仍停留在早期狀態，宣稱版本 v0.2.42、C# 檔約 277 個，並把「清洗」標為僅格式轉換、「知識庫」與「附加應用」標為「尚無」。但實際程式碼早已完成完整清洗管線（去重／遮罩／分類／摘要／品質過濾）、知識蒸餾、階段三 RAG 全流程（向量庫、切塊、Embedding、索引、混合檢索、Query Rewrite、問答 UI、RAG 評測）、AI 技能產生器，以及 chunk 級團隊權控。本次以程式現況為準，全庫掃描並校正「與程式碼牴觸」的現況敘述。

異動內容（僅文件與版本號）

  • 更新 strategy/01 計畫範圍與遠景：修正版本（v0.2.160）、C# 檔數（約 340，不含 migrations）、重寫「與現有系統的關係」現況表（清洗／知識庫／附加應用由 ⚠️/❌ 改為 ✅ 並保留真實待補），並為階段二／三／四補上「現況」段落。
  • 更新 strategy/09 企業應用情境型錄：各情境「平台對應」移除已實作的「向量檢索／問答 UI／權控檢索」，保留仍未實作項目（版本控管、結構化抽取、Agent 工作流等）；同步更新開頭「既有能力／共通待補」清單。
  • 更新 marketing/商業簡報-決策投資版：現況表與 C# 檔數同步；「近期路線圖」標註各階段已交付版本；並重建 .pptx、同步 .html。
  • 更新 presentation/旗艦簡報：「我們在哪裡」能力狀態表由「🔄 即將上線」改為「✅ 現已可用」（僅 AI Agent 自動化工作流保留「🔄 規劃中」）；重建 .html 與 .pptx。
  • 更新 presentation/旗艦簡報・講者指南：「誠實分層」原則由「匯入以外尚在開發」改為「完整閉環已可用、可當場示範，僅 Agent 工作流規劃中」，並同步逐頁講稿、Q&A、反對意見與時間配置。
  • 收尾：以 marp CLI 重新產生 商業簡報-決策投資版.html（取代先前手動同步）；並回填 docs/README 與 changelog/README 落後的 changelog 索引條目（補齊 0.2.132–0.2.138、0.2.153–0.2.159 等，docs/README 維持「最近 50 筆」）。
