移除「AI技能產生器」畫面與功能（1.0.45）

  • 日期：2026-07-24
  • 版本：1.0.44 → 1.0.45

摘要

系統不再需要「AI技能產生器」（路由 /skills、選單 id 43、權限常數 角色_AI技能產生器）。本次將該畫面、僅為其存在的程式碼、資料表與功能表項目一併移除，並同步修正相關文件。既有的實作／PRD changelog（2026-06-20 兩則）保留為歷史紀錄不予更動。

內容

1. 畫面與端點移除

  • 刪除頁面 SkillPage.razor、檢視 SkillView.razor(.cs/.css)、下載端點 SkillController.cs。
  • Menu.json 移除 id 43「AI技能產生器」子項；RolePermissionService 與 MagicObjectHelper 同步移除 角色_AI技能產生器（維持選單↔權限的位置索引對齊）。

2. 服務／背景管線移除

  • 刪除 SkillDefinitionService、SkillGenerationProcessor、SkillGenerationBackgroundService、ISkillGenerationQueue/SkillGenerationQueue、SkillContentHelper、SkillPromptDefaults。
  • 移除 DI 註冊、Program.cs 的 SkillOutputPath 目錄建立與 AddHostedService<SkillGenerationBackgroundService>()。
  • PipelineNames.SkillGeneration 移除；背景處理管線由 8 條調整為 7 條。
  • 儀表板（DashboardService）移除「AI 技能」統計卡片、管線狀態與最近清單列。
  • 系統健康檢查（SystemHealthService）移除 SkillGenerationBackgroundService 檢查項。

3. 提示詞與設定

  • 提示詞槽位「技能-Meta」（SkillMeta）自 LlmPromptKeys、LlmPromptDefaults、LlmPromptsSettings 與 appsettings.json 移除。
  • SystemSettings.SkillOutputPath 與 appsettings.json 對應設定移除。

4. 資料模型與資料庫

  • 移除實體 SkillDefinition、SkillSourceItem 及其 DbSet、關聯設定與 AutoMapper 對應、Adapter 模型。
  • 新增雙資料庫 migration RemoveSkillGenerator（Sqlite 與 SqlServer 各一），刪除 SkillDefinition／SkillSourceItem 兩張資料表。既有技能資料將永久刪除。

5. 文件

  • 刪除專屬文件 docs/prd/AI技能產生器-prd.md、docs/guides/AI技能產生器使用指南.md。
  • 全庫同步移除各索引、權限對照表、開發慣例速查、PRD 矩陣、guides 章節、架構總覽、行銷／策略／簡報等文件中的相關內容。

備註

  • Token 用量紀錄的操作類型常數 LlmTokenUsage.OperationSkillGeneration 與其用量報表標籤刻意保留：它服務的是已寫入的歷史 Token 用量資料，非畫面程式碼，移除會使舊紀錄顯示異常。
  • 既有角色權限 TabViewJson 中殘留的 "AI技能產生器" 字串為孤兒字串，依名稱比對找不到節點即忽略，不影響資料正確性。
  • 驗證：dotnet build 0 錯誤；623 測試全綠；MenuPermissionAlignmentTests 通過（確認位置索引未漂移）。
