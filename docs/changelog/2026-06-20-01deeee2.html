0.2.99 關閉鈕固定可見＋加入素材分頁

對話窗放大後，內容過長導致：關閉鈕需捲動才看得到；右側「加入素材」清單一次顯示多筆且無分頁。本次：

  • 關閉鈕固定可見：.member-manage-modal .ant-modal-body 改為固定高度 calc(100vh - 150px)、overflow:hidden 的 flex 直向容器；.ks-member-layout 填滿剩餘高度、左右兩欄各自 flex 直向，.ks-member-list 改 flex:1; overflow:auto（只有清單內部捲動），.ks-member-footer 固定於 body 底部恆可見。
  • 加入素材分頁：右側清單改為每頁 MemberPageSize=20 筆，新增「上一頁／下一頁」與「第 X / Y 頁（共 N 筆）」；切換型別/搜尋/分類/團隊/排序或開窗時回到第 1 頁。查詢本就 Skip/Take 分頁（非全載），此為明確化分頁操作。
  • appsettings.json 0.2.98 → 0.2.99。

0.2.98 移除重複的關閉按鈕

對話窗底部原有兩個都叫「關閉」、且都呼叫 OnMemberModalCloseAsync 的按鈕（AntDesign 預設 Ok/Cancel，OkText/CancelText 皆設為「關閉」），重複且易混淆。改為：

  • 兩頁管理成員 <Modal> 設 Footer="null" 移除預設兩顆按鈕；OnCancel 仍處理右上角 X 與 Esc 關閉。
  • 於對話窗內容底部新增單一「關閉」主要按鈕（.ks-member-footer 右對齊），其餘行為不變。
  • appsettings.json 0.2.97 → 0.2.98。

0.2.97 放大對話窗

承 0.2.96，原僅縮小內距但對話窗仍固定約 900px、置中，寬螢幕四周留白過大。本次將兩頁「管理成員」對話窗放大至接近滿版：

  • wwwroot/app.css .member-manage-modal：寬度 92vw（上限 1400px）、top: 24px 貼近上緣；.ant-modal-body max-height: calc(100vh - 140px) 可捲動。
  • 兩個 scoped CSS .ks-member-list max-height 由 50vh 改為 calc(100vh - 230px)，兩欄清單隨對話窗加高並各自捲動。
  • 不改對話窗結構與邏輯；appsettings.json 0.2.96 → 0.2.97。

需求

知識來源管理清單與 AI技能產生器兩頁的「管理成員」對話窗：

  1. 上下左右留白太多，需縮小。
  2. 右半部「加入素材」區塊除標題關鍵字外，再加入「依最近更新日期排序（預設最近優先、可切最舊優先）」與「分類、團隊」篩選。

變更（兩頁對稱）

  • 留白：管理成員 <Modal> 的 Class 加 member-manage-modal；wwwroot/app.css 全域縮小 .member-manage-modal .ant-modal-body／.ant-modal-header padding（24px → 12/16px）；scoped CSS 兩欄間距 24px → 16px、工具列下距與標題邊距收斂、工具列換行。
  • 服務 KnowledgeSourceService / SkillDefinitionService 的 GetSelectableItemsAsync：Selectable* 三個 helper 新增分類/團隊篩選參數（TagStringHelper.BuildContainsAnyPredicate，疊加於既有狀態=已完成、關鍵字、團隊存取範圍之上）；排序改依 DataRequest.SortDescending（預設 desc＝最近更新優先，可切 asc）。
  • UI KnowledgeSourceView / SkillView：右欄新增分類多選、團隊多選、排序下拉（最近更新優先／最舊更新優先）；新增 memberCategoryFilters/memberTeamFilters/memberSortDescending 欄位，開啟對話窗時重置；ReloadSelectableAsync 帶入這些條件。

影響範圍

  • 僅 UI 與可選素材查詢；不改成員加入/移除/排序邏輯、不改 SelectableSourceItemAdapterModel、不動主清單頁。
  • 團隊權控未變：使用者選的團隊篩選只在「可存取範圍」內再縮小。
  • appsettings.json SystemVersion 0.2.95 → 0.2.96。

驗證

  1. dotnet build 通過；dotnet test 全綠。
  2. 兩頁「管理成員」對話窗留白變小；右側可用分類/團隊/關鍵字篩選與最近更新排序（預設最近在前）。
