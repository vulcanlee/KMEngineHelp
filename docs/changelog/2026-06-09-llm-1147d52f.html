2026-06-09 逐字稿依提示詞透過 LLM 產生內容（0.2.44）

摘要

音訊轉錄頁針對「已完成」紀錄，新增「依提示詞透過 LLM 產生內容」功能：選取（並可調整）提示詞清單中的提示詞，將「提示詞 + 三個換行 + 逐字稿」送往 OpenAI 聊天模型，結果保存於該筆紀錄並可檢視、複製到剪貼簿。系統版本 0.2.43 → 0.2.44。

異動內容

  • 設定：OpenAISettings 新增 GenerationModel（預設 gpt-5.4）與 GenerationTimeoutSeconds（預設 120）；共用既有 ApiKey／BaseUrl。appsettings.json 同步新增。
  • 資料模型：MediaTranscription 新增 GeneratedContent、GeneratedAt 欄位（雙 provider migration AddGeneratedContentToMediaTranscription）；MediaTranscriptionAdapterModel 對應新增欄位與唯讀 HasGeneratedContent。
  • 聊天用戶端 OpenAIChatCompletionClient：呼叫 chat/completions（Bearer、最小請求欄位），靜態 BuildRequestBody／ParseContent 便於測試。AddHttpClient<OpenAIChatCompletionClient>（逾時取 GenerationTimeoutSeconds）。
  • 產生服務 LlmGenerationService：ComposePrompt（三換行規則）＋ GenerateAsync（呼叫 LLM 並寫回結果）；僅依賴 DbContext 與聊天用戶端，可於背景獨立 DI scope 安全執行。AddScoped<LlmGenerationService>()。
  • 提示詞下拉：PromptService 新增 GetAllEnabledAsync()（啟用中、依名稱排序、含本文）。
  • UI：MediaTranscriptionView 操作區新增「依提示詞產生」（✨）與「檢視產生結果」（📑）圖示；產生對話窗（單選可搜尋下拉 + 多行文字盒）、結果對話窗（唯讀 + 複製到剪貼簿，IJSRuntime 介接 navigator.clipboard.writeText）。背景產生：對話窗即時關閉並提示，完成後自動刷新讓檢視圖示出現；逐字稿讀取在 UI 執行緒（含團隊權控）先取得後再丟背景。
  • 測試：新增 LlmGenerationServiceTests（三換行）、OpenAIChatCompletionClientTests（請求／回應解析），PromptServiceTests 新增 GetAllEnabledAsync 測試。全套 132 個測試綠燈。
  • 文件：更新資料模型、設定檔說明、EFCore migration 清單、README 索引；新增本功能 PRD。

範圍外（未來延伸）
