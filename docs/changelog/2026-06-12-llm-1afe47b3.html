LLM 雲端/地端切換 + 容量邊界文件（0.2.67）

  • 日期：2026-06-12
  • 版本：0.2.66 → 0.2.67
  • 對應路線圖：資料清洗開發代辦清單（第三階段尾巴 + A4）

一、LLM 雲端/地端切換（設定驅動）

聊天/生成＋視覺 LLM 可由設定切換雲端 OpenAI 或地端 OpenAI 相容伺服器（Ollama／LM Studio／vLLM）， 支援「資料不出企業環境」的地端部署。語音轉錄（Whisper／gpt-4o-transcribe）維持雲端（OpenAI 專屬）。

  • OpenAISettings 新增 GenerationProvider（Cloud/Local）、LocalBaseUrl、LocalGenerationModel、

LocalApiKey（選填）、LocalGenerationTimeoutSeconds（預設 300）；新增 GetGenerationProvider()／ ResolveChatLlm()／IsChatLlmConfigured()。

  • OpenAIChatCompletionClient：金鑰檢查改為依 provider（RequiresApiKey）——地端免金鑰時不拋錯、不送

Authorization 標頭；BaseUrl/Model/逾時取自解析後的設定。Program.cs 的聊天 HttpClient 依 ResolveChatLlm() 配置。

  • CleaningEnhancer 的「未設定 LLM 則略過」改用 IsChatLlmConfigured()（地端已設定即不再誤略過）。
  • 切換於啟動時生效（改設定需重啟，比照 DatabaseProvider）。地端模型須支援視覺才適用圖片解讀。
  • 設定說明與 Ollama 範例見 日誌與設定檔說明 §4.8。
  • 測試：OpenAISettingsTests（provider 解析、ResolveChatLlm、IsChatLlmConfigured、金鑰必要性）共 14 筆；全測試 236 筆綠燈。

二、A4 容量邊界文件

新增 容量邊界與限制：彙整各管線上傳上限（文件 1GB／圖片 50MB／音訊 1GB）、 Whisper 25MB·1200s 自動分段、各逾時、允許格式，以及「靜默失敗風險」（MarkItDown 格式未預檢、FFmpeg 路徑、 抖音逾時、Kestrel/SignalR 預設、Blazor InputFile 30MB）。數值對齊程式常數。

備註

  • 純文件部分（容量邊界）不獨立計版本，隨本版（含 LLM 切換程式）一起提交。
  • 地端 ASR（語音轉錄）為未來另案。
