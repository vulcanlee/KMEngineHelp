system-health：ApiKey 未設定提升為紅色錯誤（0.2.88）

  • 日期：2026-06-19
  • 版本：0.2.87 → 0.2.88
  • 類型：行為調整

需求

/system-health 的「OpenAI API 設定」檢查原本以「失敗項目數量」決定狀態，ApiKey 單獨空白時僅為 Degraded（黃燈警示）。ApiKey 為轉錄／生成功能的必要條件，缺它整個功能無法運作，應提升為紅色錯誤。

變更

  • SystemHealthService.CheckOpenAIApiSettings()：新增 apiKeyMissing 判斷，ApiKey 空白時一律 Unhealthy（紅燈／異常）；BaseUrl／Model 等其他問題維持依數量計分。
  • 金鑰內容仍不外洩：證據欄沿用 MaskPresence() 只顯示「已設定／未設定」，失敗訊息顯示「設定問題：ApiKey 未設定。」。
  • 更新 docs/features/系統健康監控.md 對應說明；appsettings.json SystemVersion 0.2.87 → 0.2.88。

影響範圍

  • 僅前端健康燈號狀態與文件；無資料庫變更，不需 migration。

驗證

  1. 將 OpenAISettings:ApiKey 留空 → /system-health 該項為紅燈（異常）並顯示「設定問題：ApiKey 未設定。」。
  2. 填入金鑰 → 恢復綠燈（正常），證據顯示「已設定」。
