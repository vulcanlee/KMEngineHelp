變更紀錄

登入頁科技神秘風重設計紀錄

變更目的

將 /Auths/Login 由既有的翡翠綠玻璃擬態，升級為「霓虹翡翠・科技神秘風」：暗黑底 + neon emerald 發光 + cyan 點綴，並同步更新首頁 Splash 的配色與文案，維持全站一致的登場感。

設計方向

  • 主色調：暗綠黑底（#04120b→#0a3322）＋霓虹翡翠（#34d399 / #6ee7b7）＋青藍點綴（#22d3ee），延續品牌綠、轉為暗黑矩陣感。
  • 四種特效：① 動態透視網格（數位地平線）② 粒子連線節點（canvas constellation）③ 掃描線 + 卡片光暈脈動 ④ 標題微 glitch + kicker 打字游標。

本次修改檔案

  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/Auths/Login.razor（裝飾層、標題 data-text、打字 kicker、文案、引用 login-fx.js）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/Auths/Login.razor.css（全面改寫為霓虹翡翠暗黑風）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/Auths/Login.razor.cs（登入失敗訊息語氣微調）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/wwwroot/js/login-fx.js（新增：粒子連線 canvas 特效）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/Views/Commons/SplashView.razor（+ .razor.css，同步配色與文案）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/appsettings.json（版本 0.2.155→0.2.156）

文案調整（登入頁）

  • Badge：ENTERPRISE ACCESS → SECURE GATEWAY
  • 定位文案：改為「串接企業分散的文件、會議與影音，淬鍊為可搜尋、可問答、可傳承的智慧知識核心。」
  • 表單 kicker（打字效果）：Welcome Back → IDENTITY VERIFICATION
  • 副標：使用者登入 → 身分核驗；說明：改為「請完成身分驗證以連線至知識核心。」
  • 安全提示：企業級安全登入 → 端對端加密連線
  • 登入失敗預設訊息：改為「身分驗證失敗，請重新確認帳號與密碼。」
  • 欄位標籤、placeholder、使用 Google 登入 等維持不變（功能清晰優先）。

文案調整（Splash）

  • eyebrow：Welcome → SYSTEM ONLINE
  • 載入句：改為「正在初始化知識核心，為你準備工作環境…」
  • 定位文案與登入頁保持一致。

可及性與效能

  • 全面支援 prefers-reduced-motion：使用者偏好減少動態時，網格／掃描線／glitch／打字／粒子動畫皆停止，畫面仍完整可用。
  • login-fx.js 為自足 vanilla JS，無相依；找不到 canvas 或偏好減少動態時安全略過；分頁隱藏時暫停 rAF 省資源；節點數依面積計算並設上限保護效能。
  • 響應式維持 960/768/480 三斷點；小螢幕降低特效強度（隱藏透視網格）確保表單可用。

未變更

  • 登入後端邏輯、表單欄位 name／繫結、FormName="login"、SSR POST 流程、路由與 AntDesign 設定皆未更動。

編碼要求

  • 本次新增與更新的文件皆以 UTF-8（含 BOM）保存，內容為繁體中文、無亂碼。
