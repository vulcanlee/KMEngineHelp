編修對話窗左右兩側各加複製按鈕（1.0.1）

  • 日期：2026-07-13
  • 版本：1.0.0 → 1.0.1
  • 類型：功能強化 / UI

需求

共用內容編修對話窗 ContentEditDialog（標題如「編修產生結果」）左半部「編輯內容」與右半部「預覽」， 要各加一顆「複製」按鈕，可分別複製這兩邊的內容到剪貼簿：

  1. 左側「複製」→ 複製編輯區的原始文字（Markdown 原始碼）。
  2. 右側「複製」→ 複製預覽區實際看到的純文字（Markdown 符號已套用，例如 **粗體** 顯示為「粗體」）。
  3. 兩個按鈕在所有使用此對話窗的頁面固定顯示。

變更

ContentEditDialog（共用元件）

  • 左側標題列「複製」鈕改為固定顯示（移除原 ShowCopy 參數與 @if (ShowCopy) 判斷）；行為不變，仍以 navigator.clipboard.writeText 複製編輯區 editingText（Markdown 原始碼）。
  • 右側「預覽」標題列新增一顆「複製」鈕，複製預覽區的可見純文字；預覽 div 加上 @ref="previewRef"，透過新方法 OnCopyPreviewAsync 呼叫 keChat.copyElementText 讀取其 innerText 後複製（含成功/失敗訊息）。
  • 移除 ShowCopy 參數：改為兩側固定顯示，不再需要逐頁開關。

wwwroot/js/chat.js

  • window.keChat 新增 copyElementText(element)：讀取指定 DOM 元素的 innerText（Markdown 已渲染的可見純文字）並 navigator.clipboard.writeText 複製，回傳成功與否。

呼叫端

  • 移除三處 ShowCopy="true" 屬性（參數已刪除）：WikiPageView、SkillView、KnowledgeSourceView。其餘使用點原本未設 ShowCopy，本次改為兩側皆顯示複製鈕。

影響範圍

  • 變更檔案：Components/Commons/ContentEditDialog.razor、wwwroot/js/chat.js、Components/Views/WikiPages/WikiPageView.razor、Components/Views/Skills/SkillView.razor、Components/Views/KnowledgeSources/KnowledgeSourceView.razor、appsettings.json（版本）。
  • 無模型／資料庫變更，不需 migration。

驗證

  1. 於任一有此對話窗的頁面（如 SkillView 的「編修產生結果」）開窗，左右兩側標題列各有「複製」鈕。
  2. 左側「複製」→ 貼到記事本為 Markdown 原始碼（含 **、# 等符號）。
  3. 右側「複製」→ 貼到記事本為 純文字（**粗體** 已變「粗體」、清單符號已套用）。
  4. 各顯示「已複製到剪貼簿」成功訊息；「儲存／關閉／搜尋取代」等既有功能不受影響。
