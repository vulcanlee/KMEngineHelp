Token 用量記錄與查閱頁＋首頁 30 天 Token 統計（0.3.29→0.3.30）

  • 日期：2026-07-12
  • 版本：0.3.29 → 0.3.30
  • 類型：新功能

需求

系統每次呼叫 OpenAI 都會拿到 usage（各類 token 統計），但過去只寫 NLog、未持久化，無法查閱、篩選或彙總。需求：把每次呼叫的 token 用量存進可查詢的資料表，記錄「哪個作業/畫面、哪個使用者、哪個模型、各類 token 數」；提供管理員查閱頁（可依使用者、作業、模型、時間區間篩選）；首頁儀表板顯示最近 30 天、依 token 類型的全站用量。

變更

資料層

  • 新增實體 LlmTokenUsage（CreatedAt/使用者/Operation/CallType/Model/RecordId/各類 token 欄位/DetailsJson），BackendDBContext 加 DbSet 與 CreatedAt 索引；雙 provider migration AddLlmTokenUsage。

情境（作業/使用者）

  • 新增 OperationContext（AsyncLocal，Share/Helpers）攜帶「作業/紀錄Id/使用者」，沿 async 鏈流到 client。
  • 背景佇列帶入提交者身分：6 個佇列（Cleaning/Distillation/EmbeddingIndex/SkillGeneration/Transcription/ImageRecognition）載荷改 PipelineJob(Id, UserAccount, UserName)，EnqueueAsync 加可選身分參數；入列服務傳 CurrentUser；6 個背景服務迴圈 OperationContext.Push；系統復原入列身分為 null。互動端於知識庫問答／知識來源對話 View 的 SendAsync Push。

記錄與落地

  • TokenUsageParser（沿用 TokenUsageFormatter 攤平邏輯，回傳結構化用量＋DetailsJson）。
  • ITokenUsageRecorder/TokenUsageRecorder（singleton＋Channel，非阻塞、失敗隔離）於 3 個 OpenAI client 的 4 個擷取點呼叫；TokenUsageWriterBackgroundService（hosted）以自建 scope 的獨立 BackendDBContext 批次落地。

UI

  • 新增管理員頁 /token-usage（TokenUsageQueryService 分頁/篩選/合計；篩選含使用者、時間區間、作業、型別、模型；上方顯示合計列）；Menu.json 系統管理群組 id 48（data_usage，adminOnly）。
  • 首頁儀表板新增「最近 30 天 Token 用量」區塊（送出/接收/推理/快取/合計，全站彙總）。

測試

  • TokenUsageParserTests（chat/embedding/transcription 三種 usage 形狀＋空值）。
  • 更新受佇列介面變更影響的測試假件與服務建構；補 MenuIconTests/CrudActionIconTests 允許清單（data_usage、chat、history）。

範圍決策（誠實記錄）

  • Token 用量純數字、不含內容本文；記錄失敗一律隔離，絕不影響 LLM 主流程。
  • 無保留/清理策略（每次呼叫一列）；管理員需留意資料表成長，必要時自行封存。
  • 儀表板為全站彙總、依 token 類型、不套團隊權控（純數字）。
  • 互動作業標籤目前涵蓋兩個聊天入口與 6 條背景管線；其餘互動作業（媒體/文件生成、RAG/黃金評測、RAG 診斷試檢索）仍會記錄，但作業欄暫退化為 API 型別、使用者可能為空（後續可再補 OperationContext.Push）。

影響範圍

  • appsettings.json SystemVersion 0.3.29 → 0.3.30。

  1. 全解決方案建置 0 錯誤；雙 provider migration AddLlmTokenUsage 僅建 LlmTokenUsage 表＋CreatedAt 索引。
  2. App 於 Development 啟動、自動套用 migration，確認 SQLite 已建 LlmTokenUsage 表與 IX_LlmTokenUsage_CreatedAt；TokenUsageWriterBackgroundService 啟動。
  3. dotnet test 全綠（504 通過，含 TokenUsageParserTests）。
  4. scripts/Test-DocsEncoding.ps1 全綠。
