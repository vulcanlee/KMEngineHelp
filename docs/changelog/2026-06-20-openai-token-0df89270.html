OpenAI chat 呼叫記錄 token 用量到日誌（0.2.93）

  • 日期：2026-06-20
  • 版本：0.2.92 → 0.2.93
  • 類型：可觀測性（日誌）

需求

清洗等流程會呼叫 OpenAI Chat Completions，但原本 OpenAIChatCompletionClient 只取 choices[0].message.content、丟棄回應的 usage，且未注入 logger，導致日誌看不到送出/接收的 token 數。需求是讓日誌能看到每次呼叫的 token 用量。

變更

OpenAIChatCompletionClient

  • 建構式注入 ILogger<OpenAIChatCompletionClient>（typed HttpClient 由 DI 自動注入；未改 IChatCompletionClient 介面與任何呼叫端）。
  • 新增靜態 ParseUsage(responseJson) → ChatUsage（PromptTokens/CompletionTokens/TotalTokens，可空；無 usage 回空值）。
  • 新增私有 LogUsage(model, operation, responseBody)：成功回應後記一行 Information：

「OpenAI chat 用量。Operation=… Model=… 送出(prompt)=… 接收(completion)=… 合計(total)=…」；無 usage 記「不可用」；解析失敗只記 Warning，不影響主流程。

  • CompleteAsync／CompleteWithImageAsync／CompleteWithFileAsync 三處各在回傳前呼叫 LogUsage（Operation 分別為 Text/Image/File）。

涵蓋範圍

清洗五步驟（去重/遮罩/分類/摘要/信心自評）、圖片辨識、文件/逐字稿 LLM 生成皆會記錄。一次清洗最多 5 行，夾在 cleaning queued 與 Cleaning completed 之間。

影響範圍

  • 變更檔案：OpenAIChatCompletionClient.cs、OpenAIChatCompletionClientTests.cs、docs/operations/日誌與設定檔說明.md、appsettings.json（版本號）。
  • 僅記 token 數字，不記錄請求/回應內容本文。無資料庫變更，不需 migration。
  • appsettings.json SystemVersion 0.2.92 → 0.2.93。

驗證

  1. dotnet test --filter OpenAIChatCompletionClient 綠燈（6 通過，含 2 筆新 ParseUsage 測試）。
  2. 設好 OpenAI 金鑰後按「清洗」，日誌出現 5 行 token 用量。
  3. scripts/Test-DocsEncoding.ps1 全綠。
