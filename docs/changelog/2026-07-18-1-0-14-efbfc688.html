三份商業簡報全面更新至系統 1.0.14

  • 日期：2026-07-18
  • 版本：1.0.14（不升版；本次為簡報/文件更新，非程式異動）

需求

三份對外簡報都停在 0.2.x 年代（決策投資版最舊：標日 2026/06/08、「約 340 個 C# 檔」、路線圖「截至 0.2.160」、rerank「未導入」），落後現行 SystemVersion 1.0.14 約 15+ 個 minor。本次全面更新至現況，並補齊 0.3.x–1.0.14 新能力；以 docs/strategy/系統功能與特色清單-20項.md（20 核心＋9 企業專屬）與 changelog 里程碑為對齊基準。

變更

  • 標日 2026/06/08→2026/07/18，加對應版本 1.0.14；「340 個 C# 檔」→「600+ 個 C# 檔、約 40 個功能頁」。

旗艦簡報（docs/presentation/KnowledgeExtraction-AI-旗艦簡報.md）

  • 標題加產品名與版本；閉環與能力段補 YouTube/抖音、信心自評、互連 Wiki/版本化/知識瀏覽、MCP。
  • 「我們在哪裡」狀態表補 MCP 對外整合、版本化時效、經營報表/24 項健康監控為✅現已可用；Agent 自動化工作流與授權/計費機制標🔄規劃中。
  • 資安頁補可觀測性（報表/健康檢查/PDF）；競品註記日期更新。

講者指南（docs/presentation/KnowledgeExtraction-AI-簡報講者指南.md，配套同步）

  • 加對應版本 1.0.14；§0 現貨清單補 MCP/版本化/知識瀏覽/報表/健康監控，規劃中改為「Agent 多步驟編排＋授權/計費機制」；Q2 改述 MCP 已上線、完整自動化編排為下一步。

  • 兩份商業 html：Marp 未安裝，改用 Build-FlagshipDeck.py 產自包含 HTML（輸出暫存 base 後只覆蓋 .html，navy pptx 不動）。故商業簡報 pptx 為 navy、html 為旗艦式自包含（媒體不同，本次認可之取捨）。
