抽取／LLM 生成文字內容 UI 線上編修（0.2.74）

  • 日期：2026-06-16
  • 版本：0.2.73 → 0.2.74
  • 類型：功能新增 / UI

調整內容

  • 四種純檔案儲存的文字內容可在原檢視頁線上編修並存回原檔：文件萃取 Markdown、影音逐字稿、影音 LLM 生成內容、圖片辨識文字。
  • 新增共用元件 Components/Commons/ContentEditDialog.razor：寬版對話窗、左編輯／右 Markdown 即時預覽；父層提供 Content 初值與 OnSave 回呼。
  • 新增 Components/Commons/MarkdownRenderer.cs（採 Markdig 套件，DisableHtml() 防 MarkupString XSS）。
  • 各 Service 新增 Update*ContentAsync（UpdateMarkdownContentAsync / UpdateTranscriptContentAsync / UpdateGeneratedContentAsync / UpdateRecognitionTextContentAsync）。
  • 鐵則：一律原地覆寫同一相對路徑（不產生新 GUID 檔、不動 DB 路徑欄位，僅更新 UpdatedAt）→ 不需 migration；比照各 Get*ContentAsync 套團隊權控（IsTeamAccessible）才可寫；編碼比照各 writer（逐字稿無 BOM，其餘 Encoding.UTF8）。
  • 影音頁新增「編修逐字稿／編修產生結果」、圖片頁新增「編修解讀文字」、文件頁的 Markdown 預覽改為「檢視/編修」。

備註

  • 編修來源後，下游清洗（CleaningProcessor）需重跑清洗才會反映新內容（清洗按需即時讀檔，屬既有流程）。
