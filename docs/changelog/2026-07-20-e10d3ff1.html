側邊選單拆分為「專案協作」與「資料匯入」（1.0.17）

  • 日期：2026/07/20
  • 版本：1.0.16 → 1.0.17
  • 類型：功能調整（選單重整）＋既有不一致修正＋新增守護測試
  • 對應 PRD：專案協作模組強化 PRD 第一階段
  • 代辦清單：專案協作模組強化開發代辦清單

一、變更內容

1.1 選單結構

原「專案管理」單一子選單同時容納六個職能不同的功能，語意混雜。本次拆為兩個頂層群組：

拆分前拆分後
專案管理 → 專案項目專案協作 → 專案項目
專案管理 → 工作項目專案協作 → 工作項目
專案管理 → 會議記錄專案協作 → 會議記錄
專案管理 → 音訊轉錄資料匯入 → 音訊轉錄
專案管理 → 文件萃取資料匯入 → 文件萃取
專案管理 → 圖片清單資料匯入 → 圖片清單

拆分後與既有「清洗與蒸餾」形成「匯入 → 清洗 → 蒸餾」的流水線語意。

頂層順序（共 8 組）：首頁、專案協作、資料匯入、清洗與蒸餾、系統管理、資料定義、統計報表、登出。

Menu.json 頂層 id 順手重編為 1..8（原為 1,2,3,4,5,7,6，統計報表 id 7 排在登出 id 6 之前）。SidebarMenuItemModel.Id 全專案無任何程式讀取，純文件用途，重編零風險。

1.2 權限常數

  • 新增 MagicObjectHelper.角色_專案協作（值 "專案協作功能"）
  • 新增 MagicObjectHelper.角色_資料匯入（值 "資料匯入功能"）
  • 移除 MagicObjectHelper.角色_專案管理（值 "專案管理功能"）
  • 六個葉節點權限字串逐字不變："專案項目"、"工作項目"、"會議項目"、"音訊轉錄"、"文件萃取"、"圖片清單"

1.3 修正既有不一致：/projects 頁面守衛

/projects 原本是全站唯一用群組權限（角色_專案管理）做頁面守衛的頁面，而選單上「專案項目」綁的卻是 角色_專案項目——兩者不一致，導致只勾「專案項目」的角色看得到選單項、點進去卻被擋。

本次改為 角色_專案項目（ProjectViewView.razor.cs），與其他五頁一致（各自使用自己的葉節點常數）。

1.4 新增位置索引守護測試

新增 KnowledgeExtraction.Tests/MenuPermissionAlignmentTests.cs（3 個測試）。此前沒有任何測試守護 Menu.json ↔ RolePermissionService 的位置索引不變量，而該不變量一旦漂移是靜默失效：ApplyPermissionStructure 以陣列位置串接兩者（名稱從不參與比對），索引錯位時權限名會退化成選單項名稱，選單對非管理員直接消失。

三項檢查：

  1. Menu.json 頂層數 == GetRoleListPermissionAllName().Count
  2. 每組子權限數足以容納其 subMenu（容許動作型權限尾隨）
  3. 無任何選單子項退化為以自身名稱當權限

adminOnly 項豁免：FilterMenuItems 以 hasPermission = item.AdminOnly 直接放行，完全略過角色權限，故「系統管理」（10 子項／2 子權限）與「統計報表」（5 子項／0 子權限）的權限槽位可以是空的。這是既有的刻意設計（見速查文件 §1.6 adminOnly 豁免），測試需一併豁免。

二、相容性（重要）

既有角色的頁面權限完全不受影響。

AuthenticationStateHelper.CheckAccessPage(name) 只是對角色 RoleView.TabViewJson 反序列化出的字串做平面 Contains。六個葉節點權限字串逐字不變，因此：

  1. 不會失去任何頁面權限 — 舊角色 TabViewJson 內的六個葉節點字串照樣命中。
  2. 選單也不會消失 — FilterMenuItems 的規則是「父節點自身無權限但有 ≥1 個可見子項時仍保留」，故舊角色即使沒有新的 資料匯入功能 群組字串，「資料匯入」父節點照樣顯示。
  3. 無需資料遷移、無需改 SQL — 殘留的 "專案管理功能" 字串會被 SetPermissionInput 靜默忽略。
  4. 預設角色 自動修復 — 每次啟動由 Program.cs 重寫為全部權限。

唯一殘留：自訂角色在 /roleviews 會看到「專案協作功能」與「資料匯入功能」兩個未勾選的新群組標題。

發行說明

既有角色的頁面權限不受影響；如需勾選新的「專案協作／資料匯入」群組層級權限，請至角色管理重新勾選。

另：/projects 的進入權限已由「專案管理功能」改為「專案項目」。若貴單位有角色只勾了「專案管理功能」而未勾「專案項目」，請至角色管理補勾「專案項目」。（該類角色原本就看不到「專案項目」選單，僅能靠直接輸入網址進入。）
