MCP API Key 改存資料庫＋網頁管理（啟用/停用）（1.0.8 → 1.0.9）

  • 日期：2026-07-17
  • 版本：1.0.8 → 1.0.9
  • 類型：新功能（MCP 存取金鑰治理：由設定檔遷移至資料庫，並提供網頁維護）

需求

MCP 專用 API Key 初版（1.0.5–1.0.6）存於 appsettings.json 的 Mcp:ApiKeys，撤銷需改設定並依賴 reloadOnChange，無法逐把即時啟用/停用、也無網頁維護。本次將金鑰改存資料庫並提供管理員網頁 CRUD 與啟用/停用切換。設計見 MCP Server 整合設計與使用指南 §7、MCP 服務使用說明書 §6.7、產品需求見 MCP Server 整合 PRD。

變更

  • 資料模型：新增 McpAccessKey entity（Name/KeyValue/UserId/IsEnabled/CreatedAt/UpdatedAt）＋ DbSet ＋ McpAccessKeyAdapterModel ＋ AutoMapper 雙向對映；產生雙資料庫 migration（Sqlite 20260717053352_AddMcpAccessKey 與 SqlServer 20260717053434_AddMcpAccessKey 各一）。
  • 服務層：新增 McpAccessKeyService——CRUD、ToggleEnabledAsync（列表直接切換）、FindEnabledMatchAsync（認證用，載入啟用中金鑰以 CryptographicOperations.FixedTimeEquals 常數時間比對）、GenerateKey、GetUserOptionsAsync（使用者下拉）。
  • 認證：McpApiKeyAuthenticationHandler 改注入 McpAccessKeyService 查資料庫（只認啟用中金鑰）；命中發相同 ClaimTypes.Sid/Name 身分，下游 McpIdentityResolver 與團隊權控不變。移除 Mcp:ApiKeys 設定綁定與 McpSettings 類別。
  • 網頁管理：新增 Blazor 管理頁 /mcp-api-keys（系統管理 → MCP金鑰管理，adminOnly ＋ CheckIsAdmin）：新增自動產生金鑰、可重新產生／複製、對映使用者下拉、啟用/停用切換、修改／刪除。Menu.json 加入該頁（key 圖示）。
  • 文件：MCP服務使用說明書 §6.7、MCP 整合設計指南、Hands-on Lab 更新為「金鑰存 DB、網頁維護、可啟用停用」。
  • appsettings.json 移除 Mcp 區段、版本標記 1.0.8 → 1.0.9。

主要異動檔案

  • AccessDatas/Models/McpAccessKey.cs（新增）、BackendDBContext.cs、Models/AutoMapping.cs、雙 provider Migrations
  • Business/Services/DataAccess/McpAccessKeyService.cs（新增）、Dtos/AdapterModel/McpAccessKeyAdapterModel.cs（新增）
  • Web/Auth/McpApiKeyAuthenticationHandler.cs、Web/Components/Pages/McpAccessKeys/*、Views/McpAccessKeys/*、Datas/Menu.json
  • 移除 Models/Systems/McpSettings.cs

已知限制

  • 金鑰以明文存 DB（僅管理員可於網頁檢視）；team 範圍綁在對映帳號上。
  • 金鑰稽核（簽發／撤銷歷程表）列為日後增強。

驗證

  • 端到端：DB 啟用金鑰連線 200；停用後立即 401（免重啟）；重新啟用又通。
  • dotnet test 558 通過（新增「停用金鑰拒絕」案例改用 DB fixture；MenuIconTests 允許 key 圖示）。
  • 選單三處同步（Menu.json、RolePermissionService、MagicObjectHelper）已對應 /mcp-api-keys。
  • scripts/Test-DocsEncoding.ps1 全綠。
