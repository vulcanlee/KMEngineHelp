變更紀錄

登入後預設導向改為知識庫問答（1.0.14 → 1.0.15）

  • 日期：2026-07-18
  • 版本：1.0.14 → 1.0.15
  • 類型：導向行為調整＋文件同步

背景

先前 commit 0c20eb9 已把 SplashView 的驗證成功導向從 /app 改為 /knowledge-base-chat，但該路徑只涵蓋「已登入使用者開啟根路徑 /」的情境。實際的帳密登入與 Google 登入仍導向 /App（統計儀表板），造成三條路徑行為不一致。本次補齊其餘兩條，並同步更新描述「登入後落地頁」的文件。

變更

  1. 帳密登入（Components/Auths/Login.razor.cs）：ReturnUrl 為空時的預設導向 /App → /knowledge-base-chat。
  2. Google 登入（Controllers/ExternalAuthController.cs）：GetSafeReturnUrl 的 fallback /App → /knowledge-base-chat。
  3. appsettings.json：SystemVersion 1.0.14 → 1.0.15。
  4. 文件同步：docs/prd/首頁與導覽-prd.md（範圍、畫面、驗收、相關程式、現況校正）、docs/prd/README.md、README.md、docs/guides/完整操作手冊.md、docs/guides/新手完整操作指南.md（含登入流程圖）、docs/guides/實作練習手冊-Hands-on Lab.md、docs/guides/AI知識問答使用指南.md、docs/security/Google OAuth2 第三方登入.md（含流程圖）。

刻意不變更

  • Menu.json：選單第一項「首頁」仍指向 /App。選單順序與 MagicObjectHelper／RolePermissionService 以位置索引對應，調整風險高且非本次需求；儀表板仍可由選單進入。
  • ChangePassword.razor／Profile.razor：儲存或取消後回 /App，屬「回首頁」語意，非登入落地頁。
  • KnowledgeBaseChatView.razor.cs 的 GoBack()：從問答頁返回 /App；若改成問答頁會變成導回自己。
  • AuthenticationStateHelper.cs：強制變更密碼者仍優先導向 /ChangePassword，此優先權高於落地頁。
  • ReturnUrl 行為：使用者帶 ReturnUrl 登入時仍回原本要去的頁面，不被落地頁覆蓋。
  • 既有 changelog 為歷史紀錄，不回頭改寫。

驗證

  • dotnet build。
  • dotnet test；AuthenticationStateHelperTests 以 http://localhost/App 作為現行 URI，測的是 Check 行為而非導向目標，不受影響。
  • 手動：帳密登入、已登入開啟 / 皆落在 /knowledge-base-chat；帶 ReturnUrl 登入仍回原頁；選單「首頁」仍可進入 /App；強制改密碼帳號仍先導向 /ChangePassword。
  • scripts/Test-DocsEncoding.ps1 確認文件為 UTF-8 含 BOM。
