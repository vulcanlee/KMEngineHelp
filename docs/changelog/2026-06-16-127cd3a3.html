變更紀錄

文件萃取「依提示詞產生」可選萃取文字或原始檔案（0.2.77）

  • 日期：2026-06-16
  • 版本：0.2.76 → 0.2.77
  • 類型：功能新增 / LLM / 資料模型

調整內容

  • 文件萃取頁新增「依提示詞產生」按鈕，對話窗可選產生來源：
  • 萃取文字（Markdown）：以 MarkItDown 抽取文字 ＋ 提示詞 → LLM（CompleteAsync）。
  • 送原始檔案到 LLM：圖片走視覺（CompleteWithImageAsync）、PDF 走 base64 file（新增 CompleteWithFileAsync）。非圖片/PDF 型別（Word/Excel/PPT/HTML 等）此選項停用，以 DocumentExtractionService.IsLlmFileSupported 判斷。
  • 結果與影音一致：落 GeneratedContentPath 保存、可用 ContentEditDialog 檢視/編修、重新產生即覆寫舊檔。
  • 資料模型：DocumentExtraction 新增 GeneratedContentRelativePath、GeneratedAt，並產生雙 migration AddDocumentGeneratedContent（SQLite + SQL Server，皆可空）。
  • 新增 DocumentLlmGenerationService（背景產生，Task.Run + 獨立 DI scope）；DI 於 ServiceCollectionExtensions 註冊。
  • DocumentExtractionService 新增 GetGeneratedContentAsync、UpdateGeneratedContentAsync、GetSourceForLlmAsync（團隊權控＋僅圖片/PDF＋20MB 上限）、IsLlmFileSupported；刪除紀錄時一併刪生成檔。
  • 新增 Markdig NuGet 相依（內容預覽，DisableHtml 防 XSS）。

安全與限制

  • 團隊權控與輸入讀取一律在 UI 執行緒完成（背景 scope 無使用者驗證情境），再把已授權資料傳入背景產生。
  • PDF 能否成功取決於所設定 GenerationModel 是否支援 file 輸入；不支援時 OpenAI 回非 2xx，目前以錯誤通知呈現，可改用「萃取文字」模式。

驗證

  • 圖片與 PDF 各以「原始檔案」產生成功；Word/Excel 的「原始檔案」選項為停用。
  • 「萃取文字」產生成功並可檢視/編修；無交集團隊帳號無法產生/檢視/編修。
