實作練習手冊（Hands-on Lab）對齊系統 0.3.32（文件 1.0 → 2.0）

  • 日期：2026-07-12
  • 版本：文件 1.0 → 2.0（對應系統 0.2.133 → 0.3.32）
  • 類型：文件更新

需求

docs/guides/實作練習手冊-Hands-on Lab.md 停在系統 0.2.133、文件版本 1.0，已明顯過舊：產品已更名「智庫引擎」、選單重組、新增多個頁面、既有頁新增功能。需求：把這份「按表操課」的練習手冊更新到對齊現行系統 0.3.32，並補上與知識庫煉製主線相關的新功能練習。

範圍決策（與需求者確認）

  1. 平衡深度：對齊現況（版本/改名/選單導覽/失效 UI 字串）＋為知識庫煉製相關新功能新增重點練習。
  2. 專案管理群組（專案/工作/會議）不寫（超出知識庫主線）；但標註匯入三頁現掛在「專案管理」群組下。
  3. 管理員頁：Token 用量、AI 聊天紀錄（含滿意度）、系統健康監控寫重點實作；RAG 診斷、資料一致性巡檢、日誌等級寫導覽＋指向。
  4. UI 字串逐一比對現行 Blazor 元件後才寫入。

變更

  • 前置資訊：文件版本 1.0→2.0、加更新日期、對應系統 0.3.32、標示系統名「智庫引擎」；功能一覽表改依現行選單群組排列並補齊新頁；參考型手冊並列《新手完整操作指南》。
  • 登入章（第 4 章）：改為科技神秘風「身分核驗」畫面，路由更正為 /Auths/Login，錯誤字串更正為「身分驗證失敗，請重新確認帳號與密碼。」，補 Google 登入／待審核頁說明；驗證碼（隨機 4 位數）與內建帳密（support/1qaz@WSX）維持不變。
  • 基礎資料章（第 5 章）：加選單群組導覽——團隊/分類/提示詞/清洗設定檔在「資料定義」，使用者/角色在「系統管理」。
  • 匯入章（第 6 章）：音訊來源類型改「檔案上傳/影片連結」、語言改「繁體中文/English/自動偵測」、狀態機補「已取消」；文件萃取與圖片清單補「批次上傳壓縮檔」；標註支援副檔名；編修對話窗補「搜尋取代」。
  • 清洗/蒸餾/索引（第 7–10 章）：清洗狀態補「已退回」；索引章補「全量重建索引」按鈕。
  • 新增 9.6 知識瀏覽 /knowledge-wiki：一般讀者閱讀蒸餾 Wiki 的雙欄畫面與 [[概念]] 導覽。
  • 問答章（第 11 章）：控制項補限定知識來源/分類、送出/停止、下載 PDF、滿意度回饋（👍/👎）、QueryRewrite 說明；加一則回饋動手步驟。
  • 新增第 17 章「管理員維運與觀測頁」：系統健康監控、AI 聊天紀錄（含滿意度查閱）、Token 用量（緊湊數字說明）三節重點實作；RAG 診斷／資料一致性巡檢／日誌等級導覽表。原 FAQ 章順延為第 18 章。
  • 更新章（第 15 章）：改用「上傳新版本／版本歷史」素材版本鏈為推薦做法。
  • FAQ／延伸閱讀：新增管理員頁與 Token 表示法問答；延伸閱讀補《新手完整操作指南》。
