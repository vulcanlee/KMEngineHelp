素材版本鏈：上傳新版本＋自動接手（0.3.20→0.3.21）

  • 日期：2026-07-11
  • 版本：0.3.20 → 0.3.21
  • 類型：新增功能（docs/architecture/資料生命週期與維護.md §6 backlog P3）

需求

素材（音訊/文件/圖片）原本無版本鏈：要更新一份檔案的新版本只能重傳成一筆全新紀錄，難以追溯「同一份檔的歷次版本」，且與既有知識來源的銜接需人工處理。決策採「記錄版本＋自動接手」、三種素材全做。

變更

資料模型（需雙資料庫 migration）

  • 三素材實體與 AdapterModel 各新增：VersionNumber（int，預設 1）、IsLatest（bool，預設 true）、PreviousVersionId（int?）、SupersededById（int?）——純可空自我參照，無硬 FK（比照 WikiPage VER-1 但簡化，不引入 as-of）。
  • Migration AddSourceVersionChain（Sqlite + SqlServer 各一，12 欄）；IsLatest/VersionNumber 欄位預設 true/1，既有列回填為「最新版 v1」。AutoMapper 同名欄位自動對應，無需改設定。

商業層

  • KnowledgeSourceMaintenanceHelper.RepointOwningSourcesToNewVersionAsync(context, itemType, oldItemId, newItemId)：把引用舊版素材的 KnowledgeSourceItem 重指到新版、所屬來源設 ContentStale；不自行 SaveChanges（呼叫端同一交易）。
  • 三素材 Service 新增 AddNewVersionAsync(previousId, uploadFile)：團隊權控 + 僅允許對最新版上傳；寫新檔、建版本鏈（沿用原標題/描述/分類/團隊、VersionNumber+1、PreviousVersionId、IsLatest=true）；SaveChanges 後標舊版 IsLatest=false＋SupersededById，再 repoint 成員；音訊/文件入列處理，圖片維持「未解讀」。

UI 層

  • 三 View 每列（僅最新版）新增「上傳新版本」按鈕（drive_folder_upload）；新增「版本」欄顯示 v{n}，非最新版標「（已被取代）」。
  • 共用新增 Modal 加入「新版本」子模式（isNewVersionMode）：只顯示檔案上傳與說明、隱藏中繼資料欄位；OnModalOkAsync 新增分支呼叫 AddNewVersionAsync。

測試

  • 新增 SourceVersionTests（3 筆）：AddNewVersionAsync 建鏈/取代/重指成員/標記過時/入列；非最新版上傳被拒；RepointOwningSourcesToNewVersionAsync 重指並標記過時。
  • 全測試 493 通過、0 失敗（含 CrudActionIconTests/MenuIconTests）。

範圍決策（誠實記錄）

  • 版本模型採最小四欄（不做 as-of/RootId/字串狀態常數）；素材不進 RAG 檢索，故無需時效查詢。
  • 上傳新版本/編修僅標記過時、不自動重跑下游（避免非預期運算成本）；重跑由使用者或「資料一致性巡檢」批次觸發。
  • 只允許對「最新版」上傳新版本，維持版本鏈線性。

影響範圍

  • docs/architecture/資料生命週期與維護.md §4.1、§5-D、§6（P3 標完成）。
  • docs/guides/新手完整操作指南.md §16.3、§16.6。
  • docs/guides/EFCore.md migration 目錄新增 AddSourceVersionChain。
  • appsettings.json SystemVersion 0.3.20 → 0.3.21。

驗證

  1. dotnet build 成功；兩道 dotnet ef migrations add AddSourceVersionChain 各產出一組檔（既有列回填 v1/最新）。
  2. dotnet test 綠燈（493 通過，含新增 SourceVersionTests）。
  3. 手動：對一筆文件按「上傳新版本」→ 新版為 v2/最新、舊版標「已被取代」；若被知識來源引用，該來源成員改指新版且顯示「內容已過時」。音訊自動轉錄；圖片新版「未解讀」需手動解讀。
  4. scripts/Test-DocsEncoding.ps1 全綠。
