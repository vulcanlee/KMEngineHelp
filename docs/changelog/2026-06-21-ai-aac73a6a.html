2026-06-21 知識來源「AI 對話」回答詳簡切換

版本：0.2.107 → 0.2.108

承 知識來源 AI 對話 與 修正。

需求

AI 回答每次又多又長。根因：預設系統提示詞未要求精簡、模型 gpt-5.4（GPT-5 家族 reasoning）天生詳盡、請求亦未設輸出長度上限。需求是讓使用者能自行控制回答長度。

變更

KnowledgeSourceChatService

  • 新增公開常數 VerbosityConcise/VerbosityStandard/VerbosityDetailed。
  • 新增 static ResolveVerbosityInstruction(verbosity) 映射長度指示：
  • 簡潔：精簡扼要、重點/條列為主、盡量簡短。
  • 標準（預設）：重點清楚、篇幅適中、避免不必要的冗長。
  • 詳細：完整詳盡、必要時補充背景/結構/範例。
  • BuildMessages 新增 verbosity 參數，把長度指示併入第一則 system 訊息：{系統提示詞}\n\n{長度指示}\n\n---\n以下為參考資料：\n{內容}；長度日誌加記 回答詳簡=。

對話頁 KnowledgeSourceChatView

  • 設定列新增「回答詳簡」下拉（簡潔/標準/詳細，預設標準），@bind-Value="verbosity"，變更即時套用於下一則訊息、不清空對話、不需 reload。

影響範圍

  • 變更：KnowledgeSourceChatService.cs、KnowledgeSourceChatView.razor(.cs)、KnowledgeSourceChatServiceTests.cs（新增）、docs/architecture/開發慣例與限制速查.md、appsettings.json（版本號）。
  • 無資料庫變更，不需 migration。

驗證

  1. dotnet test 全綠（273 通過，含 5 筆新 KnowledgeSourceChatServiceTests）。
  2. 對話頁切「簡潔」回答明顯變短、「詳細」完整詳盡、「標準」適中；切換不影響先前對話。
  3. 日誌「知識來源對話組訊息」可見 回答詳簡=…。
  4. scripts/Test-DocsEncoding.ps1 全綠。
