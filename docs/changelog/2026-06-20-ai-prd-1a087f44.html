新增「AI Agent 技能產生器」PRD（規劃中，0.2.94）

  • 日期：2026-06-20

需求

使用者想做一個操作類似「知識來源管理清單」的工具：指定文件素材＋指定/內建提示詞 → 由 LLM 讀取內容產生可反覆使用的技能（SKILL.md）供 Claude Code / Codex 使用，並可下載成檔案。先交付 PRD 設計文件供日後實作。

變更

新增 docs/prd/AI技能產生器-prd.md（狀態：規劃中）

依使用者三項決策設計：

  • 成員來源三類都支援（文件萃取／音訊轉錄／圖片辨識，沿用 KnowledgeSourceItem 軟參照模式）。
  • 下載兩者皆提供：單一 SKILL.md ＋ zip（內含 <slug>/SKILL.md，可直接解壓到 .claude/skills/）。
  • 提示詞優先序：自訂文字 → 選 /prompts → 內建「技能產生」meta-prompt。

PRD 內容涵蓋：背景與目的、需求決策、範圍/非目標、使用者流程、資料模型（SkillDefinition＋SkillSourceItem，雙 migration）、設定（新增 SkillOutputPath＋內建 meta-prompt）、SKILL.md 格式與產生邏輯（frontmatter name/description＋本文、slug 規則、frontmatter 解析回填）、背景產生管線（佇列→背景服務→處理器，比照清洗管線）、下載端點、UI、選單權限三處同步、檔案清單、相依風險、容量限制、驗收條件。

明確界定：整體比照知識來源管理模組；技能產生必須有 LLM（未設金鑰直接失敗，與清洗可降級不同）；本期不做技能市集/自動安裝/執行引擎/多檔技能包。
