修復「黃金評測」頁無已評測樣本時進入即崩潰（0.2.82）

  • 日期：2026-06-17
  • 版本：0.2.81 → 0.2.82
  • 類型：缺陷修正

問題

進入「黃金評測」頁（GoldenSampleView）即拋例外：

System.InvalidOperationException: Sequence contains no elements
  at System.Linq.Enumerable.Max[...]
  at CleaningEvaluator.RecommendThreshold(...) CleaningEvaluator.cs:115
  at CleaningEvaluator.BuildAggregate(...) CleaningEvaluator.cs:136
  at GoldenSampleService.GetAggregateAsync() ...
  at GoldenSampleView.LoadAggregateAsync() / OnInitializedAsync()

根因

頁面載入時 GoldenSampleService.GetAggregateAsync 只取已評測樣本（LastMetricsJson != null）。當尚無任何已評測樣本（全新頁、樣本未評測——最常見情況）時：

  • BuildAggregate 對空集合呼叫 SweepThresholds，回傳數列門檻列，但每列 EvaluatedCount == 0。
  • RecommendThreshold：rows.Count == 0 的防呆通過不了（門檻列非空），candidates 為空，落到 fallback 對 rows.Where(r => r.EvaluatedCount > 0)（空序列）呼叫 .Max(...) → 拋「Sequence contains no elements」。

修正

CleaningEvaluator.RecommendThreshold：fallback 先把 EvaluatedCount > 0 的列實體化，空則回傳 null，再取 Max/Min：

var evaluatedRows = rows.Where(r => r.EvaluatedCount > 0).ToList();
if (evaluatedRows.Count == 0)
    return null;

decimal maxPrecision = evaluatedRows.Max(r => r.PrecisionVsHuman);
return evaluatedRows
    .Where(r => r.PrecisionVsHuman == maxPrecision)
    .Min(r => r.Threshold);

亦涵蓋「有樣本但全部無信心值」的情況。無已評測樣本時推薦門檻為 null（尚無推薦門檻），頁面正常呈現空彙整而非崩潰。
