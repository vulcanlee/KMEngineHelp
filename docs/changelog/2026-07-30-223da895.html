設計決策

決策理由
用腳本產生，不手寫 HTML5 份 md 加 5 份 html 手動同步必然會漂移。md 是唯一來源，改了 md 就重跑腳本
沿用 docs/strategy/系統功能與特色清單-20項.html 的 8 色粉彩調色盤與深色模式與既有對外 HTML 風格一致
大字（基準 19px）、左右滿版（max-width:2000px ＋ clamp 內距）、每個 H2 依序輪替一個粉彩主色長文件好定位；符合既有網頁版的視覺習慣
寬表格自帶 overflow-x:auto 包裹手機與投影時不會破版
內含 @media print 規則速查卡要能列印；表格與程式碼區塊避免跨頁斷開
本組 5 份之間的 .md 連結改寫為 .html；指向其他 .md 的連結轉為不可點擊的樣式化文字（<span class="docref">，滑過顯示檔名）客戶端拿不到其他 md 檔，留成連結只會變成死連結
HTML 不加 BOMscripts/Test-DocsEncoding.ps1 只檢查 *.md；HTML 以 <meta charset="utf-8"> 宣告，加 BOM 反而可能影響部分解析器

重新產生方式

python scripts/Build-OnboardingDocsHtml.py           # 產生 5 份
python scripts/Build-OnboardingDocsHtml.py --check   # 只轉換驗證、不寫檔
