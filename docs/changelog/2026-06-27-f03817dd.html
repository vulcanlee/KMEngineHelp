系統功能與文件同步審計（0.2.139）

版本

  • appsettings.json：SystemSettings.SystemInformation.SystemVersion 由 0.2.138 (2026/06/27) 遞增為 0.2.139 (2026/06/27)。

異動內容

  • 新增 系統功能與文件同步審計，盤點正式選單功能、API Controller、Entity、七條背景管線、文件覆蓋、不一致項與後續功能建議。
  • 更新 架構總覽：背景管線由早期四條修正為現況七條，音訊管線名稱改為實際的 ITranscriptionQueue / TranscriptionBackgroundService，並補上蒸餾、嵌入索引、技能產生、RAG/Embedding 相關服務。
  • 更新 日誌與設定檔說明：同步目前 appsettings.json 欄位，補 SkillOutputPath、WikiOutputPath、Distillation、Retrieval、Embedding 設定、KnowledgeBaseSystem、DistillationGenerate 與 MarkItDown 設定段落。
  • 更新 外部工具安裝與路徑設定：統一抖音助手描述為「系統自動呼叫，但需互動式桌面」。
  • 更新 維護規範：修正文件編碼規則，明確要求 docs/*.md 為 UTF-8 BOM 並通過 scripts/Test-DocsEncoding.ps1。
  • 同步根 README.md、docs/README、planning/README 與本 changelog 索引。

影響範圍

  • 本次只更新文件與版本號，不變更 API、DTO、Entity、migration、路由或 UI 行為。
  • 明確標註 WeatherForecastController、/weather、/counter 為樣板/非正式選單功能，避免文件審計時誤列為產品功能。
