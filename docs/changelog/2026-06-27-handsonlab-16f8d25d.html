變更內容

新增 docs/guides/實作練習手冊-Hands-on Lab.md：一份按表操課、邊做邊學的實作練習手冊，補足既有《完整操作手冊》偏參考型的不足。

特色

  • 以虛構公司「鼎峰系統整合股份有限公司—第一系統開發部」情境貫穿全文，涵蓋「系統維運／部署知識」與「軟體開發知識」兩大知識域。
  • 列出實際要輸入的團隊（運維組／開發組／業務合約組）、分類（10）、角色（4）、使用者（王小明／李四／陳美玲／張經理）、知識紀錄（A1–A5／B1–B3／P1），讀者照做即可從零建起一套知識庫。
  • 以 B3（業務合約組）與 P1（公開）設計團隊權控可見性差異教學，並安排第 14 章逐一換帳號驗證。
  • 每個畫面採固定結構：用途說明 → 欄位表（意義／舉例／必填）→ 本情境輸入值 → 逐步操作 → 預期結果 → 常見錯誤。
  • 練習素材採內嵌可複製內容＋無金鑰替代路徑：沒有 OpenAI 金鑰也能用文件萃取走完全流程。
  • 涵蓋登入驗證碼、基礎資料、三條匯入管線、知識來源清洗（比較不同清洗設定檔）、黃金評測、蒸餾、索引、知識庫問答（預設提示詞與預期結果格式）、RAG 評測（越權＝0）、AI 技能產生器、知識更新練習，並附大量 FAQ與可複製素材彙整附錄。
