發行說明：音訊轉錄維運強化與抖音整合（0.2.22 – 0.2.30）

期間：2026/06/04。本輪聚焦「音訊轉錄」影片連結來源的各平台下載方式釐清、抖音端到端自動化，以及相關維運文件與編碼維護。版本來源為 appsettings.json 的 SystemVersion。

重點摘要

  • 小紅書：以「影片連結」來源直接可用、免 cookies（yt-dlp 自動跟隨 xhslink 短連結）。
  • 抖音：yt-dlp 因 web API 簽章（a_bogus／msToken）無法下載，且與 cookie 無關（實測帶完整登入 cookie 仍失敗）。改以 playwright 助手用已登入瀏覽器攔截音訊串流下載，並已整合進系統自動觸發。
  • 新增全新機器部署 SOP 與外部工具佈署說明；修正多份文件的過時敘述；統一文件 UTF-8（BOM）與主控台日誌編碼。

功能與變更（依版本）

0.2.22 — 釐清各平台下載方式、新增抖音音訊助手

  • 實測確認：小紅書 yt-dlp 可用（免 cookies）；抖音 yt-dlp 不可用（簽章問題，非 cookie）。
  • 新增 tools/douyin-audio/get-douyin-audio.mjs：以 @playwright/cli 內建瀏覽器載入抖音影片頁、攔截音訊 CDN 串流、ffmpeg 轉 mp3。
  • 還原 OpenAISettings:YtDlpCookiesFromBrowser（Edge 的 App-Bound Encryption 會使 --cookies-from-browser 失敗，連帶弄壞小紅書／YouTube）。
  • 更正維運／PRD 文件中「cookies 可解抖音/小紅書」的舊敘述。

0.2.23 — 部署文件

  • 新增 全新機器部署 SOP：端到端安裝步驟 + appsettings.json 參數環境同步確認總表（含機密與環境變數對照）。
  • 外部工具安裝與路徑設定：工具總表加入抖音助手工具鏈（Node.js／@playwright/cli／Chromium），新增安裝（§3.3）與佈署注意事項（§9，本機 vs 無頭伺服器）。

0.2.24 — 文件編碼

  • 既有文件補上 UTF-8 BOM，使 scripts/Test-DocsEncoding.ps1 全數通過。

0.2.25 — 抖音助手支援合併式 mp4

  • 部分抖音影片為合併式 mp4（音訊+視訊同檔，無獨立 DASH 音訊軌）。助手改用 content-type + URL 標記分類攔截（音訊軌優先、其次合併檔以 ffmpeg 抽音訊），並在失敗時列出實際媒體網址供診斷。

0.2.26 / 0.2.27 — 抖音端到端自動化（核心）

  • 設計與計畫文件：spec、plan。
  • 分享文字自動帶入：新增 ShareTextParser（ExtractUrl／ExtractTitle）；建立轉錄記錄時於「影片網址」欄貼上分享文字，自動帶入標題與乾淨網址（可手動修改）。
  • 抖音自動下載：新增 DouyinAudioDownloader（IsDouyin 偵測 + 呼叫助手）；TranscriptionProcessor.DownloadFromUrlAsync 依網址分流（抖音走助手、YouTube／小紅書走 yt-dlp）。助手腳本新增 --out 與 TITLE=／MP3_PATH= 機器輸出供 C# 整合。
  • 新增設定 OpenAISettings：NodePath、DouyinHelperScript、DouyinTimeoutSeconds。
  • 之後在「影片連結」貼抖音連結即自動下載並轉錄，無須手動上傳。

0.2.28 — 設定抖音助手路徑

  • appsettings.json 將 DouyinHelperScript 直接填為本機腳本絕對路徑（與 FfmpegPath／YtDlpPath 同慣例），免每次設 User Secrets。

0.2.29 — 主控台日誌 UTF-8

  • nlog.config 的 console target 加上 encoding="utf-8"，修正主控台輸出中日韓字顯示為 ?（file target 原本即為 UTF-8）。

0.2.30 — 發行說明與文件維護

  • 新增本發行說明；更新文件索引（readme.md §9、docs/README.md）納入部署 SOP 與本文件；更正多份文件中抖音「手動上傳」的過時流程為「系統自動觸發」；補齊 readme.md §7 的 cookies／抖音相關設定欄位。

使用方式（抖音）

前提：本機已安裝 Node.js 與 @playwright/cli（含 Chromium），瀏覽器設定檔已登入抖音；OpenAISettings:DouyinHelperScript 指向 get-douyin-audio.mjs。

  1. 「音訊轉錄」→ 新增 → 來源「影片連結」→ 貼上抖音連結或整段分享文字 → 標題與網址自動帶入。
  2. 送出後背景轉錄會自動呼叫助手：瀏覽器視窗跳出（必要時手動過驗證）→ 下載音訊 → 轉錄為台灣繁體逐字稿。

詳見 外部工具安裝與路徑設定 §8 與 tools/douyin-audio/README.md。

已知限制

  • 抖音自動下載僅限有桌面的本機（助手需可見瀏覽器與偶爾人工過驗證），無頭伺服器不適用。
  • 抖音登入會過期、平台會改版；登入過期時於跳出的瀏覽器視窗重新登入即可。
  • 同一時間僅能處理一個抖音工作（持久瀏覽器設定檔有鎖；背景佇列本就循序）。
