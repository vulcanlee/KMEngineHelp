RAG 切塊參數設定化與設計文件補強（0.2.141）

  • 日期：2026/06/28
  • 版本：0.2.140 → 0.2.141

摘要

將知識庫 RAG 的切塊參數從 Chunker 寫死常數移到 appsettings.json 的 SystemSettings.Retrieval，讓客戶首次部署時可依資料型態調整 chunk 大小、硬上限與 overlap。同時新增「知識庫 RAG 設計與執行」架構文件，說明 RAG 全流程、可調參數、索引重建時機與品質調整方式。

變更內容

  • SystemSettings.Retrieval 新增：
  • ChunkTargetChars，預設 800
  • ChunkMaxChars，預設 1200
  • ChunkOverlapChars，預設 120
  • Chunker 改為可透過 IOptions<SystemSettings> 讀取切塊設定，並保留預設建構式供測試/工具使用。
  • 新增切塊設定驗證，避免 ChunkMaxChars < ChunkTargetChars、overlap 不合法等設定產生壞索引。
  • 新增 知識庫 RAG 設計與執行，並同步 README、PRD、使用指南、PoC 指南、設定文件與階段三設計藍圖。
  • SystemVersion 升至 0.2.141 (2026/06/28)。

注意事項

TopK、權重與 MinScore 屬查詢時參數，調整後重啟即可影響後續查詢。ChunkTargetChars、ChunkMaxChars、ChunkOverlapChars 屬索引建立時參數，調整後既有 VectorEmbedding 不會自動改變，需要重新蒸餾或重建索引才會生效。
