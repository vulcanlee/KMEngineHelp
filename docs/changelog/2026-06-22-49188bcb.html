知識來源 AI 對話：訊息可複製到剪貼簿（0.2.113）

  • 日期：2026-06-22
  • 版本：0.2.112 → 0.2.113
  • 對應 PRD：知識來源管理 PRD

摘要

「知識來源管理清單」的 AI 對話頁，比照 ChatGPT 網頁，為每一輪對話的「使用者 Prompt」 與「LLM 輸出」各加上一個複製到剪貼簿按鈕，可單獨複製任一則內容。

內容

  • 每則訊息可複製：每則氣泡下方新增複製鈕（hover 該則訊息時淡入），點擊後跳出

「已複製到剪貼簿」提示。多輪對話時，每一則 Prompt 與輸出皆可獨立選擇複製。

  • 複製原始 Markdown：LLM 輸出在畫面上以 Markdown 渲染，但複製的是

原始 Markdown 文字（直接取 ChatMessage.Content，非渲染後 HTML）； 使用者訊息則複製原輸入文字。

  • 串流友善：串流產生中、尚未有內容的助理訊息（打字游標階段）不顯示複製鈕，

產生完成後才出現，避免複製到空字串。

實作

  • KnowledgeSourceChatView.razor：每則訊息改為「氣泡 ＋ 動作列」欄式結構，動作列含複製鈕

（AntDesign Tooltip ＋ Button ＋ Icon Type="copy"）。

  • KnowledgeSourceChatView.razor.cs：新增 CopyMessageAsync(content)，沿用既有複製範式

（navigator.clipboard.writeText ＋ MessageService 成功／失敗提示）。

  • KnowledgeSourceChatView.razor.css：新增 .ke-msg-col / .ke-msg-actions 與 hover 淡入樣式。
