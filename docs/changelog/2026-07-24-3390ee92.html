統計儀表板：加大區塊間垂直間距並加細分隔線（1.0.47→1.0.48）

  • 日期：2026-07-24
  • 版本：1.0.47 → 1.0.48
  • 類型：介面微調（純 CSS）

需求

首頁統計儀表板各區塊之間僅靠 margin-bottom: 24px 分隔、區塊標題無上方留白，標題緊貼上一塊內容，視覺上不易分辨區塊界線。希望加大區塊間垂直間距並加一條細分隔線。

變更

  • DashboardView.razor.css：新增規則，對 .dashboard 的直接子堆疊區塊（第一個總量卡除外）與最後的 .dashboard-columns 區塊加上 margin-top/padding-top 各 28px 與 border-top: 1px solid #f0f0f0。
  • :not(:first-of-type) 使第一個區塊維持齊上不加線。
  • 僅選 .dashboard > 直接子，故「經營洞察」區塊內部的三欄群組不會被加線，維持同區塊視覺一致。
  • 相鄰兄弟 margin 折疊取最大值，不與既有 margin-bottom: 24px 相加。

影響與相容性

  • 純視覺 CSS 調整，不改 HTML 結構與任何 C#；無資料/邏輯變更、不需 migration。

版本

  • appsettings.json SystemVersion：1.0.47 (2026/07/24) → 1.0.48 (2026/07/24)。
