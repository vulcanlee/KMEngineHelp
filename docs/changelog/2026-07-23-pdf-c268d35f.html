內容編修對話窗預覽可下載為 PDF（1.0.31）

  • 日期：2026-07-23
  • 版本：1.0.30 → 1.0.31

摘要

在共用的內容編修對話窗（ContentEditDialog）右側「預覽」面板的標題列，於既有「複製」按鈕旁 新增一個下載 PDF按鈕：把目前編輯中的內容（＝預覽所見）轉成 PDF 檔並下載。此對話窗被 「清洗結果」「知識瀏覽（Wiki）」「技能」「文件萃取」「影像辨識」「媒體轉錄」「會議紀錄」等頁面 共用，因此一次讓所有含預覽的對話窗一致擁有此功能。

內容

  • 下載預覽所見：PDF 內容取自左側編輯框的最新文字（含使用者即時修改），與右側 Markdown

預覽一致；按鈕僅在有預覽（ShowPreview=true）時顯示，純文字模式（如逐字稿）不出現。

  • 繁體中文不亂碼：沿用既有伺服器端 QuestPDF 機制，內嵌 Noto Sans TC 字型，A4、1 吋邊界、頁碼。
  • 一鍵下載：PDF bytes 透過 Blazor DotNetStreamReference 串流回瀏覽器下載，檔名為

{對話窗標題}_{時間戳}.pdf（標題已濾除檔名不合法字元）。

實作

  • Components/Commons/ContentEditDialog.razor：預覽標題列新增「下載 PDF」按鈕；新增

OnDownloadPdfAsync()（沿用既有 ChatPdfExporter.Generate(editingText, Title) 與 keChat.downloadFileFromStream）與 MakeSafeFileName(title) 檔名清理輔助方法。

  • 沿用既有基礎設施（QuestPDF／QuestPDF.Markdown／內嵌字型／chat.js 下載函式），未新增套件。

備註

  • 無資料模型變更，不需要資料庫 migration。
  • 內容為前端暫存、無持久化 Id，故不新增 controller 端點，直接於元件內產生並串流下載

（比照 2026-07-10-聊天內容下載PDF.md 的既有決策）。
