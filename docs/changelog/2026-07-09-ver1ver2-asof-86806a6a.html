變更紀錄

VER-1 完整版本狀態機 + VER-2 失效標記/as-of（0.3.13→0.3.14）

  • 日期：2026-07-09
  • 版本：0.3.13 → 0.3.14
  • 類型：版本化與時效性（VER，核心 RAG 管線）

需求

收尾 planning/12 延後的 P1：把 design doc 2026-07-01-...-design.md §三/§四 的完整版本化與時效性落地。此前蒸餾為快照式（重蒸餾即刪除舊 Wiki 頁與向量），無版本歷史、無「只回現行版」、無 as-of。核心不變量：概念鍵＝(KnowledgeSourceId, Title)，每概念至多一個 EffectiveStatus==current。

變更（7 階段）

1. 模型 + 雙 migration + backfill

  • WikiPage 加 Version/EffectiveStatus(current/superseded/null)/EffectiveDate/ExpiryDate/SupersededByPageId/PreviousVersionPageId/Owner/LastReviewedAt/ChangeSummary。
  • VectorEmbedding 加 IsCurrent(預設 true)/EffectiveDate/ExpiryDate。
  • 雙 migration AddVersioningFields；backfill：既有「已完成」頁→current、既有向量 IsCurrent=true（避免既有知識從檢索消失）。

2. 蒸餾改「保留舊版→superseded→版本鏈」

  • DistillationProcessor 不再刪除舊版（移除 DeleteExistingPagesAsync）：自動核可的新版即成 current、舊 current→superseded（ExpiryDate/SupersededByPageId）＋其向量 IsCurrent=false；待審核新版為草稿、舊版維持 current 到新版核可。

3. 核可狀態轉移

  • WikiPageService.ApproveAsync：核可即成 current、同概念舊 current→superseded＋向量失效；版次+1、鏈回舊版。

4. 索引引擎「現行感知」

  • EmbeddingIndexProcessor 只索引「已完成且 current」頁；diff 只作用於 IsCurrent=true 向量（superseded 不被當孤兒刪除，保留）；新向量帶 IsCurrent=true＋Wiki 層 EffectiveDate。

5. 檢索「只取現行版 + as-of」

  • RetrievalQuery.AsOf／VectorQuery.AsOf；EffectiveVersionFilter 疊加在權控之上——預設只回 IsCurrent；as-of(T) 取時點現行 Wiki 版本（Cleaned 恆納入）。DualDbVectorStore 與 RetrievalService 兩路一致。

6. UI

  • /knowledge-wiki 閱讀頁顯示版本歷史（各版本 Version/生效狀態/日期/變更摘要，可檢視舊版）。
  • 蒸餾頁加版次/生效欄與治理模態（Owner/ChangeSummary，UpdateGovernanceAsync）。
  • /rag-diagnostics 試檢索加 as-of 日期。

7. 測試

  • 新增：Approve supersede＋向量失效、版本鏈查詢、檢索預設只回現行版、as-of 回時點版本；修正 EmbeddingIndexProcessorTests fixture（已完成頁設 current）。
  • 全測試 484 通過、0 失敗。

不變量與相容

  • 權控疊加在生效過濾之上不取代；越權洩漏維持 0（RagEval）。
  • 向後相容：backfill 讓既有資料行為不變（既有頁＝current、既有向量＝IsCurrent）。
  • Cleaned 層不版本化、恆為現行/納入 as-of。

影響範圍

  • 進度：VER-1 ✅、VER-2 ✅ 完成——planning/12 全部 P1 至此完成。
  • 同步更新 design §十二、知識庫RAG設計與執行 §2.1/§六、蒸餾指南、planning/12。
  • appsettings.json 0.3.13 → 0.3.14；需套用雙 migration。

驗證

  1. dotnet build＋dotnet test 綠燈（484）。
  2. 蒸餾→改內容重蒸餾（高信心自動核可）→ 舊頁 superseded 保留、其向量 IsCurrent=false；問答/試檢索只命中新版；/knowledge-wiki 版本歷史可見舊版。
  3. as-of：/rag-diagnostics 試檢索設過去時點回舊版、現在回新版。
  4. 權控：非管理員越權洩漏＝0。
  5. scripts/Test-DocsEncoding.ps1 全綠。
