變更紀錄

favicon 指紋化與品牌徽章文字調整紀錄

變更目的

  1. 修正瀏覽器分頁 favicon 仍顯示舊圖示的問題（硬快取）。
  2. 將登入頁與 Splash 的品牌小字由「SECURE GATEWAY / SYSTEM ONLINE」置換為與產品相關的「智庫引擎 · 企業知識」。

問題與修正

  • favicon 未更新：Components/App.razor 的 favicon <link> 原本直接用 href="favicon.png"，未經 @Assets[...] 指紋化，導致瀏覽器沿用舊快取。改為 href="@Assets["favicon.png"]"（比照同檔 CSS 連結），URL 帶內容雜湊，檔案變更即自動破快取。
  • 徽章文字置換：登入頁 .brand-badge「SECURE GATEWAY」與 Splash .splash-eyebrow「SYSTEM ONLINE」皆改為「智庫引擎 · 企業知識」。對應樣式由英文大寫設計（mono 字體、字距 0.22em、uppercase）調整為適配中文（改用預設字體、字距 0.1em、移除 uppercase），保留霓虹綠與光暈。

本次修改檔案

  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/App.razor（favicon 指紋化）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/Auths/Login.razor（+ .razor.css）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/Components/Views/Commons/SplashView.razor（+ .razor.css）
  • src/KnowledgeExtraction/KnowledgeExtraction.Web/appsettings.json（版本 0.2.157→0.2.158）

未變更

  • 登入頁 kicker「IDENTITY VERIFICATION」（與登入情境相關，保留）。
  • 圖示資產本身、其餘版面與霓虹翡翠樣式。

備註

  • 使用者端首次可能仍需 Ctrl+F5 清一次舊 favicon 快取；之後每次圖示變更會自動破快取。

編碼要求

  • 本次新增文件以 UTF-8（含 BOM）保存，內容為繁體中文、無亂碼。
