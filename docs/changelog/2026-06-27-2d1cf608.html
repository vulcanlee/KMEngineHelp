黃金評測說明強化：指南擴充＋頁面名詞 tooltip（0.2.137）

  • 日期：2026-06-27
  • 版本：0.2.136 → 0.2.137
  • 類型：文件 / UI 可理解性改善

背景

使用者反映看不懂黃金評測頁面的統計表（遮罩Recall／分類F1／摘要涵蓋／MustKeep／建議門檻／目前門檻／自動清洗率／待審核率／PrecisionVsHuman／RecallVsHuman），也不清楚「按評測此筆系統做了什麼、有什麼用、對系統有沒有影響」。經程式碼追蹤確認：黃金評測是量測／校準工具，advisory-only——不改設定、不影響搜尋／RAG、不改變實際清洗結果；唯一生效旋鈕是 appsettings 的 Cleaning.ConfidenceThreshold（人工修改）。

調整內容

  • 擴充 docs/guides/清洗品質評測使用指南.md（1.0 → 1.1）：新增「按下評測此筆系統做了什麼（運作原理、5 段 LLM 與提示詞）」、補「最近信心」定義與分類 F1 公式範例、新增「用畫面那筆逐項拆解」完整範例與健康對照組、「看到數字該怎麼調門檻」決策表、「黃金評測對系統有沒有影響」澄清段、樣本數量建議。
  • GoldenSampleView.razor 加名詞 tooltip（不改邏輯）：儀表板統計數字與門檻、校準表表頭、資料表欄位標題（人工通過／最近信心／遮罩Recall／分類F1／摘要涵蓋）加上 hover 白話說明，文案與指南一致。沿用既有 AntDesign Tooltip／native title，未新增相依。
  • 另製作互動式視覺說明（Artifact 網頁，claude.ai 代管，不進版控）：流程圖、指標卡、門檻校準互動。

驗證

  • dotnet build Web 專案成功；dotnet test 367 筆全綠。
  • scripts/Test-DocsEncoding.ps1 通過（指南與本變更紀錄具 BOM、無亂碼）。

備註

僅文件與 UI 說明強化，未改黃金評測演算法、清洗門檻邏輯、資料模型或權限；不需 migration、不需權限三處同步。
