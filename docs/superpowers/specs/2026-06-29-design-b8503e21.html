設計：專案列表「工作與會議」對話窗 + 共用編輯 Modal 抽取

  • 日期：2026/06/29
  • 對應版本：0.2.152
  • 狀態：已實作
  • 編碼：UTF-8（繁體中文，含 BOM）

一、背景與目標

一個專案會關聯多個工作項目（MyTask）與多個會議記錄（Meeting，皆以可空 ProjectId 外鍵關聯）。使用者希望在專案清單上以對話窗（非路由切換）直接檢視某專案關聯的工作與會議，並能就地新增/修改/刪除。用對話窗而非導向新頁，是為了避免離開專案清單時遺失當下的頁次與捲動位置。

二、需求決策（與使用者確認）

  • 入口：專案清單每列新增「工作與會議」按鈕（仿既有「管理子工作」巢狀對話窗 UX）。
  • 版面：對話窗內用 Tabs（「工作項目」/「會議記錄」），各一個簡單表格（不加搜尋/分頁）。
  • 重用：抽出完整自包含編輯對話窗元件 MyTasEditModal / MeetingEditModal，並重構現有 MyTasViewView/MeetingViewView 改用同一元件。
  • 列動作：新增/修改/刪除（不在此做「管理子工作」）。
  • 所屬專案：對話窗內新增與修改皆鎖定為當前專案。

三、元件設計

1. MyTasEditModal / MeetingEditModal（共用編輯對話窗）

各自擁有 <Modal> + <EditForm> + DataAnnotationsValidator + InputWatcher + AntDesign.Form、附件上傳/移除狀態、LocalEditContext 驗證，以及完整存檔路徑（BeforeAddCheck/BeforeUpdateCheck → 開上傳串流 → AddAsync/UpdateAsync）與通知。建構式注入服務。

主要參數（MyTasEditModal，MeetingEditModal 為其子集，無 child/ChildCount）：

參數說明
Visible / VisibleChanged支援 @bind-Visible
RecordId (int?)null/≤0＝新增；否則編輯該筆
ParentTaskId (int?)非 null＝子工作（僅 MyTas）
ProjectIdContext (int?)預選/鎖定的專案
LockProject (bool)true＝所屬專案預選且不可改（以 disabled Input 顯示專案名）
HideProject (bool)true＝不渲染所屬專案欄位（子工作沿用父工作專案）
ChildCount (int)供「有子工作時日期唯讀」規則（僅 MyTas）
InheritTeams / InheritCategories新增子工作時繼承父工作標籤（僅 MyTas）
OnSaved / OnCancelled存檔成功 / 取消後通知宿主

關鍵實作要點：

  • 重建守衛：以 _wasVisible 僅在 Visible 由 hidden→visible 時載入下拉資料與重建 CurrentRecord；避免每次 OnParametersSet 重建而清空使用者輸入。
  • 所屬專案沿用哨兵 0／「（不指定專案）」；LockProject 時固定 CurrentRecord.ProjectId = ProjectIdContext 並以 disabled Input 呈現。服務端 >0 ? : null 正規化不變。
  • 存檔成功後 VisibleChanged.InvokeAsync(false) + OnSaved.InvokeAsync()；取消則 VisibleChanged.InvokeAsync(false) + OnCancelled.InvokeAsync()。元件不涉入父工作日期同步（仍由服務端 RecomputeParentDatesAsync 處理）。

2. ProjectRelatedRecordsModal（關聯對話窗）

參數：Visible/VisibleChanged、ProjectId、ProjectTitle。

  • OnParametersSet（hidden→visible 守衛）：以 CheckAccessPage(角色_工作項目/角色_會議項目) 決定 canTasks/canMeetings 與預設分頁，載入兩清單。
  • 載入：MyTasService.GetAsync / MeetingService.GetAsync 帶 ProjectIdFilters=[ProjectId]、PageSize=int.MaxValue、Take=0（取全部、仍套團隊權控）。
  • Tabs + 兩個簡單表格（依權限渲染），每列 修改/刪除 + 新增鈕；內嵌 MyTasEditModal（LockProject=true）與 MeetingEditModal（LockProject=true）。
  • 巢狀流程：開編輯前以私有 selfVisible=false 隱藏本對話窗，OnSaved→重載該清單＋selfVisible=true；OnCancelled→selfVisible=true。使用者關閉（X）經 OnCancel → VisibleChanged(false) 通知宿主。

3. 入口 ProjectViewView

ActionColumn 第一個 SpaceItem 加「工作與會議」鈕（Icon="event_note"），僅在使用者具備 角色_工作項目 或 角色_會議項目 時顯示。開啟即設定 relatedProjectId/Title 與 relatedRecordsVisible=true，純疊加不導航。

四、後端

MeetingService.GetAsync 補上 ProjectIdFilters 過濾（仿 MyTasService）：

if (dataRequest.ProjectIdFilters.Count > 0)
{
    dataSource = dataSource.Where(x =>
        x.ProjectId != null && dataRequest.ProjectIdFilters.Contains(x.ProjectId.Value));
}

無資料庫/模型變更、無 migration。

五、不變量

  • 團隊權控沿用各 *Service.GetAsync 內既有 BuildTeamAccessPredicate。
  • 多選分類/團隊維持 Mode=SelectMode.Multiple + Values/OnSelectedItemsChanged。
  • 哨兵 0／服務端 <=0→null 正規化沿用。
  • DbSet MyTas ≠ Entity MyTask；不動模型。
