音訊轉錄擴充設計規格：YouTube 來源、繁體輸出修正、語言選擇

項目內容
撰寫日期2026/06/03
對應版本0.2.18
狀態已實作
相關文件音訊影片轉錄服務 PRD §13、日誌與設定檔說明 §4.8

背景與問題

現有「音訊轉錄」只能上傳本機檔案，並以固定 language=zh／繁體 prompt 呼叫 gpt-4o-transcribe。實務遇到三個問題與一個延伸需求：

  1. 無法直接以 YouTube 連結轉錄（需手動下載再上傳）。
  2. 中文輸出常為簡體。經查證：OpenAI 轉錄 API 的 language 僅接受 ISO-639-1 兩碼（中文僅 zh，不支援 zh-tw），且 language／prompt 對模型只是軟性偏好，無法保證繁體。
  3. 純英文影片被中文設定干擾，需逐筆選擇語言。
  4. 需同步更新說明文件。

設計決策（已與使用者確認）

  • 繁體修正：強化繁體 prompt ＋ OpenCC（OpenccNetLib s2twp）後處理保底，僅在語言為中文時套用。
  • 語言選擇：新增記錄時提供「轉錄語言」下拉（繁體中文／English／自動偵測），逐筆指定。
  • YouTube：以 yt-dlp -x 僅下載音訊轉 mp3。
  • 來源類型：同一新增表單用「來源類型」切換（檔案上傳／YouTube 連結），共用同一套記錄與背景流程。

架構與資料流

[新增表單] 來源類型 + 語言
   ├─ 檔案上傳 → 寫檔 → 建立記錄(Upload, Language) → 佇列
   └─ YouTube  → 僅存 URL → 建立記錄(YouTube, SourceUrl, Language) → 佇列
                                   │
[TranscriptionBackgroundService] ──┤
                                   ▼
[TranscriptionProcessor]
   1. 若 YouTube 且尚未下載 → YouTubeDownloader 抽音訊 mp3，補齊檔案欄位
   2. >25MB → MediaChunker 分段
   3. 依 Language 解析 (apiLanguage, prompt, applyOpenCC)
   4. 逐段 OpenAITranscriptionClient.TranscribeAsync(part, language, prompt)
   5. 合併；若 applyOpenCC → ChineseConverter.ToTraditional（s2twp）
   6. 存逐字稿 .txt、更新狀態

元件職責

  • YouTubeDownloader（新增）：以 Process 叫用 yt-dlp，-x --audio-format mp3 --no-playlist --ffmpeg-location ...，輸出 {yyyy}/{guid}.mp3，並取影片標題作為原始檔名。回傳路徑／大小／ContentType。
  • ChineseConverter（新增，Singleton）：包裝 OpenccNetLib.Opencc("s2twp").S2Twp，簡轉台灣繁體；字典檔隨建置輸出至 dicts/。
  • OpenAITranscriptionClient.TranscribeAsync：新增 language／prompt 參數，空值不送該欄位。
  • TranscriptionProcessor：新增 YouTube 下載步驟、語言解析、OpenCC 後處理；不再於完成時覆寫 Language。
  • MediaTranscriptionService：BeforeAddCheckAsync 依來源分流；新增 AddYouTubeAsync；AddAsync 寫入 SourceType／Language。
  • 前端：新增表單加「來源類型」「轉錄語言」與 URL 欄位，OnModalOkAsync 依來源分流。

資料模型

MediaTranscription 新增 SourceType（Upload/YouTube，既有資料預設 Upload）、SourceUrl（nullable）。Language 改為建立時寫入。SQLite 與 SqlServer 兩套 migration AddYouTubeSourceToMediaTranscription 皆已建立。

錯誤處理

  • yt-dlp／ffmpeg 缺失或下載失敗 → 拋出中文訊息，該筆標記「失敗」並記錄 ErrorMessage。
  • YouTube URL 驗證：http(s) 且網域含 youtube.com／youtu.be。
  • 刪除記錄時連動刪除已下載音訊與逐字稿（沿用既有 TryDeleteRelative）。

前置需求

系統需安裝 yt-dlp 與 FFmpeg，路徑由 OpenAISettings:YtDlpPath／FfmpegPath 指定。

驗證

  • 單元測試 ChineseConverterTests 驗證簡轉繁（软件→軟體、程序→程式）。
  • dotnet build、dotnet test（66 + 5 測試）全數通過。
  • 端對端：上傳中文影片得台灣繁體；YouTube 連結免上傳完成轉錄；英文影片不轉繁；自動偵測不送 language。
