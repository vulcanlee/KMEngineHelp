PRD 全庫基線重建設計

  • 日期：2026/07/12
  • 目標系統版本：0.3.34
  • 狀態：已由使用者確認，待實作

一、目標

將 docs/prd 建立為可驗證的產品需求單一入口：完整覆蓋目前已實作的系統能力，同時保留尚未實作的產品藍圖，但兩者必須嚴格分層，不能讓讀者把規劃誤認為現況。

本次保留既有 PRD 路徑與歷史引用，不進行大規模重新命名或合併。文件以產品能力為單位；所有正式選單頁仍須透過覆蓋矩陣對應至少一份 PRD。

二、真實來源與判定順序

PRD 校正依下列順序判定現況：

  1. 程式碼、資料模型、設定與自動化測試。
  2. Menu.json、Razor @page、權限樹與實際服務流程。
  3. 架構、安全、功能、操作及維運專題文件。
  4. changelog 與既有 PRD 的歷史描述。

文件互相衝突時，以較高順位來源校正；有保存價值的舊決策放入變更紀錄，不保留在現行需求中。

三、PRD 資訊架構

每份 PRD 統一標示：文件版本、文件狀態、現行系統版本、首次實作版本、最後核對日期。能力狀態只使用「已實作」「部分實作」「規劃中」「已淘汰」。

每份文件至少包含：

  • 產品目標、使用者與入口。
  • 已實作範圍與明確非目標。
  • 使用流程、畫面／介面與資料規則。
  • 權限、安全及團隊權控。
  • 狀態機、背景作業、錯誤與恢復行為（適用時）。
  • 資料影響、版本／時效性與下游連動（適用時）。
  • 可驗證的驗收條件、主要程式來源與關聯文件。
  • 獨立的「規劃中需求」章節；不得把未實作欄位或流程寫入現況章節。

docs/prd/README.md 升級為 PRD 主控台，包含：

  • 產品能力、PRD、選單頁、程式來源與狀態覆蓋矩陣。
  • 無選單入口的核心背景管線、索引、權控、版本生命週期與稽核能力。
  • 已實作與規劃中藍圖分區。
  • 新增／修改功能時的 PRD 維護規則。

四、新增能力 PRD

新增五組產品能力文件：

  1. 知識瀏覽與 Wiki 導覽：涵蓋 /knowledge-wiki、概念索引、分類／團隊篩選、WikiLink、版本閱讀、複製／PDF 與權控。
  2. 嵌入索引與混合檢索：涵蓋切塊、嵌入、向量儲存、關鍵字／向量融合、來源與分類限制、索引狀態、單筆／全量重建及權控。
  3. RAG 診斷與查詢期調校：涵蓋 /rag-diagnostics、門檻、查詢期參數、分佈／模擬、索引健康、自檢、試檢索及熱套用風險。
  4. 資料版本、時效性與一致性生命週期：涵蓋素材版本鏈、as-of、過時標記、孤兒成員、/data-consistency、重新清洗／蒸餾／索引連動與安全清理。
  5. AI 可觀測性與成本治理：涵蓋 /chat-logs、滿意度、問答稽核、/token-usage、成本統計、資料留存與管理員權限。

/log-settings 併入擴充後的「系統健康監控 PRD」，與健康檢查、日誌尾端、執行期診斷形成同一產品能力。

內容搜尋取代、共用內容編修、PDF 下載、批次壓縮檔上傳等較小的跨頁能力，回寫所屬現有 PRD，不另建碎片文件。

五、既有 PRD 校正

逐份審核現有 26 份 PRD，按下列群組執行：

  • 帳號與治理：首頁、登入、使用者、角色、分類、團隊、提示詞、系統健康。
  • 專案協作：專案、工作、會議與附件。
  • 內容匯入：影音轉錄、文件萃取、圖片辨識、逐字稿／文件衍生內容。
  • 知識加工：知識來源、清洗、清洗設定檔、黃金評測、蒸餾。
  • RAG 與品質：問答、RAG 評測、PDF 專屬 RAG 藍圖、索引／檢索與診斷。

每份檢查路由、欄位、按鈕、狀態、設定鍵、權限、團隊權控、資料影響、錯誤恢復、驗收及程式連結。近期香港功能須回寫正確歸屬，包括素材版本鏈、內容搜尋取代、問答來源／分類限制、滿意度與聊天稽核、Token 用量、全量索引、資料一致性與診斷頁。

《PDF 型 RAG 處理 PRD》保留，但分成「目前通用 RAG 已提供的能力」與「尚未實作的 PDF 結構感知藍圖」，規劃內容不得出現在現況驗收。

六、驗收與交付

  • 所有正式選單頁 100% 對應至少一份現況 PRD。
  • 所有背景管線、核心資料實體與跨域安全能力都有產品需求歸屬。
  • PRD 中的路由、設定鍵、狀態與主要功能可由程式碼或測試驗證。
  • 已實作與規劃中需求完全分區；部分實作項目逐條標示完成／未完成。
  • 所有相對連結可解析，scripts/Test-DocsEncoding.ps1 全數通過。
  • dotnet test 通過；Git diff 僅包含 PRD、必要索引／changelog、設計／計畫文件與版本設定。
  • 系統版本由 0.3.33 升為 0.3.34；新增 PRD 版本為 1.0，既有 PRD 依校正幅度提升文件版本。
  • 不自動 commit；交付時提供建議 commit message 並保留獨立 worktree 供審閱。
