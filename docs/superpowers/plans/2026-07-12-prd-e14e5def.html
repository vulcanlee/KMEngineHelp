For agentic workers: REQUIRED: Use superpowers:executing-plans to implement this plan. Steps use checkbox (- [ ]) syntax for tracking. 本專案未授權子代理，且不得自動 commit。

Tech Stack: Markdown（UTF-8 BOM、繁體中文）、ASP.NET Core／Blazor、EF Core、PowerShell、ripgrep、Git、xUnit。
